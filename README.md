# 東方座敷幕 〜 Mansion of Borrowed Rooms.

東方Projectの二次創作弾幕シューティングゲームです。ブラウザだけで動きます。

> 本作品は上海アリス幻樂団「東方Project」の二次創作です。公式とは関係ありません。
> 音楽・効果音と、`img/` 以外の絵はすべてこのリポジトリ内のコードで生成しています。

## あそびかた

`index.html` をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけで遊べます。インストールやビルドは不要です。
最初に画面をクリック（またはキーを押す）と音が鳴り始めます。

### 1ファイル版

[`dist/zashiki.html`](dist/zashiki.html) はゲーム全体を1つのHTMLファイルにまとめたものです。
このファイルだけを保存・配布すれば、ダブルクリックで遊べます（ネット接続なしでも動きます）。

前のゲーム『東方星降夜 〜 Night of Falling Stars.』（1.3.0）は [`dist/hoshifuru.html`](dist/hoshifuru.html) にそのまま残してあります。
2つのゲームのハイスコアなどの記録は、別々に保存されます。

ソースを変更したあとは、次のコマンドで作り直せます（Node.js が必要です）。

```
node tools/build-single.js
```

### テスト

ブラウザ（Chromium）でゲームを実際に動かして、メニュー・全ステージのボス戦・管理者ページ・ハイスコアの保存などを自動で確かめます。
はじめに `npm install` で Playwright を入れてください。

```
node tools/test.js          # ふつうのテスト（1分ほど）
node tools/test.js --full   # 自動操縦で全ステージをクリアするテストも行う
node tools/test.js --dist   # 1ファイル版を対象にする
```

`npm run build` / `npm test` でも同じことができます。開発の決まりごとは `CLAUDE.md`、変更の記録は `CHANGELOG.md`、
ストーリー・キャラクター・弾幕・背景・自機・音楽・名前を入れかえるときの手順は `docs/CONTENT_GUIDE.md` にあります。

| 操作 | キーボード | ゲームパッド | タッチ |
| --- | --- | --- | --- |
| 移動 | ↑↓←→ | 十字キー / 左スティック | ドラッグ |
| ショット・決定 | Z / Space / Enter | A | 触れている間は自動 |
| ボム・戻る | X | B | 「ボム」ボタン |
| 低速移動 | Shift | LB / RB | 「低速」ボタン（切り替え） |
| 一時停止 | Esc / P | Start | 「II」ボタン |
| 会話スキップ | Ctrl | Y | タップ |
| 音のオン/オフ | M | | |

マウスでは自機を操作できません（ドラッグでの移動や画面のボム・低速ボタンは無効）。メニューの選択や会話送りはクリックでもできます。

### ハイスコア

ハイスコアは難易度とキャラクターごとに、遊んだブラウザの中に保存されます。
プラクティスとコンティニューしたプレイでは、ハイスコアは更新されません。

## ストーリー

ある朝、人里の家々が、一晩でぼろぼろに古びてしまった。
屋根には穴があき、床は虫だらけ。部屋がまるごと消えてしまった家まであるという。
博麗霊夢と霧雨魔理沙は、それぞれ人里へと向かった。

本編は全6面です。6面をクリアするとエンディングになります。エキストラステージは準備中です。
エキストラステージは、本編を Normal 以上の難易度でコンティニューせずにクリアすると遊べるようになります（タイトルの「エキストラスタート」）。

- 中ボスは、戦っているあいだ名前を出しません
- 2面の中ボスは瑠璃（前のゲームの4面ボス）です
- 3面の中ボス（？？？）は、よその家でくつろいでいた正体不明の子です。3面のボスを倒すと、隠れていた屋敷が姿を現します
- 1面はほかの面よりやさしくしてあります
- 2面の道中には緑の手、3面からは一つ目の手が出てきます。古びた屋根からは瓦が降ってきます（大きな瓦は一撃で倒せます）
- 4面は人里から借りてきた部屋を次々に突き抜けていきます。破れたふすまの紙きれは弾を撃ちませんが、ぶつかるとミスになります
- 5面では梁が落ちてきます（横いっぱいの予告線のあと）
- スペルカード名と曲名は仮のものです

## ゲームの内容

- 自機は2人
  - **博麗霊夢**：ホーミングアミュレット / パスウェイジョンニードル、ボムは霊符「夢想封印」
  - **霧雨魔理沙**：マジックミサイル / イリュージョンレーザー、ボムは恋符「マスタースパーク」
- 難易度は Easy / Normal / Hard / Lunatic の4段階（エキストラステージは Extra）
- ボムを使うと、自機のキャラクターのカットインが出ます
- 東方らしいシステム：低速移動と当たり判定表示、グレイズ、喰らいボム、霊力（パワー）、
  アイテム自動回収ライン、「点」アイテムでのエクステンド、スペルカードボーナスと取得履歴
- 会話シーンとエンディングはキャラクターごとに別の内容
- プラクティス（ステージ選択）、ミュージックルーム（オリジナル曲13曲）、オプション（音量・初期残機）
- ハイスコアとスペルカード履歴はブラウザに保存されます

## 改造するには

ステージやボスの弾幕はジェネレータ関数で書いてあり、`yield n` で n フレーム待ちます。
各ステージは道中の `script` とボス戦の `boss` に分かれています。ボスを増やしたら、ステージの `bosses` にも書いてください（管理者ページの一覧とテストが使います）。

作ったボスの攻撃は、URL のうしろに `?boss=ボスのID&phase=何番目&diff=0〜3` を付けて開くと、会話なしですぐ試せます
（例：`index.html?boss=toganoo&phase=3&diff=3`。プラクティス扱いなので記録は残りません）。

```js
// スペルカードの例：自機狙いの5方向弾を40フレームごとに撃つ
{
  type: 'spell', name: '星符「サンプル」', hp: 1000, time: 30,
  *script(b) {
    for (;;) {
      fireFan({ x: b.x, y: b.y, n: 5, spread: 0.6, angle: b.aim(), speed: 2.5, type: 'star', color: 'yellow' });
      yield 40;
    }
  },
}
```

- 弾の種類：`small` `ball` `large` `dot` `rice` `kunai` `amulet` `star` `bigstar` `ice` `butterfly`
- 弾の色：`red` `orange` `yellow` `green` `cyan` `blue` `purple` `pink` `white` `dark`
- 難易度ごとの値は `dv(Easy, Normal, Hard, Lunatic)` で指定できます
- 全体の難しさは `js/bullets.js` の `BULLET_SPEED_SCALE`（弾の速さ）と `RING_DENSITY_SCALE`（全方位弾の数）で調整できます
  - ステージごとの倍率は各ステージの `speedScale` / `densityScale` / `hpScale`（ボスの体力）で指定します（いまは1面・4面・5面・6面）
  - Lunatic は扇状の弾が両端に1発ずつ増え、ザコを倒すと撃ち返し弾が飛んできます
- 見た目は `img/` のPNGを同じ名前で置き換えると変えられます（背景は透明にしてください）
  - `player.png` / `marisa_player.png`：ゲーム中の霊夢・魔理沙
  - `reimu.png` / `marisa.png`：霊夢・魔理沙の原画（キャラクター選択・ボムのカットイン・会話・エンディング）
  - `foot_fairy.png`：各面でいちばん弱い妖精
  - `midboss1.png`：1面の中ボス
  - ボスの原画（スペルカードのカットインと会話）と、ゲーム中のドット絵（`_dot`）：
    `nokiba`（1面 軒端 鬼乃）、`hamishiro`（2面 喰代 守子）、`namesawa`（3面 滑沢 瓢）、`toganoo`（4面 栂尾 芯）、
    `yanari`（5面 家鳴 鳴音・6面中ボス）、`zashiki`（6面 座敷 宿美）
  - 中ボス：`boss4`（2面中ボス 瑠璃。前のゲームの4面ボスと同じ絵）、`midboss3b`（3面中ボス ？？？）
  - `hand.png`：2面の道中に出る緑の手
  - `hand_eye.png`：3面以降の道中のザコ（一つ目の手）
  - いまは読み込んでいない絵：`boss3` / `midboss3`（と `_dot`。前のゲーム『東方星降夜』の絵）、`midboss2`（と `_dot`。2.0.0 までの2面中ボス）
- 曲は `js/music.js` にMML（`o5 e4. d8 c4 o4 a4 |` のような書き方）とコード進行で追加できます
