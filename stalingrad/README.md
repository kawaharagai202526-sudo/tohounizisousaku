# スターリングラード攻防戦 3D俯瞰デモ

1942年7月〜1943年2月のスターリングラードの戦いを、約5分の3D俯瞰映像として再現する単一HTMLのデモです。

`index.html` をブラウザで開くだけで動きます（three.js を CDN から読み込むため、インターネット接続が必要です）。

## 内容

| 章 | 時期 | 主な演出 |
| --- | --- | --- |
| 序章 | 1942年夏 | 雲の上から草原へ降下、タイトル |
| 第一章 ヴォルガへ | 7/17〜8/23 | 第6軍・第4装甲軍の進軍矢印、第14装甲軍団のヴォルガ到達 |
| 第二章 炎上 | 8/23 | 爆撃機の編隊、市街の炎上と黒煙 |
| 第三章 市街戦 | 9/13〜11/18 | 市街の前線の推移、第13親衛狙撃師団の渡河、主要ランドマーク |
| 第四章 天王星作戦 | 11/19〜11/23 | 霧の中の砲撃、南北からの挟撃、包囲網の完成 |
| 第五章 救出と空輸 | 12月 | 輸送機の空輸、冬の嵐作戦、小土星作戦 |
| 第六章 包囲網の終焉 | 1/10〜2/2 | コリツォ作戦、包囲網の分断、降伏 |
| 終章 | 1943/2/2 | 数字で見る戦い |

- 地形：ヴォルガ川・ドン川・支流・市街の峡谷（バルカ）・ママエフ・クルガンを高さ関数で生成（縦方向は誇張）
- 季節：夏の草原 → 秋 → 積雪、ヴォルガ川の結氷
- 霧：距離霧 + 流れる高さ霧、雲海、降雪
- カメラ：時間方向に滑らかなエルミート補間のシネマカメラ。ドラッグで自由視点に切替

## 操作

Space 再生／一時停止、← → 5秒移動、1〜8 章へ移動、C カメラ切替、L ラベル、H 字幕等を隠す、F 全画面

地名・部隊位置・前線は史実をもとに簡略化したものです。数字（包囲された将兵数、死傷者数など）には諸説があります。
