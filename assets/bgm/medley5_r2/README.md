# 5 曲つなぎ・作り直し版 (r2) × 5 パターン

[`../medley5/`](../medley5/README.md) をもとに、**原型を残すことより、1 曲としてのまとまりと自然な繋ぎを優先して** 作り直した版です。
テンポ・キー・切れていた所の補修は `medley5` と同じです（基準は 5 曲目 S5）。その上で次の処理を加えています。

## 追加した処理

- **全曲共通のドラム層**
  - 5 曲すべてに、同じキット・同じノリのドラムを薄く重ねました（4 つ打ちのキック、2・4 拍のクラップ、裏拍のハイハット、8 小節ごとのクラッシュ）。
  - 音楽はそのキックに合わせて軽くうねらせています（サイドチェイン）。曲が変わってもリズムの土台が同じなので、1 曲に聴こえやすくなります。
- **音作りを揃える**
  - EQ：S2〜S4 を S5 の周波数バランスにほぼ完全に寄せました。
  - ステレオ：モノラルだった S3〜S5 を、ステレオの S1・S2 と同じくらいの横幅に広げました（モノラルで聴いても音は変わりません）。
  - 最後に全体へ共通の残響と軽いコンプをかけ、同じ部屋・同じ仕上げの音にしています。
- **繋ぎ目**
  - 前の曲は、最後の 2 小節で低音をハイパスでだんだん抜いていき、次の曲の頭で低音が戻ります（DJ ミックスの「ドロップ」の形）。
  - キーが変わる所には、前後の和音に共通する音を柔らかいパッドで伸ばしています（S1→S2: F / S2→S3: F / S3→S4: A♭ / S4→S5: G / 最後の F→E: G#）。

## 5 パターン

| ファイル | 長さ | 内容 |
|---|---|---|
| `medley5r2_v1_unified.ogg` | 1:45 | **統一**。上の処理をすべてかけた標準形。最後は E で「ジャーン」 |
| `medley5r2_v2_nonstop.ogg` | 1:50 | **ノンストップ**。前の曲は 4 小節かけて抜き、次の曲はこもった音から開いていきます。S3 のブレイク中もドラムを止めず、最後もドラムを鳴らしたままフェードアウト |
| `medley5r2_v3_drive.ogg` | 1:32 | **疾走**。イントロ・S2 を短くし、S3 のブレイクも飛ばします。ドラム層とうねりを強めにして、短い「キメ」で終わります |
| `medley5r2_v4_cinematic.ogg` | 1:52 | **ドラマチック**。タム・スネアロール・ライザーで大きく盛り上げ、共通音のパッドも厚めにしています。最後は冒頭のパッドを元の E で戻して締めくくります |
| `medley5r2_v5_loop.ogg` | 1:40 | **ゲーム用ループ**。S1・S2 をイントロにして、S3 → S4 → S5 → S3 … |
