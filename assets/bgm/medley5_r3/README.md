# 5 曲つなぎ・採用版 v4 の繋ぎ目作り直し (r3)

`medley5r3_v4_cinematic.ogg`（1:51）

[`../medley5_r2/`](../medley5_r2/README.md) で採用された v4（ドラマチック）を、繋ぎ目だけ作り直した版です。
曲の並び・音作り（共通のドラム層、EQ・音量・横幅の統一、共通の残響）・終わり方は r2 の v4 と同じです。

## 何が悪かったか（数値での比較）

採用された 3 部構成版 v4 の繋ぎ目を基準にして、繋ぎ目の前後 2.5 秒を比べました。

| 繋ぎ目 | 音色の差 (r2 → r3) | 音量の差 (r2 → r3) | 一番深い落ち込み (r2 → r3) |
|---|---|---|---|
| S1 → S2 | **120 → 49** | 2.9 → 1.1 dB | -21.8 → -16.2 LUFS |
| S2 → S3 | 24 → 13 | 1.8 → 0.7 dB | -16.2 → -14.8 LUFS |
| S3 → S4 | 21 → 18 | 1.9 → 1.0 dB | **-24.8 → -19.4 LUFS** |
| S4 → S5 | 34 → 28 | 0.7 → 0.6 dB | -15.5 → -15.8 LUFS |
| 3 部構成版 v4（基準） | 27〜72 | 1.7 dB 以内 | -19 LUFS 程度まで |

## 繋ぎ目ごとの直し方

- **S1 → S2**：こもったパッドから明るいバンドへ急に変わっていました。
  - パッドの最後の 2 小節で、S2 をローパスでこもらせた小さな音から重ね始め、だんだん音を開いていきます。
  - ハイハット、ライザー、F の共通音パッドでつないでいます。
- **S2 → S3**：112 → 168 BPM へ一気に変わっていました。
  - S2 の後半 2 小節で、拍ごとになめらかに加速していきます。
  - スネアも 8 分 → 16 分と加速に合わせて細かく、大きくしています。
- **S3 → S4**：ブレイクで音が沈みすぎていました。
  - ブレイクで伸ばす和音は原曲では 12 dB ほど減衰していくので、その分を持ち上げました。
  - キックの鼓動と 16 分のスネアを残し、A♭ のパッド・ライザー・逆再生シンバルを強めて 4 曲目の頭へ持ち上げます。
- **S4 → S5**：小節を半分で切り貼りしていました。
  - S4 を 1 拍長く残し、S5 の助走と 1 拍かけてクロスフェードするようにしました。
  - S4 の低音はハイパスで抜いていきます。

## 作り直し方

```sh
python3 tools/bgm/build_medley5_r3.py
```
