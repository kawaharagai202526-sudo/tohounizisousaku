# BGM（原曲 3 曲つなぎの完成版 × 5 パターン）

`source/original.m4a` は、3 曲をつないだ未完成の原曲です（アップロードされた動画から音声だけを無劣化で取り出したもの）。
これをもとに、曲調を揃えて繋ぎ目を自然にした完成版を 5 パターン作りました。

## 原曲の解析結果

| | 区間 | テンポ | 調 | 特徴 |
|---|---|---|---|---|
| 1 曲目 (P1) | 0:00–0:32 | 162 BPM | D#m（D#→E→F#→E のループ）→ D#sus4 のブレイク | 音圧が高い |
| 2 曲目 (P2) **基準** | 0:32–1:20 | 166 BPM | F#m → 0:57 で Gm へ半音転調 | 4 つ打ち＋ストレートな 8 分 |
| 3 曲目 (P3) | 1:20–2:34 | 155〜168 BPM で揺れる | E♭/B♭ 系 | ピッチが約 +17 セント高い。打楽器が薄く、P2 より約 10 dB 小さい |

## 共通の処理

- **全体のテンポを P2 の 166 BPM に統一**。P2 の音には一切手を加えていません。
- **P1**：ほぼそのまま。v2 以外はテンポだけ 162→166 BPM（+2.5%、音程は変えない）に合わせています。
- **P3 を P2 に合わせる**
  - 拍を 1 拍ずつ追跡し、揺れていたテンポを 166 BPM の一定テンポに補正
  - +17 セントずれていたピッチを P2 と同じ基準に補正
  - 周波数バランス・音圧を P2 に近づける（EQ・コンプ・区間ごとの音量調整）
  - P2 と同じ系統のドラムを追加（4 つ打ち、2・4 拍のスネア／クラップ、裏拍のハイハット。重いヒットが続く部分はハーフタイム）
- **繋ぎ目**：ライザー、スネアロール、逆再生シンバル、クラッシュ、インパクト、タムのフィルなどで自然に繋いでいます。
  - P1→P2：P1 のブレイク (D#) → P2 の助走小節 (C#) → F#m という流れをそのまま活かしています
  - P2→P3：P2 は原曲で唐突に切れていたので、着地のクラッシュとインパクト、短い残響を足しています
- 音程のある新しいフレーズ（ベース・メロディ等）は足していません。解析だけで音を決めると和音とぶつかる危険があるためです。追加した音は打楽器と効果音のみです。

## 5 パターン

| ファイル | 長さ | 内容 |
|---|---|---|
| `bgm_v1_standard.ogg` | 2:32 | **標準**。全体を 166 BPM に統一。P1→P2 はスネアロール＋ライザーで盛り上げ、P2→P3 はタムのフィルで繋ぎます。P3 の最後はパッドで静かに終わります。 |
| `bgm_v2_faithful.ogg` | 2:32 | **原曲重視**。P1 は原速（162 BPM）のまま一切加工なし。ブレイク中に少しずつ加速して P2 のテンポへ移ります。足す音は控えめです（P3 のドラムも軽め）。 |
| `bgm_v3_drive.ogg` | 2:15 | **疾走感**。P1 のブレイク後半からキックで助走をつけ、P2→P3 はドラムを止めずに直結します。P3 を最も強く P2 に寄せ、パッドの部分に入ったところで「ジャーン」と短く締めます。P2 の転調箇所にもクラッシュを追加しています。 |
| `bgm_v4_cinematic.ogg` | 2:35 | **ドラマチック**。P1 のブレイクを 8 小節に整えています（似ている 18–19 小節をもう一度挟みます）。P2→P3 はいったん落とし、P3 はハイハット → キック → フルのドラムと徐々に盛り上げます。 |
| `bgm_v5_loop.ogg` | 2:13 | **ゲーム用ループ**。P3 の再現部の後に P2 の助走小節を置き、P2 の頭へ戻ります。P1→P2 と同じ「C# の助走小節 → F#m」の流れで戻ります。 |

### v5 のループ位置

| | サンプル (44.1 kHz) | 秒 |
|---|---|---|
| ループ開始 (LOOPSTART) | 1405417 | 31.8689 |
| ループ終了 (= ファイル末尾) | 5868779 | 133.0789 |

OGG には RPG ツクール等と同じ形式の `LOOPSTART` / `LOOPLENGTH`（サンプル数）タグを入れてあります。
ループ終了点の後に続く残響はループ開始点に重ねてあるので、そのままループ再生しても継ぎ目は出ません。

## 作り直し方

```sh
# 必要なもの: ffmpeg, rubberband-cli, fluidsynth, fluid-soundfont-gm (apt)
pip install -r tools/bgm/requirements.txt
python3 tools/bgm/analyze_source.py   # 原曲を解析して tools/bgm/source_analysis.json を作る (任意)
python3 tools/bgm/build_bgm.py        # 5 パターンすべて。 v1 v3 のように指定も可
```

`assets/bgm/*.ogg` のほか、作業用の WAV と試聴用の MP3 が `build/bgm/` に出力されます（git 管理外）。
