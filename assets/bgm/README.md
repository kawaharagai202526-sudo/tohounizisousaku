# BGM（1 曲目 + 2 曲目の完成版 × 5 パターン）

`source/original.m4a` は、3 曲をつないだ未完成の原曲です（アップロードされた動画から音声だけを無劣化で取り出したもの）。
現行版では **3 曲目を削除** し、1 曲目 → 2 曲目を曲調を揃えて自然につないだ完成版を 5 パターン用意しています。
3 曲目まで入った前回の版は `with_part3/` に残してあります。

## 原曲の解析結果

| | 区間 | テンポ | 調 | 特徴 |
|---|---|---|---|---|
| 1 曲目 (P1) | 0:00–0:32 | 162 BPM | D#m（D#→E→F#→E のループ）→ D#sus4 のブレイク | 音圧が高い |
| 2 曲目 (P2) **基準** | 0:32–1:20 | 166 BPM | F#m → 0:57 で Gm へ半音転調、最後は Gm→F→G/B→Gsus4 | 4 つ打ち＋ストレートな 8 分。原曲では Gsus4 の途中で切れている |
| 3 曲目 (P3) | 1:20–2:34 | — | — | **現行版では削除** |

## 共通の処理

- **テンポは P2 の 166 BPM に統一**。P2 の音には一切手を加えていません。
- **P1**：ほぼそのまま。v2 以外はテンポだけ 162→166 BPM（+2.5%、音程は変えない）に合わせています。
- **P1→P2 の繋ぎ**：P1 のブレイク (D#) → P2 の助走小節 (C#) → F#m という原曲の流れを活かし、ライザー・スネアロール・逆再生シンバル・クラッシュ・インパクトで自然につないでいます。
- **終わり方を新しく作成**：P2 は原曲では Gsus4 の途中で切れていたので、パターンごとに終わり方を作りました（下表）。
  「ジャーン」の着地音には、P2 の 30 小節目の頭（G5 の和音）をそのまま使っています。Gsus4 → G と解決して終わる形です。
- 追加した音は打楽器と効果音のみです。和音とぶつかる危険があるため、新しいメロディやベースは足していません。

## 5 パターン

| ファイル | 長さ | P1→P2 の繋ぎ | 終わり方 |
|---|---|---|---|
| `bgm_v1_standard.ogg` | 1:23 | スネアロール＋ライザーで盛り上げる | タムのフィル → Gsus4 が G に解決して「ジャーン」、残響で終わる |
| `bgm_v2_faithful.ogg` | 1:30 | **P1 は原速 (162 BPM) のまま無加工**。ブレイク中に少しずつ加速。足す音は控えめ | P2 の最後の 8 小節をもう一度流しながらフェードアウト（原曲の音だけ） |
| `bgm_v3_drive.ogg` | 1:21 | ブレイク後半からキックで助走。P2 の転調箇所にもクラッシュ | スネアで詰めて短い「キメ」でスパッと終わる |
| `bgm_v4_cinematic.ogg` | 1:36 | ブレイクを 8 小節に整え（似ている 18–19 小節をもう一度挟む）、タムとライザーで盛り上げる | P1 のテーマ（メロディのある 8–15 小節）を再現し、P1 自身のブレイク頭の和音 (D#sus4) で着地 |
| `bgm_v5_loop.ogg` | 1:18 | v1 と同じ | P2 の後、タムのフィルで P1 の頭へ戻り **曲全体をループ** |

### v5 のループ位置

| | サンプル (44.1 kHz) | 秒 |
|---|---|---|
| ループ開始 (LOOPSTART) | 1102 | 0.0250 |
| ループ終了 (= ファイル末尾) | 3444268 | 78.1013 |

OGG には RPG ツクール等と同じ形式の `LOOPSTART` / `LOOPLENGTH`（サンプル数）タグを入れてあります。
ループ終了点からはみ出す残響はループ開始点に足し込んであるので、そのままループ再生しても継ぎ目は出ません。

## 作り直し方

```sh
# 必要なもの: ffmpeg, rubberband-cli, fluidsynth, fluid-soundfont-gm (apt)
pip install -r tools/bgm/requirements.txt
python3 tools/bgm/analyze_source.py            # 原曲を解析して tools/bgm/source_analysis.json を作る (任意)
python3 tools/bgm/build_bgm.py                 # 2 曲版 5 パターン (v1 v3 のように指定も可)
python3 tools/bgm/build_bgm.py --with-part3    # 3 曲版 5 パターン (with_part3/ に出力)
```

`assets/bgm/*.ogg` のほか、作業用の WAV と試聴用の MP3 が `build/bgm/` に出力されます（git 管理外）。
