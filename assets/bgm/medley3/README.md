# 3 部構成の原曲からの完成版 × 5 パターン

`../source/medley3_original.mp3`（1:55, モノラル）は、2 つの曲がつながった未完成の原曲です。
1 曲目は最初と最後の 2 回出てきます。これをもとに、曲調を揃えて繋ぎ目を自然にした完成版を 5 パターン作りました。

## 原曲の解析結果

| | 区間 | テンポ | 調・和音 | 特徴 |
|---|---|---|---|---|
| A | 0:00–0:35 | 165 BPM | Gm（Gmaj7/Gm → E♭ → F → Gm） | 24 小節。約 -16.6 LUFS |
| B | 0:35–1:20 | 178 BPM | E♭ → F → Am7 → Gm7 の 4 小節ループ × 8 | 高い和音を伸ばす 1 小節の助走から始まる。A より 4.6 dB 大きく、少し暗い音 |
| A' | 1:20–1:55 | 165 BPM | Gm | A と同じ曲の別テイク。G のペダル音のブレイク 8 小節 → A の 8〜23 小節とほぼ同じ内容。最後の小節の途中で切れている |

キーは全部 Gm 系で揃っていて、違うのはテンポ・音量・音色でした。

## 共通の処理

- **基準は A**（最初と最後に出てくる「家」の曲）です。A と A' の音そのものには手を加えていません。
  - 例外の v3 だけは、B を基準にした速い版です。
- **テンポ**：B を 178 → 165 BPM に揃えました（v3 は逆に、A と A' を 178 にしています）。
- **音量・音色**：B を A に寄せました。
  - 音量は -12.0 → -14.0 LUFS にしています。A より 2.5 dB ほど大きい、サビのような位置づけです。
  - 音色は EQ で A のバランスに近づけました。
- **途中で切れていた所の補修**：A' の最後の小節は、最初の A の同じ位置（23 小節目, E♭）の完全な小節に差し替えました。
- **繋ぎ目**：原曲の「A の 23 小節目 → B の助走」の流れを活かし、クラッシュ・逆再生シンバル・インパクトで区切りをはっきりさせています。B → A' のブレイクはいったん落とし、ブレイクの後はライザーとスネアロールで本編へ戻します。
- **終わり方**：E♭ → G で着地します。着地音には曲の最初の一打（A の 0 小節目, Gmaj7）を使っているので、始まりと同じ和音で終わります。
- 追加した音は、打楽器と効果音のみです。

## 5 パターン

| ファイル | 長さ | 内容 |
|---|---|---|
| `medley3_v1_standard.ogg` | 2:02 | **標準**。165 BPM に統一。A → B → A'（ブレイク → 本編）→ G で「ジャーン」 |
| `medley3_v2_faithful.ogg` | 2:06 | **原曲重視**。テンポは各曲のまま（伸縮なし）、EQ も控えめ、足す音はシンバル程度。最後は A の 16〜23 小節をもう一度流しながらフェードアウト |
| `medley3_v3_drive.ogg` | 1:25 | **疾走**。B の 178 BPM に統一して全体を速くしました。A は 0〜7 → 16〜23 小節に縮め、ブレイクも 4 小節にしています。B の 8 小節ごとにクラッシュを入れ、短い「キメ」で終わります |
| `medley3_v4_cinematic.ogg` | 2:05 | **ドラマチック**。ブレイクの後半をタム・ライザー・スネアロールで大きく盛り上げます。G で着地した後、G のペダル音のブレイクを静かに戻して締めくくります |
