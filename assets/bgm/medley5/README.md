# 5 曲つなぎの完成版 × 5 パターン

`../source/medley5_original.mp3` は 5 曲をつないだ未完成の原曲（1:48）です。
これをもとに、曲調を揃えて繋ぎ目を自然にした完成版を 5 パターン作りました。

## 原曲の解析結果

| | 区間 | テンポ | 調・和音 | 特徴 |
|---|---|---|---|---|
| S1 | 0:00–0:13 | （なし） | E のペダル音 + Emaj7sus4 系のパッド | 打楽器なし。高域がこもった音。L/R が無相関のとても広いステレオ。ピッチが +14 セント高い |
| S2 | 0:13–0:26 | 110 BPM | B♭ 一発のループ | ステレオ。低音が多い |
| S3 | 0:26–0:39 | 177 BPM | B♭m → A♭ 系 | 8 小節目でビルド、9 小節目は和音を伸ばすブレイク（途中で切れている） |
| S4 | 0:39–1:02 | 170 BPM | A♭m から転調を重ねて E♭ で終わる | 16 小節 + 途中で切れた小節 |
| S5 **基準** | 1:02–1:48 | 168 BPM | C → D → Bm → Em（王道進行） | 一番長い本命の曲。最後は F（G# 入り）の途中で切れている |

## 共通の処理

- **基準は 5 曲目 (S5)**。テンポ・音量・音色・ステレオ感を S5 に合わせ、S5 の音そのものには手を加えていません。
- **テンポ**
  - S3 (177)・S4 (170) を 168 BPM に揃えました。
  - S1・S2 (110) は、168 のちょうど 2/3 にあたる 112 BPM にしました。S2 の最後に 112 BPM の 3 連符のフィルを入れています（112 の 3 連 8 分 = 168 の 8 分）。これで拍が途切れずに S3 の 168 BPM へ切り替わります。
- **キー**：S1 (E) と S2 (B♭) は増 4 度離れていてぶつかります。そこで S1 のパッドだけを半音上げて F にし、「F → B♭」（属和音 → 主和音）と解決させました。ほかの継ぎ目は元から B♭ → B♭m、A♭ → A♭m、E♭ → C と自然につながります。
- **途中で切れていた所を補修**
  - S3 のブレイクの和音は原曲では 2.5 拍で切れていたので、1 小節分に伸ばしました。
  - S4 の最後の小節は前半だけ使い、後半には S5 の助走を置いて 4 拍の小節に直しました。
  - S5 の最後の小節（3 拍目で切れている）はタムのフィルで埋めました。
- **音量・音色・ステレオ**
  - 音量：S2〜S4 を S5 と同程度（約 -14 LUFS）に揃えました。
  - 音色：低音が多い S2〜S4 を EQ で S5 に寄せました。
  - ステレオ：S1・S2 の広いステレオを少し狭め、モノラルの S3〜S5 には薄い残響を足して、曲間の空気感をつなげています。
- **終わり方**：S5 の最後の F（G# を含む）から、S5 自身の E メジャーの和音へ「スパニッシュ終止」で着地します。
- 追加した音は打楽器と効果音のみです（クラッシュ、逆再生シンバル、ライザー、インパクト、3 連符・タムのフィル）。
