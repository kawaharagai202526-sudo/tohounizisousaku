# 3 部構成・作り直し版 (r2) × 5 パターン

[`../medley3/`](../medley3/README.md) をもとに、**原型を残すことより、1 曲としてのまとまりと自然な繋ぎを優先して** 作り直した版です。
構成（A → B → A'）、テンポ合わせ、切れていた所の補修は `medley3` と同じです（基準は A、v3 だけ B）。その上で次の処理を加えています。

## 追加した処理

- **全編共通のドラム層**
  - 同じキット・同じノリのドラムを全編に薄く重ねました。
    - A の前半 8 小節はキックとハイハットだけにし、9 小節目から 4 つ打ち＋クラップにします。
    - ブレイクは後半からハイハットで盛り上げます。
  - 音楽はそのキックに合わせて軽くうねらせています。
- **音作りを揃える**
  - 音量・EQ：B を A の音量と周波数バランスにほぼ完全に寄せました。A と B の音量差は、前回の 2.5 dB から約 1 dB になっています。
  - ステレオ：原曲はモノラルなので、全体を同じ横幅に広げました（モノラルで聴いても音は変わりません）。
  - 最後に全体へ共通の残響と軽いコンプをかけています。
- **繋ぎ目**
  - 前の部分は、最後の 2 小節で低音をハイパスでだんだん抜き、次の頭で低音が戻ります。
  - 前後の和音に共通する音を柔らかいパッドで伸ばしています（A→B: F / B→A': G / ブレイク→本編: G / 着地: G）。

## 5 パターン

| ファイル | 長さ | 内容 |
|---|---|---|
| `medley3r2_v1_unified.ogg` | 2:03 | **統一**。上の処理をすべてかけた標準形。最後は G で「ジャーン」 |
| `medley3r2_v2_nonstop.ogg` | 2:10 | **ノンストップ**。4 小節かけて抜き、次はこもった音から開いていきます。ブレイク中もキックを止めず、最後もドラムを鳴らしたままフェードアウト |
| `medley3r2_v3_drive.ogg` | 1:25 | **疾走**。178 BPM に統一して短く詰め、ドラム層とうねりを強めにしています。短い「キメ」で終わります |
| `medley3r2_v4_cinematic.ogg` | 2:05 | **ドラマチック**。ブレイク全体で G のパッドを膨らませ、タム・ライザー・スネアロールで盛り上げます。最後は G のペダル音で静かに締めくくります |
| `medley3r2_v5_loop.ogg` | 1:58 | **ゲーム用ループ**。A をイントロにして、B → A' → B … とループします。継ぎ目の直前は 1 周目と同じ小節です |
