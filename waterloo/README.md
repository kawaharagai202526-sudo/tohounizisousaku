# ワーテルローの戦い 3D俯瞰デモ

1815年6月18日のワーテルローの戦いを、約4分40秒の3D俯瞰映像として再現するデモです。スターリングラード版と同じ描画エンジンを使っています。

- `index.html` … three.js を CDN から読み込む版（インターネット接続が必要）
- `waterloo-offline.html` … three.js を同梱したオフライン版。ダブルクリックだけで再生できます

## カメラ

カメラは主要な地域・場面を自動で追いかけます（ウーグモン、デルロン軍団の前進、英重騎兵の突撃、ネイの騎兵、プロイセン軍の到着、近衛の攻撃など）。一部の場面では部隊の動きに合わせて追尾します。視聴者がカメラを動かす機能はありません。

## 内容

| 章 | 時刻 | 主な演出 |
| --- | --- | --- |
| 序章 百日天下 | 6/15〜6/17 | 作戦地図：サンブル川渡河、リニーとカトル・ブラ、豪雨の中の後退 |
| 第一章 雨上がりの朝 | 6/18 午前 | 両軍の布陣、ぬかるんだ麦畑 |
| 第二章 ウーグモン | 11:30頃〜 | ジェローム師団の攻撃、北門の攻防、館の炎上 |
| 第三章 デルロン軍団の突撃 | 13:30頃〜 | 第1軍団の前進、ピクトン戦死、英重騎兵の突撃と槍騎兵の反撃 |
| 第四章 ネイの騎兵突撃 | 16:00頃〜 | 騎兵の大突撃と連合軍の方陣 |
| 第五章 プロイセン軍の到着 | 16:30頃〜18:30頃 | ビューロー軍団、プランスノワの攻防、ラ・エー・サント陥落 |
| 第六章 近衛の敗走 | 19:30頃〜21:00頃 | 近衛の攻撃と後退、ツィーテン軍団の到着、全軍前進 |
| 終章 | 6/18 夜 | 数字で見る戦い |

画面右上に日付と時刻（10分単位）、右下に位置図・方位・縮尺を表示します。天候は17日の豪雨、18日朝のもや、夕焼けへと変化します。

## 操作

Space 再生／一時停止、← → 5秒移動、1〜8 章へ移動、L ラベル、H 字幕等を隠す、F 全画面。操作バーで再生速度と画質（高画質／標準／軽量）を選べます。

地形・部隊位置は史実をもとに簡略化したものです（縦方向は誇張）。兵力・損害の数字には諸説があります。
