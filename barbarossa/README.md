# バルバロッサ作戦 3D俯瞰デモ

1941年6月22日に始まったドイツのソ連侵攻（バルバロッサ作戦）を、1942年1月のモスクワ前面の反攻まで、約10分の3D俯瞰映像で再現するデモです。

- `index.html` … three.js を CDN から読み込む版（インターネット接続が必要）
- `barbarossa-offline.html` … three.js を同梱したオフライン版。ダブルクリックだけで再生できます

## カメラ

カメラはバルト海から黒海までの主要な戦域・場面を自動で追いかけます。装甲集団や方面軍の動きに合わせて追尾し、離れた戦域へ移るときは一度高く引いてから寄ります。視聴者がカメラを動かす機能はありません。

戦線は時間とともに動き、枢軸側の占領地域は青く、包囲されたソ連軍は赤い斜線と輪で示します。季節は夏の草原から秋の泥、初雪、厳冬へと変わり、海や湖も凍ります。

## 操作

Space 再生／一時停止、← → 5秒移動、数字キーで章へ移動、L ラベル、H 字幕等を隠す、F 全画面。操作バーで再生速度と画質を選べます。

地形・戦線・部隊の位置は史実をもとに簡略化したものです（縦方向は誇張）。捕虜数・損害の数字は各国の発表や推定によるもので、諸説があります。
