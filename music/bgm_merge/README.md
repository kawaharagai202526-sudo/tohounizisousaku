# BGM 3 曲統合

3 曲が連結されただけの原曲 (`YouCut_20261025_005138108.mp4`, 4:35) を、
曲調を揃えて繋ぎ目を自然にした 1 曲 (`music/output/bgm_merged.ogg` / `.mp3`, 4:29) にするスクリプト。

## 原曲の解析結果

| | 原曲の位置 | テンポ / 拍子 | キー | 特徴 |
|---|---|---|---|---|
| 曲1 | 0:02〜1:23 | 約 186 BPM の 3 拍子系 | D マイナー | 速い旋律主体。最後は Dm で終わるが 1:23.4 で急にカット |
| 曲2 | 1:23〜2:41 | 約 151 BPM 4/4 (1 小節 ≈ 1.59 秒) | 半音階的に転調し F マイナーで終止 | ハイパスのイントロ → 持続和音の本編 → 加速ロールのクライマックス → アウトロ (B♭→A♭→G→F) |
| 曲3 | 2:41〜4:30 | 前半 115 BPM 4/4、後半はテンポが揺れる | F マイナーで始まり G マイナーへ転調 | 808 系の重い低音とキック主体。4:00 付近で 4 秒減衰 + 無音の内部継ぎ目。末尾はフェードで途切れ、最後に 1 秒の不要な断片 |

調の関係が元々つながっている (Dm = F の平行調 → 曲2 冒頭は F の属和音 C7 → 曲2 は Fm で終止 → 曲3 は Fm で開始) ので、
移調はせずテンポ・質感・繋ぎ目を中心に整えた。

## 完成版の構成

| 時刻 | 内容 |
|---|---|
| 0:00〜1:21 | 曲1 (冒頭の無音 2.3 秒を詰めた以外は原曲のまま。音量も原曲と同じ) |
| 1:21〜1:26 | 曲1 最後の Dm 和音を残響で伸ばしローパスで閉じる + ダウンリフター。曲2 のイントロ (C7 = F の属和音) がその上に入る |
| 1:21〜2:25 | 曲2 イントロ〜本編〜加速ロール (本編は +2.5 dB、元々大きいクライマックスはそのまま) |
| 2:25 | ロールの着地点 (曲2 の小節頭) に曲3 の一打目を合わせてドロップ |
| 2:25〜4:13 | 曲3 (曲2 の曲調に寄せる加工、下記) |
| 3:40〜3:43 | 曲3 内部の継ぎ目を「1 小節ブレイク + 逆再生スウェル」に置換し、小節グリッドに揃えた |
| 4:13〜4:29 | 終曲: 曲2 のアウトロを +2 半音 (F→G) 移調して接続。曲3 最後の D からベースが D→C→B♭→A→G と下行して G で終わる |

## 曲3 を曲2 に合わせた加工 (`song3.py`)

- テンポ 115 → 113.1 BPM (−1.7%)。曲3 の 3 拍 = 曲2 の 1 小節 (1.59 秒) になり、小節の周期が揃う
- 調波/打撃分離で打撃成分を −2.2 dB (打撃比率が曲2 と同じ 0.08 に)
- 長時間平均スペクトルを曲2 に 65% 寄せる EQ (重い低域を抑え、曲2 の明るく軽いバランスへ)
- 調波成分にリバーブを足して曲2 のような空間を付与
- 曲2 風のデチューン・ノコギリ波パッドをベース進行に沿って重ねる。
  曲3 は半音階的で 3 和音の判定が不安定なため「ルート + 5 度 + オクターブ」とし、
  中音域でその音が鳴っていて半音隣の音に負けていない区間だけ鳴らす (誤検出による不協和を回避)

## 再生成

```sh
pip install librosa soundfile pedalboard pyloudnorm scipy numba
ffmpeg -i YouCut_20261025_005138108.mp4 -vn -ac 2 -ar 44100 orig.wav
python3 build.py orig.wav <作業ディレクトリ>   # <作業ディレクトリ>/final.wav ができる
ffmpeg -i <作業ディレクトリ>/final.wav -c:a libvorbis -q:a 6 ../output/bgm_merged.ogg
```

主な調整値: `build.py` の `G_SONG2` (曲2 の持ち上げ量), `LUFS_SONG3` (曲3 の音量),
`song3.py` の `match_eq_curve(amount=...)` (曲2 への質感の寄せ具合), パッド音量 (`- 21.0` dB)。

# BGM2 (2026-11-08 の原曲) — `build2.py`

`YouCut_20261108_154314344_1.mp3` (1:55) を、曲調を 2 曲目に統一して
`music/output/bgm2_merged.ogg` / `.mp3` (1:55) に仕上げる。

## 原曲の解析結果 (3 曲ともキーは G マイナー)

| | 原曲の位置 | テンポ | 内容 | 問題点 |
|---|---|---|---|---|
| 曲1 | 0:00〜0:35 | 165 BPM | 24 小節 (12 小節の G ペダル → E♭-F-G → Cm-F-D7) | 曲2 より 4 dB 小さく低音が重い。25 小節目の頭で切れる |
| 曲2 | 0:35〜1:20 | 178 BPM | 1 小節のドラムフィル + 8 小節 × 4 (E♭-F-F#dim-Gm)。中高域が前に出た明るく詰まった音 | 基準 (無加工) |
| 曲3 | 1:20〜1:55 | 165 BPM | 8 小節の G ペダルのブレイク + 曲1 の 9〜24 小節目の別テイク | テンポが戻る。最終小節の途中 (残り 2 拍) で切れている |

曲2 のドラムは 2・4 拍目のストレートなバックビート、曲1・曲3 はシンコペーションの多いビートなので、
曲2 のドラムを重ねるとリズムがぶつかる。重ねずに、テンポ・音色バランス・音圧を曲2 に揃えた。

## 完成版の構成

| 時刻 | 内容 |
|---|---|
| 0:00〜0:32 | 曲1 (178 BPM に速め、音色・音圧を曲2 に合わせた 24 小節) |
| 0:32〜0:34 | 曲2 のドラムフィル 1 小節 (曲1 の最後の D7 → 曲2 の頭の E♭ は偽終止として自然につながる) |
| 0:34〜1:17 | 曲2 (原曲のまま 32 小節) |
| 1:17〜1:49 | 曲3 (曲2 の最後の Gm → 曲3 の G ペダルのブレイク → 本編。曲1 と同じ処理) |
| 1:49〜1:55 | 曲3 で欠けていた最後の 2 拍を曲1 の同じ箇所で補い、わずかにリタルダンド → 曲1 冒頭の Gm の一打を終止和音にして残響で終える |

## 曲1・曲3 を曲2 に合わせた加工

- テンポ 165 → 178 BPM (+7.9%、音程はそのまま)。1 小節が曲2 と同じ 1.348 秒になり、繋ぎ目を小節頭で揃えられる
- 長時間平均スペクトルを曲2 に 70% 寄せる EQ: 0〜150 Hz の割合が 63% → 42% (曲2 は 34%)
- コンプ + ラウドネス合わせ: 本編 −16 LUFS → −12.3 LUFS (曲2 は −12.0)
- 曲3 のブレイク (8 小節) は本編と同じゲインで、原曲どおり一段落とした質感を残す (−13.1 LUFS)

## 再生成

```sh
ffmpeg -i YouCut_20261108_154314344_1.mp3 -ac 2 -ar 44100 orig2.wav
python3 build2.py orig2.wav <作業ディレクトリ>   # <作業ディレクトリ>/final2.wav ができる
ffmpeg -i <作業ディレクトリ>/final2.wav -c:a libvorbis -q:a 6 ../output/bgm2_merged.ogg
```

主な調整値: `build2.py` の `LUFS_MAIN` (曲1・曲3 の音量), `match_eq_curve(amount=0.7)` (曲2 への音色の寄せ具合),
`COMP_RATIO`, リタルダンドの深さ (`SPEED * 0.88`)。
