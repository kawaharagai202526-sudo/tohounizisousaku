# 化物屋敷異変 キャラクター名前案（漢字版）

「キャラクター名前案」の60個すべてを、下の名前まで漢字にした「全部漢字」版。7人で計420個。

- 読みは元の案と同じ。No. は「キャラクター名前案」での番号。
- ★はおすすめ3（元の案と同じもの）。※は当て読み（ふりがなを出す前提のもの）。
- 全部漢字だと姓と名の切れ目がわかりにくいので、この資料では間に空白を入れた（例：鬼瓦 睨）。実際の表記では「鬼瓦睨」のように詰めてよい。

## 全部を漢字にするための工夫

- 意味の通る字がある名前は、その字を使った（例：睨＝にらみ、梔子＝くちなし、水鶏＝くいな）。
- 「ぺたり」「ちょろり」のような擬音の名前は、意味の近い字に読ませる「当て読み」（例：貼＝ぺたり、走＝ちょろり）か、音を一字ずつ当てる「当て字」（例：仁良々＝にらら）にした。
- 姓と同じ字が名にも入りそうなときは、別の字や旧字を探した（例：猿辻ましら→猿辻 申、若瓦わかば→若瓦 嫩葉、欠角かけみ→欠角 缺美）。
- 代わりの字がない、または同じ字のほうが意味が通るため、姓と名で字が重なっているのは次の12個：鬼面めんこ→鬼面 面子、反屋そりか→反屋 反花、尾切しっぽ→尾切 尻尾、大店たなこ→大店 店子、夜半さよこ→夜半 小夜子、朽木くちは→朽木 朽葉、怪音ねいろ→怪音 音色、可愛めごこ→可愛 愛子、方位よも→方位 四方、方違たがえ→方違 違、金神こがね→金神 黄金、七殺ななえ→七殺 七重。気になる場合は、この名前はかなのまま使うとよい。
- 当て読みは35個。読みにくいので、ゲーム中では初登場時にふりがなを出す前提。
- 下の名前の漢字は420個すべて別にした。主な既存キャラクターの名前（紫・藍・椛・咲夜など）と同じ表記は避けている。

## 漢字の当て方

- **意味で当てる**：言葉の意味どおりの字を使う。いちばん読みやすい。例：睨（にらみ）、梔子（くちなし）、一二三（ひふみ）
- **音で当てる（当て字）**：意味より音を優先して字を選ぶ。例：立枝（たつえ）、仁良々（にらら）、於仁沙（おにさ）
- **当て読み**：意味の近い字に、本来はない読み方をさせる。読みにくいので、ふりがなを出す前提。例：貼（ぺたり）、軋（みしり）、小豆（おじゃみ）
