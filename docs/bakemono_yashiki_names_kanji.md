# 化物屋敷異変 キャラクター名前案（漢字版）

「キャラクター名前案」の60個から1人30個ずつ選び、下の名前も漢字にした「全部漢字」版。7人で計210個。

- 読みは元の案と同じ。No. は「キャラクター名前案」での番号。
- ★はおすすめ3（元の案と同じもの）。
- 全部漢字だと姓と名の切れ目がわかりにくいので、この資料では間に空白を入れた（例：鬼瓦 睨）。実際の表記では「鬼瓦睨」のように詰めてよい。

## 選び方

- 漢字にしたときに意味が通るもの、見た目が締まるものを、6つのテーマからなるべく均等に選んだ。おすすめ3はすべて入れた。
- 「ちょろり」「ぺったん」のような擬音の名前は、漢字にすると読めなくなるので、ほとんど外した。
- 姓と名で同じ字が重なるもの（例：猿辻ましら→猿辻 猿）も外した。ただし、おすすめの「方違たがえ」だけは残し、別の書き方を添えた。
- 下の名前の漢字は210個すべて別にした。主な既存キャラクターの名前（紫・藍・椛・咲夜など）と同じ表記になるものは避けている。

## 漢字の当て方

| 当て方 | 内容 | 例 |
|---|---|---|
| 意味で当てる | 言葉の意味どおりの字を使う。いちばん読みやすい | 睨（にらみ）、梔子（くちなし）、一二三（ひふみ） |
| 音で当てる | 意味より音を優先して字を選ぶ（当て字） | 立枝（たつえ）、往乃（ゆきの） |
| 当て読み | 意味の近い字に、本来はない読み方をさせる。読みにくいので、ふりがなを出す前提 | 貼（ぺたり）、軋（みしり）、揺（ゆすら） |
