# 6面ボスの動機案

6面ボスが、なぜ誰かを強化して異変のきっかけを作ったのか。
[6面ボスの能力案](stage6-boss-abilities.md) の 3（器に注ぐ）と 6（力を前借りさせる）について、動機をそれぞれ10個考えた。

今の [物語](story.md)（「お返し祭り」異変）の設定に合わせて、暴走役は5面の天秤、異変は「幻想郷中の貸し借りが勝手に清算される」ことを前提にしている。
今の採用は 4（神輿）なので、3か6に切り替える場合の比較用。

---

## パターン3：器に注ぐ程度の能力（徳利の付喪神）

> 3にする場合、異変の舞台は「祭り」より「宴会」が合う。幻想郷中が酔っ払ったような大宴会の中で、貸し借りの清算が始まる。

| # | 動機 | 雰囲気 |
|---|------|--------|
| 3-1 | お酌がしたかっただけ | ゆるい・コミカル |
| 3-2 | 空っぽの器を放っておけなかった | 切ない・善意 |
| 3-3 | 自分が空になりたかった | 切ない |
| 3-4 | 器の大きさを確かめたかった | 好奇心・職人気質 |
| 3-5 | 宴会で見返したかった | コミカル |
| 3-6 | 友達が欲しくて盃を交わした | コミカル・少し切ない |
| 3-7 | 天秤の釣り合いを直そうとした | 善意・能力同士のつながりが強い |
| 3-8 | 天秤に頼まれた | どんでん返し |
| 3-9 | 片割れの徳利を探していた | 切ない・Extraにつながる |
| 3-10 | 酔わせて本音を聞きたかった | ミステリアス |

### 3-1. お酌がしたかっただけ

祝いの席で使われていた徳利。外の世界では徳利で酒を注ぐ宴会が減り、誰にも注げなくなって幻想入りした。
久しぶりに注ぐ相手（天秤）を見つけて嬉しくなり、止めどきが分からずに注ぎすぎた。

### 3-2. 空っぽの器を放っておけなかった

中身を空にされて捨てられた徳利にとって、「空っぽ」はいちばん寂しいこと。
無縁塚で、役目を失って空っぽになった天秤を見て、放っておけずに力を注いだ。

### 3-3. 自分が空になりたかった

長年注がれてきた酒と一緒に、持ち主たちの愚痴や悲しみまで溜め込んでしまい、重くて苦しかった。
中身を注ぎ出して楽になりたかった。注いだ先が、たまたま天秤だった。

### 3-4. 器の大きさを確かめたかった

相手の器の大きさを見極めるのが趣味。
「ものを量る道具の器は、どれくらいの大きさなのか」が気になって、どこまで入るか試してみたら溢れた。

### 3-5. 宴会で見返したかった

博麗神社の宴会では、いつも安酒用の徳利として隅に置かれている。
幻想郷の誰もが驚くほどの大宴会を開いて見返そうと、景気よく力を注いで回った。

### 3-6. 友達が欲しくて盃を交わした

婚礼の三々九度や、固めの盃で使われていた徳利。盃を交わせば仲間になれると思っている。
ひとりぼっちの天秤と盃を交わしたが、張り切って注ぎすぎた。

### 3-7. 天秤の釣り合いを直そうとした

片方の皿が軽く、傾いたまま捨てられていた天秤を見て、軽い方の皿に注いで釣り合わせてあげようとした。
ところが注ぎすぎて今度は逆に傾き、天秤は「釣り合わせなければ」と暴走を始めた。
天秤の皿そのものが「器」になるので、6面と5面の能力のつながりがいちばん強い。

### 3-8. 天秤に頼まれた

「もう一度必要とされたい。そのための力が欲しい」と、天秤の方から頼んできた。
断れない性格の徳利は、言われるままに注いでしまった。
暴走した本人が自分から力を求めていた、という真相になる。

### 3-9. 片割れの徳利を探していた

神前にお神酒を供える御神酒徳利（おみきどっくり）は、必ず二本一組で使われる。
片割れとはぐれて一本だけ幻想入りした彼女は、「対になる相手を探して」と天秤に力を注いだ。
天秤は幻想郷中のものに「釣り合いの相手」を求めて暴走する。
「対の相手」というテーマが、Extraのドッペルゲンガー（もう一人の自分）にも自然につながる。

### 3-10. 酔わせて本音を聞きたかった

酒の席では誰もが本音を漏らす。
捨てられた道具たちが本当は何を思っているのか知りたくて、天秤に注いだ。
天秤の本音は「もう一度、正しく量りたい」。その本音が暴走して異変になった。

## パターン6：力を前借りさせる程度の能力（高利貸しの鬼）

> 6にする場合、異変の舞台は「祭り」より、大晦日の掛け取り（年の暮れに貸し借りを清算する習わし）が合う。以前の [案B「帳尻合わせ」異変](story-ideas.md#案b帳尻合わせ異変) に近い形になる。

| # | 動機 | 雰囲気 |
|---|------|--------|
| 6-1 | 貸した分を一気に取り立てたい | 悪役・計算高い |
| 6-2 | 借りっぱなしが許せない | 鬼の正義・コミカル |
| 6-3 | 外の世界からの取り立て | スケールが大きい |
| 6-4 | 自分も借金まみれ | コミカル |
| 6-5 | 捨てられた道具に「未来」を貸したかった | 切ない・善意 |
| 6-6 | 一度も返してもらえなかった恨み | シリアス |
| 6-7 | 商売敵の質屋を潰したい | コミカル・3面と因縁 |
| 6-8 | 昔貸した大切なものを取り戻したい | ミステリアス |
| 6-9 | 人間と勝負がしたかった | 鬼らしい・熱血 |
| 6-10 | 利子で最強の鬼になりたい | 野心家 |

### 6-1. 貸した分を一気に取り立てたい

幻想郷中に小口の貸しがある高利貸し。
天秤に力を貸して幻想郷中の貸し借りを清算させれば、自分の貸し分も利子ごと一気に回収できる。
天秤は取り立ての道具として使われた。

### 6-2. 借りっぱなしが許せない

鬼は嘘と約束破りが大嫌い。
幻想郷には「死ぬまで借りてるだけ」と言う魔法使いのように、借りたものを返さない連中が多すぎる。
借りたものは返すのが筋だと、天秤に力を貸して清算させた。魔理沙との掛け合いが見どころになる。

### 6-3. 外の世界からの取り立て

幻想郷は、外の世界で忘れられたものを受け入れるばかりで何も返していない。
彼女は外の世界の「取り立て屋」で、その貸しを回収しに来た。
天秤の暴走は、幻想郷のものを外へ返させるための手段。異変の期限（忘れられたものが外へ返される）と直結する。

### 6-4. 自分も借金まみれ

実は本人も、旧地獄の元締めに大きな借りがあり、返済期限が迫っている。
利子を稼ごうと手当たり次第に力を貸していたら、いちばんの上客（天秤）が暴走した。

### 6-5. 捨てられた道具に「未来」を貸したかった

前借りできるのは、この先の未来がある者だけ。
捨てられた天秤に「あなたにはまだ先がある」と信じさせたくて、未来の力を貸した。
ところが天秤は、返すあてのない力を使い続けてしまった。

### 6-6. 一度も返してもらえなかった恨み

昔、困っていた人間たちに力を貸したが、誰一人として返しに来なかった。
「人間は借りを返さない」と恨み、幻想郷中の貸し借りを無理やり清算させようとした。
鬼が人間に失望して地上を去ったという原作の設定とも響き合う。

### 6-7. 商売敵の質屋を潰したい

3面の質屋とは長年の商売敵。
貸し借りを清算させれば質草は全部持ち主へ帰り、質屋は潰れる。3面ボスとの因縁が深まる。

### 6-8. 昔貸した大切なものを取り戻したい

ずっと昔、「必ず返す」と約束した誰かに大切なものを貸したが、返ってこない。
幻想郷中の貸し借りを清算させれば、それも戻ってくるはずだと考えた。
何を貸したのかは、エンディングかExtraで明かす。

### 6-9. 人間と勝負がしたかった

鬼は人間と勝負をするのが何より好き。
天狗と「借り物の力を持った道具が、博麗の巫女に勝てるか」という賭けをして、天秤に力を貸した。
異変そのものが、霊夢への挑戦状になっている。

### 6-10. 利子で最強の鬼になりたい

貸した力には利子がつき、その利子は自分の力になる。
幻想郷中に力を貸して利子を集め、最強の鬼になろうとした。
天秤の暴走は、利子を増やすためにわざと起こさせたもの。
