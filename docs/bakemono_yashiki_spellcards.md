# 化物屋敷異変 スペルカード・弾幕案

ボス7人（1〜6面ボスとExtraボス）の、通常弾幕とスペルカードの案。

- 名前は未定のため、ボスは「1面ボス」「Extraボス」のように登場する面で呼ぶ。スペル名にも名前は使っていない。
- 詳細構成で決めた家運システム、崩壊ギミック（5・6面）、方違えシステム（Extra）と組み合わせている。
- 決定稿の台詞や決め台詞を元ネタにしたスペルには、「テーマ」にそのことを書いている。
- 詳細構成（第2版）にあるスペルカード一覧は初期案。スペルカードと弾幕は、この資料を優先する。

## 難易度による違いの基本

| 難易度 | 違い |
|---|---|
| Easy | 弾の数と速さを大きく減らす。自機狙いの弾はほぼ使わない |
| Normal | 基本形。各スペルの「弾幕」に書いた内容 |
| Hard | 弾の数と速さを増やす。一部のスペルは「Hard/Lunaticのみ」で追加される |
| Lunatic | Hardに加えて、フェイントや二重の仕掛けが入る（各スペルの「Hard/Lunatic」の項を参照） |

## 1面ボス ｜ 鬼瓦の付喪神

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 瓦の欠片の形の弾、鬼の顔の大玉（鬼面弾）、睨みの細いレーザー |
| 戦闘の流れ | 中ボス（通常弾幕のみ）→ ボス：通常1 → スペル1 → 通常2 → スペル2（Hard/Lunatic：→ 通常3 → スペル3） |
| 弾幕の方針 | 1面なので、ちょん避けと誘導の基本を覚える弾幕。生まれたてらしく、弾の間隔が少し不揃い |

### 通常弾幕

- **通常1**：鬼面弾をゆっくり自機狙いで撃ち、そのまわりに瓦の小弾をばら撒く。
- **通常2**：左右に揺れながら、瓦の弾を扇状に3連射する。
- **通常3（Hard/Lunatic）**：鬼面弾を左右から交互に撃ち、間を瓦の小弾で埋める。

### スペルカード

#### 1. 瓦符「鬼瓦の睨み」

- **弾幕**：ボスが自機を「睨む」と、睨みの細いレーザーで狙いの線が引かれる。一拍おいて、その方向へ鬼面弾を中心とした瓦の弾の扇が飛んでくる。
- **避け方**：線が引かれたら、横に少しずらすだけで避けられる。ちょん避けの練習になる。
- **Hard/Lunatic**：睨みが2連続、3連続になる。Lunaticでは、ときどき目を逸らすふりをして逆方向にも撃つ。
- **テーマ**：鬼瓦がもともと持つ、睨みで魔を払う力。

#### 2. 屋符「屋根の上から失礼」

- **弾幕**：画面の上から瓦の形の弾が降ってくる。瓦は画面の下端（地面）に落ちると割れて、小弾になって上向きに跳ね返る。
- **避け方**：降ってくる瓦より、割れたあとの跳ね返りに注意する。画面の下に張り付きすぎない。
- **Hard/Lunatic**：瓦の数が増え、割れたときの小弾が多くなる。

#### 3. 縄符「ここから先は私の縄張り」（Hard/Lunaticのみ）

- **弾幕**：瓦の弾を並べて、画面に「境界線」を引く。線は少しずつ自機の側へ迫り、自機のいられる範囲がだんだん狭くなる。線の向こうからは鬼面弾が撃ち込まれる。
- **避け方**：線の継ぎ目が一定間隔で開くので、そこを抜けて線の向こう側へ出ると楽になる。
- **テーマ**：決定稿の「私の縄張りに入ってくるな」。

### 家運システムとの関わり

1面は家運システムのチュートリアルを兼ねる。瓦の弾を撃ち落とすと福アイテムが多めに出て、家運ゲージの仕組みを自然に覚えられる。

## 2面ボス ｜ 家守（ヤモリの妖怪）

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 虫の形の小粒弾（群れで動く）、尻尾の形の曲がるレーザー、灯りの光弾 |
| 戦闘の流れ | 中ボス（通常弾幕のみ）→ ボス：通常1 → スペル1 → 通常2 → スペル2 → 通常3 → スペル3（Hard/Lunatic：→ スペル4） |
| 弾幕の方針 | 壁や天井を這い回る動きと、自機に寄ってくる虫の群れが特徴 |

### 通常弾幕

- **通常1**：画面の左右の端（壁）に張り付いて移動しながら、横向きに虫弾の列を撃つ。
- **通常2**：画面の上端（天井）を這いながら、真下に虫弾を雨のように落とす。
- **通常3**：中央に戻り、虫弾の群れを放射状に撃つ。群れは少し遅れて自機の方へ寄ってくる。

### スペルカード

#### 1. 守符「家守の夜回り」

- **弾幕**：ボスが画面の端を一周するように這い回り、通った壁から内側へ向けて弾が伸びてくる。一周ごとに伸びる弾の列が増える。
- **避け方**：ボスと反対側の端は安全になりやすい。ボスの動きに合わせて、画面を回るように動く。
- **Hard/Lunatic**：二周目からは逆回りも混ざる。

#### 2. 虫符「湧き放題の天井裏」

- **弾幕**：天井から虫の群れの弾がばらばらと湧いて降ってくる。群れは途中でばらけて、ゆっくり自機の方へ寄ってくる。
- **避け方**：群れが寄ってくる性質を利用して、大きく動いて群れをまとめてから切り返す（誘導して避ける）。
- **Hard/Lunatic**：群れの数と、寄ってくる速さが上がる。
- **テーマ**：決定稿の「足がいっぱいあって、かわいいのに」。

#### 3. 尾符「トカゲの尻尾切り」

- **弾幕**：ボスの尻尾が、曲がるレーザーで画面をなぎ払う。ボスに一定のダメージを与えると尻尾が「切れて」独立し、画面を跳ね回りながら撃ってくる。ボスは新しい尻尾を生やして、同じ攻撃を続ける。
- **避け方**：切れた尻尾は一定時間で消える。撃ち込みすぎると尻尾が増えるので、攻撃の手加減が攻略になる。
- **Hard/Lunatic**：切れた尻尾が残る時間が長くなる。
- **テーマ**：危険が迫ると尻尾を切って逃げる、ヤモリやトカゲの習性。

#### 4. 灯符「軒下の誘蛾灯」（Hard/Lunaticのみ）

- **弾幕**：画面の中央に「灯り」の光弾が置かれ、虫弾が四方から灯りに向かって集まってくる。集まりきると灯りが弾けて、虫弾が一斉に飛び散る。
- **避け方**：灯りから離れた位置で虫の流れを見て、弾ける直前に、虫が通り過ぎたあとの灯りの近くへ入る。
- **テーマ**：夜、灯りに集まる虫を食べるヤモリの習性。

## 3面ボス ｜ ぬらりひょん

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 湯呑みの形の弾、茶柱のような細い針弾、表札の形の札弾、妖怪の行列の大玉 |
| 戦闘の流れ | 道中の中ボス（家主のふり）：通常 → 中ボススペル → 逃走 ／ ボス：通常1 → スペル1 → 通常2 → スペル2 → 通常3 → スペル3（Hard/Lunatic：→ スペル4） |
| 弾幕の方針 | いつの間にか現れる弾と、正体のすり替えがテーマ。見た目と動きが一致しない弾で惑わせる |

### 中ボス（道中、家主のふり）

#### 茶符「主人顔の一服」

- **弾幕**：お茶をすすりながら、湯呑みの形の弾をゆっくり回転させて広げる。ときどき「茶柱が立つ」と、湯呑みから細い針弾がまっすぐ伸びる。
- **避け方**：湯呑みの弾は遅い。茶柱の針弾だけ見ていればよい。
- **テーマ**：決定稿の、家主のふりをしてくつろいでいる場面と「源さん」の湯呑み。

### 通常弾幕

- **通常1**：気付くと画面のあちこちに弾が「上がり込んで」いる。前触れなく現れた小弾が、ゆっくり動き出す。
- **通常2**：左右へ素早く移動しながら、札弾をばら撒く。
- **通常3**：妖怪の影を左右に連れて、三方向から交差する弾を撃つ。

### スペルカード

#### 1. 瓢符「ぬらりくらりの上がり框」

- **弾幕**：弾が「いつの間にか」画面の中に現れる。最初は透けた状態で出現し、一拍おいて実体化してから動き出す。
- **避け方**：透けているうちは当たらない。実体化する前に、透けた弾の配置を見て逃げ道を決める。
- **Hard/Lunatic**：透けている時間が短くなる。Lunaticでは自機のすぐ近くにも現れる。
- **テーマ**：いつの間にか上がり込む程度の能力。

#### 2. 札符「表札の掛け替え」

- **弾幕**：表札の形の札弾が、赤と青の二種類飛んでくる。一定時間ごとに表札が「掛け替え」られ、赤と青の動き方（まっすぐ進む、曲がる）が入れ替わる。
- **避け方**：掛け替えの合図（札が一瞬裏返る）を見て、動き方が変わる前提で位置を取る。
- **Hard/Lunatic**：掛け替えの間隔が短くなる。Lunaticでは、裏返るふりだけして入れ替わらないことがある。
- **テーマ**：決定稿の「表札は『鈴木』」。家主を偽るぬらりひょんの、正体のすり替え。

#### 3. 逃符「勝手口からお暇」

- **弾幕**：ボスが画面の端から端へ逃げ回り、逃げた跡に弾の列が残る。跡の弾は少し遅れて、自機の方へ流れてくる。
- **避け方**：ボスの逃げる先を先回りしようとせず、跡の弾が流れてくる向きに合わせて動く。
- **Hard/Lunatic**：逃げる速さと、残る弾の数が増える。
- **テーマ**：決定稿の「お邪魔しましたー！」の逃げ足。

#### 4. 総大将「百鬼夜行の先頭」（Hard/Lunaticのみ）

- **弾幕**：ボスの背後に妖怪の行列が現れ、大玉の列になって画面を横切っていく。列と列の間を、ボスの撃つ小弾が埋める。
- **避け方**：行列の大玉は決まった道筋を通る。行列の切れ目を待って抜ける。
- **テーマ**：後の時代に「妖怪の総大将」とされた話と、決定稿の「逃げ足だけは総大将並みだな」。

## 4面ボス ｜ 大黒柱の付喪神

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 柱や梁の形の太いレーザー、木組みの格子、部屋の形の囲い弾、上棟式の餅（白い大玉） |
| 戦闘の流れ | 中ボス（家鳴の子分たちの群れ）→ ボス：通常1 → スペル1 → 通常2 → スペル2 → 通常3 → スペル3 →（Hard/Lunatic：スペル4 →）通常4 → 最後のスペル |
| 弾幕の方針 | 家を「建てる」弾幕。画面が柱や壁で区切られ、決められた通り道を進ませる |

### 通常弾幕

- **通常1**：梁のレーザーを縦横に渡し、その間に小弾を流す。
- **通常2**：柱を中心に、木組みの格子状に弾を広げる。
- **通常3**：部屋の形の囲い弾をいくつか置き、囲いの中から弾を撃つ。
- **通常4**：柱を軋ませながら、四方へ太い梁のレーザーを順に振る。

### スペルカード

#### 1. 柱符「大黒柱の屋台骨」

- **弾幕**：ボスを中心に、柱（縦のレーザー）と梁（横のレーザー）が組み上がり、画面が格子に区切られる。格子の中を、小弾が跳ね返りながら飛び交う。
- **避け方**：格子が組み上がる前に出る予告線を見て、広いマスに入る。
- **Hard/Lunatic**：格子が細かくなり、途中で組み替えが入る。

#### 2. 戸符「玄関から入れ」

- **弾幕**：画面の上から下へ、弾でできた壁が何枚も迫ってくる。壁にはそれぞれ一か所だけ「玄関」（通り抜けられる隙間）がある。玄関以外の場所を撃って壁を抜こうとすると、壁から弾が撃ち返される。
- **避け方**：壁ごとに玄関の位置が違う。次の壁の玄関を見ながら、素早く移動する。
- **Hard/Lunatic**：壁が迫る速さが上がり、玄関が狭くなる。Lunaticでは、玄関の位置が途中で一度ずれる。
- **テーマ**：決定稿の「…………玄関から入れ」と、壁を抜いて入ってきた自機への怒り。

#### 3. 建符「百間継ぎの建て増し」

- **弾幕**：部屋の形をした弾の囲いが、ボスのまわりから次々に「建て増し」されて画面を埋めていく。画面がいっぱいになりかけると、古い部屋から順に崩れて小弾になる。
- **避け方**：建て増しの順番は決まっている。最後に建つ場所（いちばん遅く埋まる場所）で待つ。
- **Hard/Lunatic**：建て増しの速さが上がり、崩れたときの小弾が増える。
- **テーマ**：人里から借りてきた部屋をつなぎ合わせた百間屋敷と、決定稿の「十四だ！」（ぶち抜かれた部屋の数）。

#### 4. 棟符「棟上げの餅撒き」（Hard/Lunaticのみ）

- **弾幕**：上棟式の餅撒きのように、白い大玉の餅弾が山なりの軌道で四方にばら撒かれる。餅は落ちると小さく割れて広がる。
- **避け方**：山なりなので、落ちる位置を見て入れ替わるように避ける。餅弾を撃ち落とすと福アイテムが出る（家運システム）。
- **テーマ**：家の骨組みができたことを祝う上棟式。

#### 5. 家符「家を支える者の意地」（4面の最後のスペル）

- **弾幕**：画面全体が軋み、頭上に梁の形の弾が並ぶ。ボスが力を緩めるたびに、梁が一斉に落ちてくる。体力が減るほど梁の数が増え、落ちる間隔が短くなる。
- **避け方**：梁は落ちる前に震える。震えている梁の真下から離れる。
- **Hard/Lunatic**：落ちた梁が床で跳ね、もう一度小弾を撒く。
- **テーマ**：自分が倒れれば屋敷が崩れると分かったうえで、最後まで踏ん張る大黒柱。撃破と同時に屋敷が軋み、崩壊が始まる演出につなげる。

## 5面ボス ｜ 家鳴（やなり）

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 煤（黒い煙の粒）、木片や瓦礫の弾、小鬼の形の弾（子分の家鳴） |
| 戦闘の流れ | 中ボス（落ちてくる大天井、ギミック）→ ボス：通常1 → スペル1 → 通常2 → スペル2 →（Hard/Lunatic：通常3 → スペル3 →）通常4 → スペル4 → 耐久スペル |
| 弾幕の方針 | 崩壊ギミック（落下物と床の傾き）が常に重なる。最後は、座敷わらしを逃がすための時間稼ぎとして耐久スペルで締める |

### 崩壊ギミックとの関わり

5面の戦闘中はずっと、梁や瓦が上から落ちてくる（当たると被弾、撃つと壊せて福アイテムが出る）。屋敷が傾くと、敵弾も傾いた方向へ流される。スペルが進むほど、傾きと落下物が増えていく。

### 通常弾幕

- **通常1**：画面を揺らしながら、柱の位置から弾を不規則に伸ばす。
- **通常2**：子分の家鳴を左右に呼び出し、子分から小弾を撃たせる。
- **通常3（Hard/Lunatic）**：煤をばら撒き、視界を少し狭める。
- **通常4**：崩れかけた廊下を背に、扇状の弾を連射する。

### スペルカード

#### 1. 鳴符「夜中の家鳴り」

- **弾幕**：「ギシッ」という軋みに合わせて画面全体が揺れ、あちこちの柱の位置から弾が不規則に伸びる。軋むたびに、弾の向きが少しずつ変わる。
- **避け方**：軋みの音が予告になる。音のリズムを覚えて、弾が伸びてくる柱から離れる。
- **Hard/Lunatic**：軋みの間隔が短くなり、Lunaticでは音と揺れがずれることがある。
- **テーマ**：夜中に家を揺すって軋ませる、家鳴の言い伝え。

#### 2. 古符「一夜百年の煤払い」

- **弾幕**：撃たれた弾が、時間とともに「古びて」いく。最初は白くて速い弾が、だんだん茶色くて遅い弾になり、最後は黒い煤になって画面に漂う。
- **避け方**：新しい白い弾は速いが少ない。古い煤は遅いが残り続けるので、煤の少ない場所を確保しながら避ける。
- **Hard/Lunatic**：古びる速さが上がり、煤が残る時間が長くなる。
- **家運**：このスペルの間は、家が古びるのに合わせて家運ゲージがじわじわ減る。
- **テーマ**：人里の家を一晩で百年分古びさせた能力。

#### 3. 鳴符「天井裏の大行進」（Hard/Lunaticのみ）

- **弾幕**：子分の家鳴たちが、天井（画面の上）から一斉に降ってくる。着地した子分は、その場で跳ねながら小弾を撒く。
- **避け方**：降ってくる子分は撃って減らせる。減らすほど後半が楽になる。

#### 4. 家符「座敷様の新しいお家」

- **弾幕**：屋敷の間取り図のような弾幕。弾でできた壁と部屋が画面に描かれ、その中を弾が走る。崩れかけなので、ところどころ壁が抜けている。
- **避け方**：抜けている壁が通り道になる。部屋から部屋へ移りながら避ける。
- **Hard/Lunatic**：壁の抜けている場所が、時間とともに移る。
- **テーマ**：座敷様のために用意した百間屋敷。

#### 5. 崩符「崩れる廊下の時間稼ぎ」（耐久スペル、5面の最後）

- **弾幕**：ボスは攻撃を受け付けず、逃げ道を塞ぐように弾を撒き続ける。背景の廊下が崩れ、落下物と床の傾きが最大になる。制限時間いっぱい耐えきれば撃破扱い。
- **避け方**：傾きで弾が流される方向の、上流側にいる。落下物の影（落ちる位置の予告）に注意する。
- **テーマ**：座敷様が逃げ切るまでの時間稼ぎ。撃破後の決定稿の台詞「座敷様……申し訳ありません」につながる。

## 6面ボス ｜ 座敷わらし

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 手鞠の形の弾、小判の形の弾（福アイテムと似ているので注意）、足跡の形の弾、金色の光弾 |
| 戦闘の流れ | 道中の中ボス（5面ボス、ぼろぼろ）：中ボススペル ／ ボス：通常1 → スペル1 → 通常2 → スペル2 → 通常3 → スペル3 → 通常4 → スペル4 →（Hard/Lunatic：スペル5 →）スペル6 → ラストスペル |
| 弾幕の方針 | 子どもの遊び（手鞠、隠れ鬼）と、福の神としての栄枯盛衰の二本立て。家運システムが最も強く関わる |

### 家運システムとの関わり

6面ボス戦では、ボスの近く（画面の上の方）にいるほど家運ゲージが上がる。福の神に近づくほど得をするが、そのぶん危ない。

### 中ボス（道中、ぼろぼろの5面ボス）

#### 守符「指一本触れさせない」

- **弾幕**：ぼろぼろの体で撃つ、弱々しい扇状の弾。一度倒しても、一度だけ立ち上がって同じ弾幕を撃ち直してくる。
- **避け方**：弾幕自体は弱い。立ち上がったときの撃ち直しに油断しない。
- **テーマ**：決定稿の「あの子には指一本触れさせない！」「なんとかここで食い止めなければ」。

### 通常弾幕

- **通常1**：手鞠の弾を、跳ねるような軌道でばら撒く。
- **通常2**：小判の弾を円形に広げる。福アイテムと見間違えないように、色を変えておく。
- **通常3**：足跡の形の弾を残しながら、画面をゆっくり歩き回る。
- **通常4**：金色の光弾を花のように開く。

### スペルカード

#### 1. 童符「手鞠唄の数え歌」

- **弾幕**：数え歌の拍子に合わせて、手鞠の弾が一つずつ増えて画面中を跳ね回る。「ひとつ、ふたつ……」と十まで数えると、手鞠が一斉に弾ける。
- **避け方**：数え始めは手鞠が少ない。数が増える前に、跳ね返りの軌道を覚えておく。
- **Hard/Lunatic**：手鞠の跳ねる速さが上がり、弾けたときの小弾が増える。

#### 2. 福符「座敷わらしの足音」

- **弾幕**：姿の見えない足音だけが、畳の上を歩き回る。足音の通り道が先に薄く光り、少し遅れてその道筋に弾が走る。
- **避け方**：光った道筋をまたがない位置で待つ。足音の向きが変わる瞬間に注意する。
- **Hard/Lunatic**：足音が二人分になる。

#### 3. 惹符「誰もが振り向く福の神」

- **弾幕**：画面中に撒かれた弾が、ボスに惹きつけられるようにボスの方へ集まっていく。集まりきると、ボスを中心に花のように開く。
- **避け方**：集まる途中の弾は、自機の後ろからも来る。ボスに近づくほど巻き込まれやすいが、家運も上がる。
- **Hard/Lunatic**：集まる速さが上がり、開いたあとの弾が二重になる。
- **テーマ**：人を惹きつける力。家鳴や大黒柱が彼女のために動いたことそのもの。

#### 4. 栄符「千客万来・家運隆盛」

- **弾幕**：撃ち込むほど弾幕が豪華になっていく。小判の弾が増え、金色の弾が混ざる。ただし弾と一緒に、福アイテムも大量に出る。
- **避け方**：欲張って福アイテムを取りに行くと危ない。家運を取るか、安全を取るかの駆け引き。
- **Hard/Lunatic**：豪華になる速さが上がる。
- **テーマ**：霊夢ルートの決め台詞「千客万来、家運隆盛……」。

#### 5. 鬼符「座敷童子の隠れ鬼」（Hard/Lunaticのみ）

- **弾幕**：ボスが姿を消し、画面に並んだ瓦礫の陰のどれかに隠れる。隠れている場所から弾が撃たれ、数秒ごとに隠れ場所が変わる。本物の隠れ場所を撃つとダメージが入る。
- **避け方**：弾の出どころを見て、隠れ場所を当てる。外れの瓦礫を撃っても何も起きない。

#### 6. 傾符「去りゆく家の没落」

- **弾幕**：背景の屋敷が傾くのに合わせて、画面の弾がすべて傾いた方向へ流れ落ちていく。ボスが「去る」動きをするたびに、傾きが大きくなる。
- **避け方**：流れの上流側を保つ。傾きが戻る瞬間に、位置を立て直す。
- **Hard/Lunatic**：傾く向きが左右で入れ替わる。
- **テーマ**：魔理沙ルートの決め台詞「わたしが去れば家は傾き、留まれば家は栄える……」。

#### 7. ラストスペル「座敷童子のいる家」

- **弾幕**：屋敷の崩壊が最高潮に達し、それまでのスペルの要素（手鞠、足音、惹きつけ、小判）が順番に重なっていく。家運ゲージを最大にすると自機が強化されるが、そのぶん弾幕も最大の密度になる。
- **避け方**：家運を上げて火力で押し切るか、家運を抑えて弾幕を薄く保つか、プレイヤーが選べる。
- **テーマ**：住み着いた家を栄えさせる座敷わらしの総決算。撃破後、決定稿の「（屋敷が完全に崩れ落ち、部屋が光になって人里へ帰っていく）」へつながる。

## Extraボス ｜ 方位神（金神）

| 項目 | 内容 |
|---|---|
| 弾の見た目 | 金色の札弾、方位盤の光線（放射状のレーザー）、十二支の印の大玉、瓦礫の弾（前半戦）、金色の針弾 |
| 戦闘の流れ | 前半戦（瓦礫の上、中ボス）：通常 → 中ボススペル1 → 中ボススペル2 → 方位盤の異界へ ／ 道中 ／ 本戦：通常とスペルを交互に → 耐久スペル → ラストスペル |
| 弾幕の方針 | 方違えシステムが全スペルに関わる。どの方角へどう動くかを考えさせる弾幕 |

### 方違えシステムとの関わり

画面の端に方位盤が表示され、金神のいる方角（凶方）が光る。凶方へ向かって動くと弾幕が激しくなり、家運ゲージも減る。凶方を避けて回り道をするのが攻略の鍵で、凶方はスペルカードごとに移り変わる（遊行）。

### 前半戦（瓦礫の上、中ボス）

#### 中1. 瓦符「百間屋敷の置き土産」

- **弾幕**：吹き飛ばした瓦礫を弾にして撃ち返してくる。大きな瓦礫は途中で割れて破片になり、破片は凶方から飛んでくる。
- **避け方**：大きな瓦礫が割れる位置を見極め、破片が飛んでくる凶方を避ける。
- **テーマ**：魔理沙ルートの決め台詞「百部屋の瓦礫など、妾には塵も同然」。

#### 中2. 鬼門「艮の鬼門封じ」

- **弾幕**：画面の右上（北東＝艮）から、鬼門封じの札の弾が押し寄せる。札は画面に貼り付くように止まり、しばらくすると一斉に剥がれて飛び散る。
- **避け方**：札が貼り付いている間に、剥がれたあとの軌道を予想して位置を取る。
- **テーマ**：百間屋敷が建てられた艮（北東）の方角。古くから鬼門として忌まれてきた。

### 通常弾幕（本戦）

- **通常1**：方位盤の八方から、金色の札弾を順番に撃つ。
- **通常2**：方位盤の光線を回転させながら、小弾をばら撒く。
- **通常3**：十二支の印の大玉を時計回りに撃ち出す。
- **通常4**：金色の針弾を扇状に連射し、凶方側だけ密度を上げる。

### スペルカード（本戦）

#### 1. 方符「金神の遊行」

- **弾幕**：金神が方位盤の八方を順に移り（遊行）、移った方角から弾幕を撃つ。方角が変わるたびに、凶方も移る。
- **避け方**：次の移動先が方位盤で予告される。凶方に入らないよう、移動先と反対側へ回る。
- **テーマ**：年や季節ごとに方角を巡る金神の遊行。Extraの基本ルールを覚えるスペル。

#### 2. 祟符「方違え知らず」

- **弾幕**：自機が凶方へ向かって動くほど、弾の数が増えていく。凶方と反対へ動くと弾が減る。まっすぐ逃げず、回り道をするように動くのが正解。
- **避け方**：方違え（いったん別の方角へ回ってから目的の位置へ向かう）を体で覚える。
- **テーマ**：方違えを忘れた世の中への怒り。

#### 3. 干支「十二支方位盤」

- **弾幕**：背景の方位盤が回り、子・丑・寅……と十二の方角から順番に、干支の印の大玉と小弾が撃ち込まれる。一周するごとに速くなる。
- **避け方**：次に撃ってくる方角は時計回りに決まっている。先回りして、その反対側へ動く。

#### 4. 暦符「大将軍の三年塞がり」

- **弾幕**：画面の一方向が、弾の壁で丸ごと塞がれる。塞がった方向は長い間開かず（三年塞がり）、残りの方向から弾幕が来る。時間とともに、塞がる方向が増えていく。
- **避け方**：使える空間がだんだん狭くなる。塞がる順番を覚えて、最後まで残る空間へ早めに移る。
- **テーマ**：同じく陰陽道の方位神・大将軍の「三年塞がり」。

#### 5. 遊符「八将神の行列」

- **弾幕**：方位を司る八柱の神の行列が、八方から弾の列になって画面を通り過ぎる。八つの列は、それぞれ色と速さが違う。
- **避け方**：列と列が交差する場所を避け、交差のあとにできる空白へ入る。
- **テーマ**：陰陽道の方位の神々、八将神。

#### 6. 金符「怒髪、金色に燃ゆ」

- **弾幕**：逆立った金色の髪から、針のような弾が画面全体に降り注ぐ。針は落ちる途中で向きを変え、自機を狙ってくる。
- **避け方**：針の向きが変わる瞬間に小さく動く。大きく動くと、別の針に当たる。
- **テーマ**：登場したときのぶち切れ。

#### 7. 天地「東西南北、天地四方」

- **弾幕**：東西南北の四方と、天（画面の上）と地（画面の下）、あらゆる方向から同時に弾が来る。方位盤の凶方が順番に光り、光った方向の弾だけが速くなる。
- **避け方**：逃げ場はない。凶方から来る速い弾だけに集中し、ほかの弾はゆっくり避ける。
- **テーマ**：霊夢ルートの決め台詞「東西南北、天地四方。この世に妾の眼の届かぬ方角はない」。

#### 8. 耐久スペル「四方塞がり」

- **弾幕**：四方すべてが凶方になり、どこへ動いても弾が増える。金神は攻撃を受け付けず、一定時間耐えきれば撃破扱い。
- **避け方**：動けば動くほど弾が増える。最小限の動きで避ける、ちょん避けの総決算。

#### 9. ラストスペル「金神七殺」

- **弾幕**：七つの波で押し寄せる、祟りの総決算。波ごとに、それまでのスペルの要素（遊行、方違え、十二支、塞がり、行列、針）が一つずつ使われ、七つ目の波ですべてが重なる。
- **避け方**：波ごとに要素が違うので、それぞれのスペルの避け方を思い出しながら進む。七つの波を数え終えれば撃破。
- **テーマ**：金神の祟りが家族七人に及ぶという「金神七殺」の言い伝え。
