# 化物屋敷異変 セリフ決定稿

1〜6面とExtraの、霊夢ルート・魔理沙ルートの会話の決定稿。会話集の案をもとに書き直していただいたものを、表記を整えて清書した。

## 表記のきまり

| 表記 | 意味 |
|---|---|
| 1面ボス〜6面ボス、Extraボス | 名前が未定のため、話し手は登場する面で表記する |
| 〔5面ボスの名前〕 | 台詞の中で名前が入る部分。名前が決まったら置き換える |
| 「」の中の（　） | 心の声（口に出していない台詞） |
| 単独の行の（　） | ト書き（演出の指示） |

清書で直した箇所と、確認点への対応は、最後の「付録」にまとめた。

### 確認点への対応（すべて反映済み）

清書のあとで挙げた確認点は、修正案をすべて反映した。修正案が2つあったものは、もとの言い回しに近い1つ目を採用した。

| 場所 | 気になっていた点 | 反映した内容 |
|---|---|---|
