# 東方二次創作 異変案 60選

## 構成ルール

- **型A（4面実行犯）**
  - 4面が異変を起こす。
  - 原因を作ったのは6面（真犯人）。6面が4面に働きかけたか、4面を暴走・増長させたことで異変が起きた。
  - 5面は6面の護衛・手下・部下。
- **型B（5面実行犯）**
  - 5面が異変を起こす。
  - 4面は異変に関わらない（自由枠）。
  - 6面は5面の主や黒幕で、異変の根本原因。

型Aの「6面の関与タイプ」

| タグ | 意味 |
| --- | --- |
| 働きかけ | 唆す・命令する・取引するなど、6面が意図して4面を動かした |
| 暴走 | 6面が与えた力や道具を、4面が制御できなくなった |
| 増長 | 6面におだてられたり崇められたりして、4面が調子に乗った |
| 無自覚 | 6面自身に異変を起こすつもりはなかった |

- 【既存】は原作キャラクター（能力は原作の表記どおり）。それ以外はオリジナル。
- 型A：36本／型B：24本

## 第一章　天候・自然・天体

### 01. 雲海異変　〔型A／働きかけ〕

> 雲が地上まで降りてきて、妖怪の山の中腹より下がすべて雲の海に沈んだ。人里は昼でも薄暗く、洗濯物は乾かず、あちこちでカビが大発生している。

- **4面【実行犯】綿雲 もくれ**（わたぐも もくれ）／雲の妖精
  - 能力：雲を膨らませる程度の能力
  - 動機：地上に落ちてきた小さな雲の妖精。「雲海を作ってくれたら天界に住まわせてあげる」という6面の約束を信じ、幻想郷中の雲を膨らませて地上へ引きずり下ろした。
- **5面【6面の従者】羽衣 ささら**（はごろも ささら）／天女
  - 能力：羽衣で空を泳ぐ程度の能力
  - 立場：6面に仕える天女。主の追放に巻き込まれて一緒に天界を追われたが、それでも忠実に護衛を務める苦労人。
- **6面【真犯人】天降 みそら**（あまくだり みそら）／天人（追放寸前）
  - 能力：雲より上を天界と定める程度の能力
  - 真相：素行不良で天界を追放されかけている天人。自分の能力の屁理屈を使い、「地上を雲で覆えば、雲から突き出た妖怪の山の上半分は丸ごと"私の天界"になる」と考えた。4面との約束は、最初から守る気がない。

### 02. 白夜異変　〔型B〕

> 日が沈まなくなった。夜行性の妖怪は弱り、人間は眠れず、吸血鬼は屋敷から一歩も出られない。どこからか一日中、鶏の鳴き声が聞こえる。

- **5面【実行犯】金鶏 あかつき**（きんけい あかつき）／金鶏
  - 能力：夜明けを呼ぶ程度の能力
  - 動機：主が暗闇を怖がって泣くので、日が傾くたびに鳴いて夜明けを呼び戻している。天岩戸の神話でも、日の神を外へ呼び出したのは鶏の声だった。一日中鳴いているので声はガラガラ。
- **6面【黒幕】天戸 ひるめ**（あまと ひるめ）／日輪の神霊
  - 能力：日輪を留める程度の能力
  - 真相：千年のあいだ岩屋の奥に閉じ込められていた太陽の欠片。暗闇の記憶がトラウマになり、外に出た途端「夜が来るのが怖い」と5面に泣きついた。悪意はない。夜を二度と見たくない一心で、太陽を空に縫い留めている。

### 03. 流星異変　〔型A／増長〕

> 毎晩、数えきれないほどの流れ星が降り注ぐ。落ちた星は「星の欠片」になり、拾えば願いが叶うと噂されて、人も妖怪も夜通し星拾いに夢中。そのぶん夜空の星は減り続けている。

- **4面【実行犯】星降 ほしな**（ほしふり ほしな）／流れ星の妖精
  - 能力：流れ星を降らせる程度の能力
  - 動機：願い事をされるのが何より嬉しい。6面に「もっと降らせれば、もっとたくさんの人に感謝される」とおだてられ、夜空の星を片っ端から落として回るようになった。
- **5面【6面の護衛】鵲 わたり**（かささぎ わたり）／鵲の妖怪
  - 能力：橋を架ける程度の能力
  - 立場：七夕の夜、天の川に橋を架ける鵲の一羽。6面の護衛として、星の欠片を狙う者を追い払っている。
- **6面【真犯人】天川 ささね**（あまかわ ささね）／七夕の笹の神
  - 能力：願い事を集める程度の能力
  - 真相：年に一度、七夕の日にしか願い事を受け取れない神。星の欠片に込められた願いは、最終的にすべて彼女のもとへ集まる。「毎日が七夕」になるよう4面を煽ったが、星が尽きれば七夕そのものが消えることには気づいていない。

### 04. 永久凍土異変　〔型A／暴走＋増長〕

> 真夏の霧の湖から凍結が広がり始めた。その氷はどんな炎でも溶けず、田畑も家も少しずつ飲み込まれていく。

- **4面【実行犯】チルノ**【既存】／妖精
  - 能力：冷気を操る程度の能力
  - 動機：6面から「永久凍土の欠片」をもらい、溶けない氷を作れるようになった。「あたいったら最強ね！」と完全に調子に乗り、幻想郷を丸ごと氷漬けにして最強を証明しようとしている。
- **5面【6面の従者】氷守 ふゆり**（ひもり ふゆり）／雪女
  - 能力：冷気を閉じ込める程度の能力
  - 立場：氷室の番人を代々務める雪女。6面には忠実だが、チルノのはしゃぎっぷりには内心ハラハラしている。
- **6面【真犯人】氷室 せつな**（ひむろ せつな）／氷室の神
  - 能力：永遠に溶けない氷を作る程度の能力
  - 真相：かつて夏のために氷を蓄えた「氷室」の神。冷蔵庫が普及して外の世界で忘れられ、幻想入りした。「夏の氷のありがたみ」を思い出させようと最強の氷精に力を貸したが、チルノは想像以上に調子に乗った。少し困ってはいるが、止める気はない。

### 05. 大凪異変　〔型B〕

> 幻想郷から風が消えた。天狗は思うように飛べず、風車は止まり、煙や瘴気が溜まって空気がどんよりと澱んでいる。

- **5面【実行犯】風留 しずか**（かざとめ しずか）／風袋の付喪神
  - 能力：風を袋に詰める程度の能力
  - 動機：主の桜が散らないよう、幻想郷中の風を片っ端から袋に詰めて回った。もとは風神の持ち物だった古い風袋。詰め込んだ風でパンパンに膨らみ、今にも破裂しそう。
- **6面【黒幕】花守 とこよ**（はなもり とこよ）／山桜の神霊
  - 能力：花を咲かせ続ける程度の能力
  - 真相：樹齢千年の山桜に宿る神霊。今年の開花が最後になると悟り、「一度でいいから散らない満開を見たい」と願った。だが風がなければ種も花粉も運ばれず、幻想郷の植物は次の世代を残せなくなりつつある。

### 06. 色抜け異変　〔型A／働きかけ〕

> 幻想郷から色が抜けていく。紅魔館は灰色に、向日葵畑は白黒に。抜けた色はすべて、空に架かったまま消えない巨大な虹へ吸い上げられている。

- **4面【実行犯】紺屋 そめ**（こうや そめ）／染め物の妖怪
  - 能力：色を抜き取る程度の能力
  - 動機：「紺屋の白袴」を地で行く、自分の服だけは染められない染め物妖怪。6面に「すべての色を集めれば、誰も見たことのない究極の色が作れる」と唆され、幻想郷中から色を抜き取った。
- **5面【6面の伴侶】蜺 あや**（げい あや）／副虹の化身
  - 能力：光を曲げる程度の能力
  - 立場：主虹に寄り添う淡い副虹。古くは虹の雄を「虹」、雌を「蜺」と呼んだ。6面の片割れとして、その昇天を見届けようとしている。
- **6面【真犯人】天梯 ななお**（あまはし ななお）／虹の大蛇
  - 能力：七色を操る程度の能力
  - 真相：虹を天に架かる蛇とみなした古い信仰から生まれた大蛇。雨上がりの空に架かるだけの自分を嫌い、龍となって天へ昇ることを悲願としている。幻想郷中の色を体に取り込めば龍になれると信じ、4面に色を集めさせた。

### 07. 水没異変　〔型A／働きかけ＋暴走〕

> 霧の湖の水位が際限なく上がり、低地が次々と水没していく。しかも水はなぜかしょっぱい。

- **4面【実行犯】わかさぎ姫**【既存】／人魚
  - 能力：水中だと力が増す程度の能力
  - 動機：6面から潮を満たす宝珠「潮満珠（しおみつたま）」を渡され、「世界が全部海になれば、あなたはどこでも最強」と囁かれた。どこへでも泳いで行けるのが楽しくて、珠の力を止められなくなっている。
- **5面【6面の従者】玉手 はこ**（たまて はこ）／竜宮の大亀
  - 能力：年月を閉じ込める程度の能力
  - 立場：6面を背に乗せて竜宮から来た大亀。彼女の弾に当たると、ほんの少しだけ時間が飛ぶ。
- **6面【真犯人】海原 おとひめ**（うなばら おとひめ）／海神の末裔
  - 能力：潮の満ち干きを操る程度の能力
  - 真相：竜宮の姫。幻想郷には海がなく、海への信仰がまったく存在しないことに目をつけた。「海がなければ作ればいい」と湖を海に変え、海神としての信仰を一から築こうとしている。

### 08. 蝗害異変　〔型A／増長〕

> 季節に関係なく作物が実り続け、人里は空前の豊作に沸いた。しかし実りすぎた作物は腐り始め、山の向こうからは黒い雲——蝗の大群が迫ってくる。

- **4面【実行犯】秋 穣子**【既存】／神
  - 能力：豊穣を司る程度の能力
  - 動機：6面に「あなたこそ真の豊穣神」と熱烈に崇められ、生まれて初めて盛大な信仰を受けて舞い上がった。秋が終わっても実りを与え続け、止め時を完全に見失っている。
- **5面【6面の部下】羽音 いなご**（はおと いなご）／蝗の妖怪
  - 能力：群れを率いる程度の能力
  - 立場：蝗の大群を率いる兵隊長。号令ひとつで空を黒く染める。
- **6面【真犯人】喰野 あまね**（くらの あまね）／蝗の王
  - 能力：食べ尽くす程度の能力
  - 真相：穣子を持ち上げて過剰に実らせたのは、それを群れごと喰らい尽くす大宴のため。狙いは幻想郷の飢饉そのもの。60本の中でも数少ない、純粋な悪意の黒幕。

### 09. 雷鳴異変　〔型B〕

> 雷が昼夜鳴り止まない。人に落ちることはないが、雷鳴が響くたびに人里の住人の「へそ」が一つずつ消えていく。

- **5面【実行犯】轟 ぴりか**（とどろき ぴりか）／雷獣
  - 能力：雷に乗る程度の能力
  - 動機：主の命令で、雷に紛れて幻想郷中のへそを集めて回っている。へそが何に使われるのかは、よく分かっていない。
- **6面【黒幕】鳴神 いかづち**（なるかみ いかづち）／雷神
  - 能力：稲妻を束ねる程度の能力
  - 真相：避雷針と気象学のせいで誰も雷を恐れなくなり、幻想入りした雷神。「幻想郷のへそ（中心）に雷を落とせば、幻想郷の天候を支配できる」という言い伝えを信じている。だが"へそ"がどこか分からないので、とりあえず住人のへそを片っ端から調べさせている。

### 10. 樹海異変　〔型A／働きかけ→暴走〕

> 魔法の森が一晩ごとに広がり、ついに人里の目前まで迫った。森に呑まれた道は、二度と同じ場所には通じない。

- **4面【実行犯】芽吹 もえぎ**（めぶき もえぎ）／木霊
  - 能力：草木を育てる程度の能力

  - 能力：神意を伝える程度の能力
  - 立場：神の使いの鹿。6面の神意を4面に伝える役目を担い、護衛も務める。
- **6面【真犯人】斎宮 いつき**（さいぐう いつき）／斎王の神霊
  - 能力：巫女を選ぶ程度の能力
  - 真相：「理想の巫女」という概念そのものが神霊化した存在。妖怪と宴会ばかりしている霊夢に失望し、自分好みの巫女を選び直そうとした。人間と妖怪の均衡という幻想郷の根幹を揺るがすので、シリーズ終盤向けの異変。

## 補足：ストーリーの流れの例

- **型A**
  - 4面：4面を倒しても異変が止まらない。4面の口から「力をくれた人がいる」「あの方に言われた」と6面の存在がほのめかされる。
  - 5面：6面の本拠地で5面が立ちはだかる。
  - 6面：真相が明かされる。
  - 6面の関与が「無自覚」の話（16・33・36・37・46）は、6面戦の会話が漫才寄りになりやすい。
- **型B**
  - 4面は自由枠。異変の被害者を置くと物語がつながりやすい。例：02なら夜を奪われた夜行性の妖怪、44なら酒を奪われた鬼、58なら八卦炉が使えない魔理沙。
