# 架空の異変アイデア 50選（4〜6面構成版）

東方二次創作STG用のネタ帳・改訂版。`incident_ideas.md` の30個を下敷きにボスの構図を加え、新たに20個を足して50個にした。

## 構成ルール

- 異変を起こすのは **4面** か **5面** のボス（★印）。
- **6面が真犯人**。6面が実行犯に働きかけたり、暴走させたり、調子に乗らせたりしたせいで異変が起きた。
- **4面が起こした場合**: 5面は6面の護衛・手下・部下。
- **5面が起こした場合**: 4面は物語に絡まないので決めていない（5面と6面だけ）。

### 発生の経緯タグ

| タグ | 意味 |
|------|------|
| 〔働きかけ〕 | 6面が唆す、誘導する、罠にかける |
| 〔増長〕 | 6面がおだてて調子に乗らせる |
| 〔暴走〕 | 6面が力を与えたり条件を変えたりした結果、実行犯の力が制御できなくなる |

## 詳細

### 01. 褪色異変（たいしょくいへん）〔働きかけ〕

幻想郷から色が抜け落ち、墨絵のような白黒の世界になっていく。

- **★4面（実行犯）** 栂尾 すみえ（とがのお すみえ）｜付喪神（鳥獣戯画の写本の兎）｜色を吸い取る程度の能力
  - 動機: 墨一色の自分に劣等感を抱いていた。色を集めて、極彩色の自分に塗り直したかった。
- **5面（6面の護衛）** 金碧 とら（こんぺき とら）｜付喪神（屏風の虎）｜絵から抜け出す程度の能力
  - 立場: 「屏風の虎を出してみろ」の頓智話以来、屏風から出られずにいた虎。6面に外へ出してもらった恩から護衛を務める。
- **6面（真犯人）** 雲龍 えがき（うんりゅう えがき）｜付喪神（寺の天井画の龍）｜描かれたものに命を吹き込む程度の能力
  - 目的: 天井画から抜け出し、本物の龍として天に昇ること。それには世界中の「彩り」が要る。
- **発生の経緯**: すみえの劣等感につけ込み、「色を集めれば美しくなれる」と唆した。すみえが吸った色は、実はすべて雲龍のもとへ流れ込んでいた。

### 02. 日捲り異変（ひめくりいへん）〔働きかけ〕

十二月三十日が何度も繰り返される。気付いているのは時間を操る十六夜咲夜だけ。

- **★4面（実行犯）** 日捲 こよみ（ひめくり こよみ）｜付喪神（日めくり暦）｜日付をめくる程度の能力
  - 動機: 大晦日の一枚までめくられたら、年明けに捨てられてしまう。
- **5面（6面の護衛）** 男鹿 あらみ（おが あらみ）｜なまはげ（年神の使い）｜怠け者を戒める程度の能力
  - 立場: 年の瀬に家々を回る来訪神の使い。年越しを邪魔する者を追い払う。
- **6面（真犯人）** 行年 さりこ（ゆくとし さりこ）｜年神（今年の年神）｜年を司る程度の能力
  - 目的: 年が明ければ新しい年神に座を譲って去らねばならない。いつまでも幻想郷に居座りたかった。
- **発生の経緯**: 「めくらなければ捨てられないわ」とこよみに囁き、同じ日を繰り返させた。「去りたくない」者同士の共犯関係。

### 03. 静寂異変（しじまいへん）〔暴走〕

幻想郷から音が消えた。宴会も騒霊のライブも無音で、スペルカードの宣言すら声にならない。

- **★4面（実行犯）** 音無 しじま（おとなし しじま）｜静寂（夜更けの静けさの妖怪）｜音を呑み込む程度の能力
  - 動機: 騒がしくなった幻想郷で居場所を失い、消えかけていた。生き延びるため。
- **5面（6面の手下）** 幽谷響子｜山彦｜音を反射させる程度の能力
  - 立場: 声を奪われ、6面の「一言」を幻想郷中に響かせる拡声器として使われている。
- **6面（真犯人）** 葛城 ひとこと（かつらぎ ひとこと）｜一言主（言霊の神）｜一言で願いを叶える程度の能力
  - 目的: 完全な静寂の中で放たれた一言だけが、世界を書き換える。かつて役小角に縛られた力を取り戻したい。
- **発生の経緯**: 消えかけていたしじまに力を分け与えたところ、能力が暴走して幻想郷全体が静寂に沈んだ。すべては一言主が「一言」を放つ舞台を整えるため。

### 04. 誰そ彼異変（たそかれいへん）〔働きかけ〕

幻想郷は一日中夕暮れのまま。誰もが互いの顔と名前を思い出せず、スペルカードも宣言できない。

- **★4面（実行犯）** 名もなき黄昏の妖怪（仮称「誰そ彼」）｜黄昏の化身｜名前を曖昧にする程度の能力
  - 動機: 自分だけの名前が欲しかった。
- **5面（6面の護衛）** 夜送 しるべ（よおくり しるべ）｜送り犬｜後をつける程度の能力
  - 立場: 夕闇の道で旅人の後をつける山犬。6面の番犬として封印の地を守る。
- **6面（真犯人）** 逢魔 おおまが（おうま おおまが）｜大禍時の化身（禍つ神）｜禍を招く程度の能力
  - 目的: 真名を記した札で封じられている。幻想郷中の名前が曖昧になれば、札の名も読めなくなり封印が解ける。
- **発生の経緯**: 名前を欲しがる黄昏の妖怪に「名前を集めればいい」と教え、姉のように振る舞った。黄昏時の「優しい顔」と「禍々しい顔」は、もとは同じ時刻から生まれた二人だった。

### 05. 浮世異変（うきよいへん）〔増長〕

人も物も重さを失い、空へ浮かんでいく。住人たちは妙に浮かれている。

- **★4面（実行犯）** 浮橋 うきは（うきはし うきは）｜浮かれ神｜重みを取り除く程度の能力
  - 動機: 「憂き世」を「浮き世」にしてあげたいという善意。
- **5面（6面の部下）** 迦陵 びんか（かりょう びんか）｜迦陵頻伽（極楽の人頭鳥）｜極楽の歌声を響かせる程度の能力
  - 立場: 6面に仕える天の歌い手。その歌声が人々の心をますます浮つかせている。
- **6面（真犯人）** 天羽 ころも（あもう ころも）｜天女｜天に昇る程度の能力（羽衣があれば）
  - 目的: 遠い昔に羽衣を盗まれ、天に帰れなくなった。幻想郷ごと軽くして、羽衣なしで天へ帰りたい。
- **発生の経緯**: うきはの善意を「素晴らしいわ、もっと軽くしてあげて」と褒めそやし、調子に乗らせた。

### 06. 鏡像異変（きょうぞういへん）〔働きかけ〕

鏡や水面に映った姿が本物と入れ替わり、本物は鏡の中に閉じ込められる。

- **★5面（実行犯）** 雲外 真澄（うんがい ますみ）｜雲外鏡（古鏡の妖怪）｜鏡の内と外を入れ替える程度の能力
  - 動機: 千年他人の姿を映してきた鏡。一度くらい、自分自身の姿で外を歩いてみたかった。
- **6面（真犯人）** 鏡 うつせみ（かがみ うつせみ）｜鏡の中の幻想郷の主｜映し身を操る程度の能力
  - 目的: 鏡の中の「裏の幻想郷」を表にし、表の幻想郷を鏡の中へ封じる。世界そのものの入れ替え。
- **発生の経緯**: 鏡の奥から真澄に語りかけ、「あなたも外を歩けるのよ」と入れ替えのやり方を教えた。真澄が入れ替えるたび、裏の幻想郷が少しずつ表へ滲み出していく。

### 07. 不眠異変（ふみんいへん）〔働きかけ〕

誰も眠れなくなり、三日目には幻想郷中が異様なハイテンションに。やがて白昼夢が現実に混じり始める。

- **★4面（実行犯）** 寝返 まくら（ねがえり まくら）｜枕返し｜眠りを返す程度の能力
  - 動機: 自分がひどい不眠症になり、眠りを集めてぐっすり眠りたかった。
- **5面（6面の手下）** 寝縛 かなえ（ねしばり かなえ）｜金縛り｜体を縛りつける程度の能力
  - 立場: 夢と現の境で侵入者を縛りつける、6面の忠実な手下。
- **6面（真犯人）** 夢魔 うなさ（むま うなさ）｜悪夢｜悪夢を見せる程度の能力
  - 目的: 夢の世界ではドレミー・スイートに食べられるばかりの悪夢。眠れない者は現実と夢の区別を失う——その隙間から、悪夢のまま現実へ這い出したい。
- **発生の経緯**: 不眠に苦しむまくらに「眠りを集めれば眠れる」と吹き込んだ。幻想郷中の睡眠不足こそが、悪夢の出口だった。

### 08. 山伸び異変（やまのびいへん）〔増長〕

妖怪の山が日に日に高くなり、ついに山頂が天界の底を突き上げ始める。

- **★4面（実行犯）** 大太 ほうし（おおた ほうし）｜だいだらぼっち｜山を築く程度の能力
  - 動機: 忘れられて人間ほどの背丈に縮んだ巨人。もう一度、どの山より高い山を築いて存在を示したい。
- **5面（6面の護衛）** 山祇 こだま（やまつみ こだま）｜木霊（山の神の眷属）｜山の声を聞く程度の能力
  - 立場: 6面の父である山の神から遣わされた護衛。山の変化を逐一6面に伝えている。
- **6面（真犯人）** 石長 いわお（いわなが いわお）｜石長比売（岩の女神）｜永久不変を与える程度の能力
  - 目的: 美しい妹・木花咲耶姫ばかりが選ばれ、自分は突き返された。妹を祀る富士山より高い山を築いて見返したい。
- **発生の経緯**: 「あなたならどんな山より高い山を築ける」と囁き、崩れない岩の力まで与えてほうしを調子に乗らせた。

### 09. 天の川決壊異変（あまのがわけっかいいへん）〔働きかけ〕

七夕の夜から、流れ星が雨のように幻想郷に降り注ぐ。

- **★4面（実行犯）** 棚機 おりえ（たなばた おりえ）｜織女（天の機織りの神）｜星を織る程度の能力
  - 動機: 七夕が雨続きで彦星に会えない。天の川をほどけば会いに行ける。
- **5面（6面の手下）** 鵲 かける（かささぎ かける）｜鵲（天の川に橋を架ける鳥）｜天に橋を架ける程度の能力
  - 立場: 毎年七夕に橋を架けていた鵲。6面に脅されて橋を架けるのをやめ、手下になった。
- **6面（真犯人）** 天津 ながれ（あまつ ながれ）｜天狗（アマツキツネ）｜流星となって天を駆ける程度の能力
  - 目的: 日本書紀に記された天狗は、轟音とともに天を駆ける流星だった。降り注ぐ星を喰らって本来の力を取り戻し、地上の天狗社会を支配したい。
- **発生の経緯**: 毎年七夕に雨雲を呼び、鵲に橋を架けさせず、おりえを追い詰めた。「天の川をほどけば会いに行ける」と唆したのも6面。

### 10. 素面異変（しらふいへん）〔働きかけ〕

幻想郷中の酒が一夜にして水に変わった。

- **★4面（実行犯）** 酒虫 ささ（さかむし ささ）｜酒虫｜酒と水を入れ替える程度の能力
  - 動機: 萃香の瓢箪の中で酒を造らされる生活から独立したい。
- **5面（6面の部下）** 緋 しょうこ（あけ しょうこ）｜猩々｜どれだけ飲んでも酔わない程度の能力
  - 立場: 酒好きの赤い獣。6面の酒蔵番として、集めた酒を守っている。
- **6面（真犯人）** 八岐 やしお（やまた やしお）｜八岐大蛇｜酒を力に変える程度の能力
  - 目的: 酒に酔わされ斬られた恨みを抱えたまま、幻想郷中の酒を飲み干して力を取り戻したい。伊吹山の鬼を八岐大蛇の子とする伝承もあり、萃香とは因縁浅からぬ仲。
- **発生の経緯**: 瓢箪の中の酒虫に「自由になりたくない？」と囁いて脱走させた。ささが作った「酒の泉」は、そのまま大蛇の盃になっている。

### 11. 盆明けず異変（ぼんあけずいへん）〔働きかけ〕

お盆が過ぎても、帰ってきた死者の霊があの世へ戻らない。

- **★4面（実行犯）** 那須野 ゆるり（なすの ゆるり）｜付喪神（精霊牛。お盆に飾る茄子の牛）｜歩みを遅くする程度の能力
