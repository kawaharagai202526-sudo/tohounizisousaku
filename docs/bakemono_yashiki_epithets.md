# 化物屋敷異変 二つ名案

「化物屋敷異変」のボス7人（1面〜Extra）の二つ名を、1人30個ずつ、計210個考えた資料。

- 二つ名は名前に依存しないように考えたので、名前がどれに決まっても組み合わせられる。
- 1人につき5つのテーマで6個ずつ考え、最後に「おすすめ3」を選んだ。
- 「詳細構成（第2版）」に書いた仮の二つ名は、比べやすいよう各キャラクターの最初に載せた（30個には含めていない）。

## 考え方

- 東方の二つ名に多い「〇〇の〇〇」「〇〇な〇〇」の形を中心に、言い切りの形（例：異変の実行犯）や、ひねった形（例：黒幕顔の無関係者）も混ぜた。
- テーマは5つ：「居場所・登場場面から」、「種族・正体から」、「性格・口調から」、「能力・弾幕から」、「物語での役割から」。
- 物語の核心に触れる二つ名（例：無邪気な真犯人）は、ゲーム中では会話のあとに出すなど、見せ方に注意がいる。
- 210個すべて別の二つ名にした。既存の東方キャラクターの二つ名と同じものは避けたが、決める前にもう一度確認すると安心。
