# 化物屋敷異変 キャラクター資料

「化物屋敷異変」のボスキャラクター7人の特徴をまとめた資料。

- 名前はまだ決めていないため記載していない。名前の仮案に合わせて考えていた二つ名も省いた。各キャラクターは「1面ボス」「Extraボス」のように登場する面で呼ぶ。
- 台詞の中で名前が入る部分は、「〔5面ボスの名前〕」のように伏せている。
- 会話シーンと台詞は「セリフ決定稿」に合わせている。
- 記載している項目は、行動・役割、種族、会話シーン、元ネタ、能力。

## 一覧

| 登場 | 種族 | 異変での立場 | 能力 |
|---|---|---|---|
| 1面ボス | 鬼瓦の付喪神 | 異変の副作用で生まれた | 睨みで魔を払う程度の能力 |
| 2面ボス | 家守（ヤモリの妖怪） | 異変の恩恵を受けている | 壁や天井に張り付く程度の能力 |
| 3面ボス | ぬらりひょん | 無関係だが、最初に黒幕と疑われる | いつの間にか上がり込む程度の能力 |
| 4面ボス | 大黒柱の付喪神 | 百間屋敷を建てた張本人（屋敷の心臓） | 家を支え、繋ぎ合わせる程度の能力 |
| 5面ボス | 家鳴（やなり） | 人里の家を古びさせた実行犯 | 家を軋ませ、古びさせる程度の能力 |
| 6面ボス | 座敷わらし | 真犯人（本人に自覚はない） | 人を惹きつけ、住み着いた家を栄えさせる程度の能力 |
| Extraボス | 方位神（金神） | 屋敷を建てられ、崩され、瓦礫を落とされた被害者 | 方角を祟る程度の能力 |

## キャラクター同士の関係

| 関係 | 内容 |
|---|---|
| 5面ボス → 6面ボス | 「座敷様」と呼んで慕い、その幸せを何より願っている |
| 4面ボス → 6面ボス | 守りたい相手。本人は最後まで明かさないが、魔理沙ルートでは誰かをかくまっていることを見抜かれる |
| 4面ボス ⇔ 5面ボス | どちらも霧雨店に住んでいた家の妖怪。異変では共犯（5面ボスが家を古びさせ、4面ボスが部屋を繋いで屋敷を建てた） |
| 3面ボス → 4面ボス | 屋敷に勝手に上がり込もうとした居候。3面ボスのせいで、隠していた屋敷が見つかる |
| 1・2面ボス | 5面ボスが家を古びさせたことの副作用で生まれた・得をしている |
| Extraボス → 全員 | 屋敷を建てた4・5面ボスにも、崩した自機にも怒っている |

## 1面ボス ｜ 鬼瓦の付喪神

| 項目 | 内容 |
|---|---|
| 登場 | 1面ボス（古びた人里の屋根の上） |
| 種族 | 鬼瓦の付喪神（本人は「鬼でもある」と名乗っている） |
| 能力 | 睨みで魔を払う程度の能力 |
| 異変での立場 | 異変の副作用で生まれた |

### 行動・役割

- 人里の家が一晩で百年分古びたとき、屋根の鬼瓦から付喪神になった。生まれてまだ一日。
- 自分が付喪神だとは分かっているが、鬼の顔をしているので「鬼でもある」と言い張っている。世間知らずで、自分の力を過信している。
- 屋根の上を自分の縄張りだと言い張り、生まれて初めて見た人間（自機）を追い払おうとして立ちはだかる。異変そのものには関わっていない。

### 種族

- 鬼瓦の付喪神。古びた屋根の上で目覚めた、生まれたての妖怪。
- 付喪神だという自覚はあるが、「名前に鬼と付いているから鬼と同じようなもん」と、鬼でもあると言い張る。

### 会話シーン

- **場面**：夜の人里の屋根の上で、生まれて初めて人間に出会う。
- **態度**：「ふっ……人間か」と調子に乗っている。自分のレベルがまったく分かっていない。
- **口調**：一人称は「私」。「〜のだ」「〜ぞ」と尊大ぶっているが、図星を突かれると「なんでわかったの！？」と素の幼さが出る。
- **霊夢ルート**：屋根の上を縄張りだと主張するが、「生まれたての付喪神が縄張りを主張すんじゃないわよ」と見抜かれる。戦闘後は「生まれたてのくせに」とからかわれ、「うるさい！」と言い返す。
- **魔理沙ルート**：「付喪神であり鬼でもある」と言い張るが、「私は霧雨だから雨ってことになる」と屁理屈で返される。戦闘後は「雨に……負けた……」。
- **代表的な台詞**
  - 「ふっ……人間か」
  - 「私は鬼瓦の付喪神よ、私の縄張りに入ってくるな」
  - 「なんでわかったの！？」
  - 「付喪神であり鬼でもあるぞ」

### 元ネタ

- **鬼瓦**：屋根の棟の端に据える瓦。鬼の顔をかたどったものが多く、魔除け・厄除けとして置かれる。
- **付喪神**：長い年月を経た道具に霊が宿り、妖怪になるという言い伝え。室町時代の『付喪神記』などで知られる。

### 能力

- **睨みで魔を払う程度の能力**：鬼瓦がもともと持っている魔除けの力。本人はこれを「鬼の力」だと思い込んでいる。
- 弾幕では、睨んだ方向へ扇状に弾を撃つ、屋根の上から瓦の形の弾を降らせる、といった形で表現する。

## 2面ボス ｜ 家守（ヤモリの妖怪）

| 項目 | 内容 |
|---|---|
| 登場 | 2面ボス（虫の湧いた裏長屋） |
| 種族 | 家守（ヤモリの妖怪） |
| 能力 | 壁や天井に張り付く程度の能力 |
| 異変での立場 | 異変の恩恵を受けている |

### 行動・役割

- 家が古びて虫が湧いたおかげで、毎晩ごちそう続き。古い家は彼女にとって「楽園」。
- 異変が終わると虫が減ってしまうので、異変を終わらせに来た自機を邪魔する。
- 霊夢ルートでは、空き家に上がり込んでいる誰か（3面ボス）のことを教え、3面への道案内役になる。
- 異変そのものには関わっていない。

### 種族

- 家守（ヤモリの妖怪）。人の家の壁に張り付き、虫を食べて暮らしている。
- 「家を守るのが家守のお仕事」と思っているが、守っているのは家なのか、ごちそうなのか、本人もよく分かっていない。

### 会話シーン

- **場面**：虫の湧いた古い家の中。
- **態度**：自機が虫を嫌がるのが心から理解できず、「どこがそんなに嫌なの？」と不思議がる。虫は「おやつ」で「ごちそう」。
- **口調**：一人称は「私」。「〜よ」「〜かしら」とのんき。
- **霊夢ルート**：霊夢の肩に落ちた虫を「私のおやつ」と言う。空き家に誰かが上がり込んでいたことを教え、見逃してもらおうとする。戦闘後はその誰かの居場所を教え、心の中で「今のうちにいっぱい食べとこ」と思う。
- **魔理沙ルート**：「私はこの家を守ってるのに」と言うが、「守ってるのは、ごちそうだろ」と見抜かれる。戦闘後は「せめて最後に思いっきり食べとこう」と意気込む。
- **代表的な台詞**
  - 「あ、それ私のおやつ。返して」
  - 「どこがそんなに嫌なの？ 足がいっぱいあって、かわいいのに」
  - 「でも、空き家に誰か上がり込んでるのは見たよ。お茶を飲んで、くつろいでた」
  - 「元に戻っちゃうなら、せめて最後に思いっきり食べとこう」

### 元ネタ

- **ヤモリ（家守）**：「家を守る」と書く。家に住み着いて害虫を食べることから、家の守り神として縁起のいい生き物とされる。夜、灯りに集まる虫を、壁や窓に張り付いて食べる。
- **自切**：ヤモリやトカゲは、危険が迫ると尻尾を切って逃げる。弾幕「トカゲの尻尾切り」の元ネタ。

### 能力

- **壁や天井に張り付く程度の能力**：壁でも天井でも張り付いて、どこまでも虫を追いかける。
- 弾幕では、画面の端から壁を這うように伸びる弾や、切れた尻尾が独立して撃ってくる弾として表現する。

## 3面ボス ｜ ぬらりひょん

| 項目 | 内容 |
|---|---|
| 登場 | 3面ボス（空き家町から人里の外れへ）。道中にも中ボスとして登場 |
| 種族 | ぬらりひょん |
| 能力 | いつの間にか上がり込む程度の能力 |
| 異変での立場 | 無関係。いかにも黒幕らしいので、最初に疑われる（ミスリード役） |

### 行動・役割

- 住人が避難して空き家になった家々に上がり込み、家主のような顔でくつろいでいた。
- 道中で自機に見つかると「うちになんか用かい？」と家主のふりをするが、速攻で見破られて逃げ出す。
- 家と家の隙間に「大きな空き家」の気配を嗅ぎつけ、そこへ逃げ込もうとしたところで捕まり、ボス戦になる。
- 戦闘後に屋敷のことを聞かれても、よく知らない。だが、この妖怪が戸口に手をかけたせいで、隠されていた百間屋敷が姿を現す。物語を後半へ進める鍵になる。

### 種族

- ぬらりひょん。いつの間にか他人の家に上がり込み、主人のようにふるまう妖怪。
- 飄々としていて堂々と居座るが、ばれると逃げ足が速い。

### 会話シーン

- **場面**：道中は空き家の茶の間（家主のふり）、ボス戦は人里の外れ（逃げた先）。
- **態度**：とぼけて家主を装うが、すぐに見破られて逃げ出す。
- **口調**：一人称は「わし」。「〜じゃ」「〜かい」。追い詰められると「クソッ」と荒くなる。
- **道中（霊夢ルート）**：「うちになんか用かい？」と家主のふりをしたまま中ボス戦。戦闘後、湯呑みの「源さん」と表札の「鈴木」で見破られ、「お邪魔しましたー！」と逃げる。
- **道中（魔理沙ルート）**：「この家の米びつがどこにあるか」に答えられず中ボス戦。戦闘後、「クソッ、こうなったら逃げるしか」と逃げる。
- **ボス戦**：追いつかれて異変の原因扱いされ、「あの屋敷」に逃げ込むつもりだったと口を滑らせる。戦闘後、屋敷のことは知らないと言うが、この妖怪のせいで屋敷の門が現れる。
- **代表的な台詞**
  - 「……おや、お客さんかい。うちになんか用かい？」
  - 「……わしの名前は源さんじゃ」
  - 「お邪魔しましたー！」
  - 「わしは、どんな家にも上がり込める性分でな。隠れた家の戸も、勝手に開いてしまうんじゃ」

### 元ネタ

- **ぬらりひょん**：鳥山石燕の『画図百鬼夜行』などに描かれた、後頭部が大きく張り出した老人の姿の妖怪。忙しい夕暮れ時に他人の家に上がり込んで茶を飲んでいる、という話や、「妖怪の総大将」とする話は、後の時代の妖怪本で広まったもの。

### 能力

- **いつの間にか上がり込む程度の能力**：誰にも気付かれないうちに他人の家に入り込み、主人のような顔でくつろぐ。
- 隠された家の戸まで開けてしまうので、百間屋敷が見つかるきっかけになる。
- 弾幕では、前触れなく画面の中に現れる弾や、逃げ回った跡に残る弾として表現する。

## 4面ボス ｜ 大黒柱の付喪神

| 項目 | 内容 |
|---|---|
| 登場 | 4面ボス（百間屋敷の中心「大黒柱の間」） |
| 種族 | 大黒柱の付喪神 |
| 能力 | 家を支え、繋ぎ合わせる程度の能力 |
| 異変での立場 | 百間屋敷を建てた張本人で、屋敷の心臓（5面ボスと共犯） |

### 行動・役割

- 5面ボスの協力を得て、人里の古びた家から部屋を一つずつ引き抜き、自分を大黒柱にして百部屋の屋敷「百間屋敷」を建てた。屋敷は家と家の隙間に隠していた。
- もとは人里の大店・霧雨店を何百年も支えてきた大黒柱。改築で取り壊され、捨てられる寸前に付喪神になった。
- 屋敷を建てたのは、6面ボス（座敷わらし）に住む家を用意するため。ただし本人は最後まで口を割らない（魔理沙ルートでは、誰かをかくまっていることを見抜かれる）。
- 屋敷は彼女が支えているので、倒されると屋敷は崩れ始める。この崩壊が、5面と6面の舞台になる。

### 種族

- 大黒柱の付喪神。何百年も一つの家を支え続けてきた、家の中心の柱が妖怪になったもの。
- 屋敷の主として、断りなく上がり込む者を何より嫌う。

### 会話シーン

- **場面**：壁をぶち抜いて豪快に不法侵入してきた自機に、ぶち切れて迎え撃つ。
- **態度**：頑固で口が堅い。何のために屋敷を建てたのかは、最後まで明かさない。
- **口調**：一人称は「私」。「〜だ」「〜だぞ」。
- **霊夢ルート**：「玄関から入れ」と怒り、建てた理由は「お前に話す義理はない」と突っぱねる。戦闘後は「ここはもう崩れる、脱出した方がいいぞ」と避難を勧めるが、霊夢は無視して奥の犯人のもとへ向かう。
- **魔理沙ルート**：ぶち抜かれた部屋の数まで数えていて怒る。「言えんな」に「家だけにか？」と返され、「もう帰ってくれ」とうんざりする。戦闘後は、誰かをかくまっていることを見抜かれる。
- **代表的な台詞**
  - 「…………玄関から入れ」
  - 「十四だ！ 一部屋ごとに、人里の家から借りてきた大事な部屋だぞ！」
  - 「お前に話す義理はない」
  - 「これ以上屋敷を維持できない！ 屋敷ごと潰れるぞ、逃げるんだ！」

### 元ネタ

- **大黒柱**：日本家屋の中心に立ち、家全体を支えるいちばん太い柱。転じて、一家や組織を支える中心人物のたとえにも使う。名前の由来には諸説ある。
- **上棟式（棟上げ）**：家の骨組みが組み上がったときに行う儀式。地域によっては屋根の上から餅をまく。弾幕「棟上げの餅撒き」の元ネタ。
- **付喪神**：長い年月を経た道具に霊が宿り、妖怪になるという言い伝え（1面ボスと同じ）。

### 能力

- **家を支え、繋ぎ合わせる程度の能力**：どんな家でも支え、ばらばらの部屋を一つの家に繋ぎ合わせる。百間屋敷は、この能力で人里の部屋を継ぎ合わせて建てられた。
- 彼女が倒れると屋敷を支えるものがなくなり、屋敷は崩れ始める。
- 弾幕では、柱と梁の形に組み上がる弾や、次々に建て増しされて迫ってくる部屋の形の弾として表現する。

## 5面ボス ｜ 家鳴（やなり）

| 項目 | 内容 |
|---|---|
| 登場 | 5面ボス（崩れゆく百間屋敷）。6面の道中にも中ボスとして再登場 |
| 種族 | 家鳴（やなり） |
| 能力 | 家を軋ませ、古びさせる程度の能力 |
| 異変での立場 | 人里の家を古びさせた実行犯 |

### 行動・役割

- 霧雨店の天井裏で何十年も6面ボスと一緒に暮らし、「座敷様」と呼んで慕ってきた。改築で住処を失った。
- 6面ボスの「住む家が欲しいなぁ」というぼやきを聞き、仲間の家鳴たちを率いて、人里中の家を一晩で百年分古びさせた（座敷わらしが住めるのは古い部屋だけなので）。4面ボスの屋敷づくりにも協力した。
- 4面ボスが倒れて屋敷が崩れ始めると、6面ボスを外へ逃がそうとする。その最中に自機と遭遇し、時間稼ぎも兼ねて戦う。
- 6面の道中では、ぼろぼろの体で再び自機の前に立ちはだかる。

### 種族

- 家鳴（やなり）。夜中に家を揺すって軋ませる小鬼の群れの、頭目にあたる。
- 敵には荒っぽいが、6面ボスの前ではどこまでも忠実で健気。

### 会話シーン

- **場面**：崩れる屋敷の中。6面ボスを外へ逃がしている最中に、自機と鉢合わせる。
- **態度**：「くそっ、座敷様を逃がさなきゃいけないってのに」と焦りながら、時間稼ぎのために立ちはだかる。
- **口調**：一人称は「あたし」。敵には「くそっ」「〜だ」と荒っぽいが、6面ボスには「座敷様」「申し訳ありません」と丁寧。
- **霊夢ルート**：6面ボスを逃がしているところで霊夢に見つかり、「ここはあたしが通さない！」と立ちはだかる。戦闘後は「座敷様……申し訳ありません」。
- **魔理沙ルート**：霧雨の家の天井裏から魔理沙を見ていたこと、その家が座敷様のおかげで栄えていたことを明かす。戦闘後は「せっかくの家、守れませんでした」と座敷様に詫びる。
- **6面の道中**：ぼろぼろの体で再び立ちはだかる（霊夢ルート「なんとかここで食い止めなければ」、魔理沙ルート「あの子には指一本触れさせない！」）。
- **代表的な台詞**
  - 「座敷様！ 早く！ ここもすぐ崩れる！」
  - 「行かせない！ 座敷様が逃げ切るまで、ここはあたしが通さない！」
  - 「お前、霧雨の家の子だな。天井裏から、何度も見たことがある」
  - 「座敷様……申し訳ありません」

### 元ネタ

- **家鳴（鳴家）**：鳥山石燕の『画図百鬼夜行』に「鳴家（やなり）」として描かれた、小鬼の姿の妖怪。家や家具が理由もなく軋んだり揺れたりするのは、この小鬼たちが揺さぶっているからだとされた。

### 能力

- **家を軋ませ、古びさせる程度の能力**：夜中に家を揺すって軋ませ、一晩で百年分古びさせる。
- 家が古びたことで、鬼瓦が付喪神になり（1面）、虫が湧き（2面）、空き家が生まれた（3面）。異変の副作用は、すべてこの能力から始まっている。
- 弾幕では、画面全体の揺れに合わせて不規則に伸びる弾や、時間とともに「古びて」色と速さが変わる弾として表現する。

## 6面ボス ｜ 座敷わらし

| 項目 | 内容 |
|---|---|
| 登場 | 6面ボス（崩れる屋敷の屋根の上から夜明けの空へ） |
| 種族 | 座敷わらし |
| 能力 | 人を惹きつけ、住み着いた家を栄えさせる程度の能力 |
| 異変での立場 | 真犯人。ただし何も頼んでおらず、本人に自覚はない |

### 行動・役割

- 何代にもわたって霧雨店の奥座敷に住み着き、店を人里一の大店に育ててきた。改築で奥座敷がなくなり、宿無しになった。
- 「古いお家がいいなぁ。住む家が欲しいなぁ」とぼやいただけ。それを聞いた4面ボスと5面ボスが、彼女のために異変を起こした。
- やっと見つかった百間屋敷に喜んで住んでいたが、崩壊が始まり、5面ボスに言われるまま外へ逃げる。屋敷の外で自機に追いつかれる。
- 倒されると屋敷は完全に崩れ落ち、部屋は元の家へ、家は元の姿へ戻る。

### 種族

- 座敷わらし。家に住み着き、その家に福をもたらす子どもの姿の神。
- 性格は比較的自由で気まま。そばにいる者を自然と惹きつけ、誰からも愛される。本人にその自覚はない。

### 会話シーン

- **場面**：崩れる屋敷の外。道中で、ぼろぼろの5面ボスが立ちはだかったあとに対面する。
- **態度**：状況がよく分かっていない。自機のことは、いいお家を壊して5面ボスを傷つけた悪者だと思っている。
- **口調**：一人称は「わたし」。「〜だよ」「〜もん」と子どもっぽい。ただし戦闘前の最後の決め台詞だけは、福の神らしい荘厳な口調になる。
- **霊夢ルート**：「その子をいじめないで！」と5面ボスをかばい、「〔5面ボスの名前〕も〔4面ボスの名前〕も喜んでたのに！」と怒る。戦闘後、皆が動いたのは自分の力のせいだと言われ、「……知らなかった」。
- **魔理沙ルート**：魔理沙を「霧雨のお店にいた子」と覚えている。戦闘後、屋敷が人里の皆の家から借りたものだったと知り、「……全部、借り物のお家だったんだ」。
- **決め台詞**：霊夢ルート「千客万来、家運隆盛……百の部屋に積もった福の重み、受け止めてみなさい！」、魔理沙ルート「わたしが去れば家は傾き、留まれば家は栄える……あなたの家運、ここで尽きぬよう祈りなさい！」
- **代表的な台詞**
  - 「待って！ その子をいじめないで！」
  - 「〔5面ボスの名前〕に何したの！？ いい子で、いつもわたしの話を聞いてくれる子なのに！」
  - 「そんなのしらないもん」
  - 「……全部、借り物のお家だったんだ」

### 元ネタ

- **座敷わらし**：岩手県を中心とする東北地方に伝わる、子どもの姿をした家の精霊（神）。旧家の奥座敷などに住み着き、住み着いた家は栄え、去った家は衰えるとされる。柳田國男の『遠野物語』にも記されている。おかっぱ頭の子どもの姿で語られることが多い。

### 能力

- **人を惹きつけ、住み着いた家を栄えさせる程度の能力**：住み着いた家を栄えさせ、去った家は傾く。化物屋敷のままの百間屋敷でさえ、彼女が住めば栄えていた。
- そばにいる者を自然と惹きつけて離さない。4面ボスと5面ボスが異変を起こしたのは、この惹きつける力のせいでもある。本人に自覚はない。
- ゲームでは「家運システム」（福アイテムを集めて家運ゲージを上げるシステム）の元になっている。6面ボス戦では、彼女に近づくほど家運が上がる。

## Extraボス ｜ 方位神（金神）

| 項目 | 内容 |
|---|---|
| 登場 | Extraボス（百間屋敷の瓦礫から方位盤の異界へ）。前半は瓦礫の上で中ボスとして戦う |
| 種族 | 方位神（金神） |
| 能力 | 方角を祟る程度の能力 |
| 異変での立場 | 被害者。ただし怒りの矛先は全員 |

### 行動・役割

- 6面ボスを倒して百間屋敷が崩れ落ちた直後、瓦礫の山を吹き飛ばして、ぶち切れながら現れる。そのまま戦闘開始。
- 今季、人里から見て艮（北東）の方角に座していた。そこへ断りもなく屋敷を建てられ、崩され、百部屋分の瓦礫を落とされた。
- 怒りの矛先は、屋敷を建てた4・5面ボスにも、崩した自機にも、方角を気にしない世の中全体にも向いている。
- 瓦礫の上で第一戦を終えると、自機を方位盤の異界へ引きずり込んで決着をつける。

### 種族

- 方位神（金神）。年や季節ごとに方角を巡り、自分のいる方角で家を建てたり引っ越したりする者を祟る神。
- 昔の人々は方違えで回り道をして避けたものだが、今では誰も気にしない。方角を忘れられ、居場所を失った古い神。古いものが捨てられていく、という本編の主題をExtraでも受け継いでいる。
- 決まりごとにうるさく怒りっぽいが、筋を通せば話は聞く。

### 会話シーン

- **場面**：崩れた屋敷の瓦礫の跡。瓦礫を吹き飛ばし、怒鳴りながら現れる。
- **態度**：怒り心頭。屋敷を建てた者も崩した者も、まとめて祟ると宣言する。
- **口調**：一人称は「妾（わらわ）」。「〜であるぞ」「〜とは何事か！」と古風。怒りが頂点に達すると「己ら」「付けろ」と言葉が荒くなる。
- **霊夢ルート**：金神と名乗り、自分の方角に家を建てて崩したことを責め立てる。戦闘後は「筋を通すなら話は聞いてやる」と、方位除けの祈祷と供え物で手を打とうとする。
- **魔理沙ルート**：頭に瓦が刺さったまま登場し、その罪まで数え上げる。戦闘後は「……瓦、抜けたか？」と気にしている。
- **決め台詞**：霊夢ルート「東西南北、天地四方。この世に妾の眼の届かぬ方角はない。凶方を犯した罪、その身で償うがよい」、魔理沙ルート「百部屋の瓦礫など、妾には塵も同然。次に崩れ落ちるのは、汝の運命であると思い知れ！」
- **代表的な台詞**
  - 「誰だぁぁぁ！ 妾の頭上に家を落とした不届き者はぁ！」
  - 「己ら全員祟られる覚悟はできておるんだろうな？」
  - 「知っておるわ！！」
  - 「済むものか。だが、筋を通すなら話は聞いてやる」

### 元ネタ

- **金神**：陰陽道で恐れられた方位の神。年ごとにいる方角が変わり、その方角に向けて家を建てる・引っ越す・旅をするなどすると祟りがあるとされた。祟りで家族七人に災いが及ぶという「金神七殺」の言い伝えもある。
- **方違え**：平安時代などに行われた習わし。行きたい方角が凶方に当たるとき、いったん別の方角へ出かけて泊まり、方角を変えてから目的地へ向かう。
- **艮（北東）の方角**：「鬼門」として古くから忌まれてきた方角。
- **八将神・大将軍**：同じく陰陽道の方位の神々。スペルカードの元ネタ。

### 能力

- **方角を祟る程度の能力**：自分のいる方角（凶方）を犯した者を祟る。
- Extraでは「方違えシステム」として表現する。画面の端の方位盤に凶方が光り、凶方へ向かって動くと弾幕が激しくなる。凶方は、スペルカードごとに金神が方角を移るのに合わせて変わっていく。
