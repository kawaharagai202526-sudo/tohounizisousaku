# 化物屋敷異変 6面ボス曲 アレンジ資料

送られた動画（3つの節をつないだ約2分34秒の音源）を元に、3つの節を1曲の6面ボス曲としてまとめ直した記録。

- 完成品は MIDI（楽器ごとのトラック付き）と、それを General MIDI 音源で鳴らした試聴用の音声（MP3、約2分36秒）。
- MIDI は DAW やシーケンサーに読み込めば、音色の差し替えや細かい修正がそのままできる。試聴用の音声は FluidSynth（FluidR3 GM 音源）で鳴らしたもので、音色は仮のもの。
- 原曲の音は、音声解析（ピッチ・和音・テンポの推定）とスペクトログラムの目視で書き起こした。細かい音の聴き違いは残っている可能性がある。

## 依頼の条件

| 条件 | この資料での扱い |
|---|---|

| 曲調を統一し、繋ぎ目を自然にする | テンポ・楽器編成・ドラムを節2に揃え、節と節の間に和音でつなぐ小節を1小節ずつ入れた |
| 音の足し引きは自由 | 節2後半と節3のリード、つなぎの小節、節3の打撃の置き方などを足し、合わない音は直した |
| 1節めは曲調をできるだけ残す | メロディ・和音・16分のハイハット・ブレイクは原曲どおり。変えたのはテンポ（83.7→83）と音色だけ |
| 2節は基準 | 和音の進行・配置、8分のノリ、16分のアルペジオをそのまま使い、曲全体の基準にした |

## まとめ方の方針

### テンポ

- 全体を節2の **83 BPM**（16分音符で動くので、体感は166前後の速い曲）に統一した。
- 節1は83.7→83でほとんど変わらない。節3は80前後で揺れていたものを83の一定に揃えた。
- 最後の2小節だけ、原曲の節3と同じようにゆっくりして終わる（83→74→68）。

### 調の流れ

E♭（D♯）短調系 → F♯短調 → G短調 → E♭長調

- **節1→節2**：節1の調で♭VIにあたるBは、F♯短調ではIV。この「両方の調に属する和音」を経由して、F♯短調のV（C♯）へ進む。そのC♯から節2の最初の和音D（♭VI）へ移るので、偽終止のような自然で劇的なつながりになる。
- **節2→節3**：節2の最後のG（長三和音、ここではG7）は、Cm（E♭長調のvi）へのVとして働く。G7→Cm→A♭→B♭→E♭という定番の流れで、節3のE♭長調に入る。
- 調を移していないので、節1の暗い響きはそのまま残っている。

### 動機（モチーフ）で曲をつなぐ

- 節2・節3には目立つ主旋律がなかったため、節1のメロディを動機として使い回した。
- **節2の後半（G短調）**：節1のメロディ8小節を半音下げて、原曲と同じリズムで再現する。和音とぶつかる音だけ直した（節2の11・12小節目の拍頭、13・14小節目の導音、16小節目の終わり）。
- **節3の最後**：節1の8小節目の動き（D♯–F♯–D♯–B–B–G♯–F♯–D–D♯）を同じ音の高さのまま戻し（E♭–G♭–E♭–C♭–C♭–A♭–G♭–D–E♭と書き換え）、E♭長調の和音で終える。曲の最初に出た暗い動機が、最後に長調へ解決する形になる。

## ゲームで使うとき

- ボス戦中に繰り返し流す場合は、**節2の頭（0:33付近、12小節目）からつなぎ2の終わり（1:22付近）まで**をループにすると、F♯短調→G短調→（つなぎ2のCm→A♭）→F♯短調のD…と戻っても不自然になりにくい。ただし、つなぎ2はE♭長調へ向かう和音なので、ループ版ではつなぎ2の後半をC♯（F♯短調のV）に差し替えるとより自然になる。
- 曲全体を通して流すなら、節3の盛り上がりをボスのラストスペル、最後の動機をボス撃破の演出に合わせる使い方が合う。
