# 化物屋敷異変 キャラクター名前案

「化物屋敷異変」のボス7人（1面〜Extra）の名前案を、1人60個ずつ、計420個考えた資料。

- 名前はまだ決まっていないため、これは案出し用の資料。採用する名前が決まったら、キャラクター資料・セリフ決定稿の〔○面ボスの名前〕に当てはめる。
- 1人につき6つのテーマで10個ずつ考え、最後に「おすすめ3」を選んだ。
- 下の名前も漢字にした「全部漢字」版は、別資料「キャラクター名前案（漢字版）」にまとめた（60個中30個ずつ）。

## 名前の付け方

- 東方の名前に多い「漢字の姓＋ひらがなの名」の形にした。姓は種族・本体・住んでいる場所から、名は性格・能力・物語での役割から取っている。
- 名はひらがなで書いている。決めたあとで漢字を当ててもよい（例：にらみ→睨、さちよ→幸代）。
- 読みは「姓 名」の順で、すべてひらがなで書いた。
- 下の名前は、420個すべて重複しないようにした。
- 以前の仮の名前（鬼瓦いかめ、家守ひっつき、滑瓢ぬらり、大黒柱ささえ、家鳴きしみ、座敷わらべ、金神うしとら）は入れていない。ただし、鬼瓦・家鳴・金神など、同じ姓を使った案はある。
- 既存の東方キャラクターと同じ下の名前は外した（例：八雲紫と同じ「ゆかり」、矢田寺成美と同じ「なるみ」、旧作の夢子と同じ「ゆめこ」）。キャラクターは毎年増えるので、決める前にもう一度確認すると安心。
