# 6面ボスが異変を起こす動機案（1〜5面を考えない版）

1〜5面の設定（天秤の暴走、貸し借りの清算）は考えずに、6面ボスがなぜ異変を起こしたのかを30個考えた。
6面ボスの能力は [6面ボスの能力案](stage6-boss-abilities.md) の 3（器に注ぐ）と 4（神輿に担ぎ上げる）の2パターンで、15個ずつ。
各案に、誰に力を与えて、どんな異変になるかも付けている。

> 3（器）は異変の舞台が「宴会」になりやすい。萃夢想（萃香が宴会を繰り返させる異変）と似るので、宴会そのものを異変の中心にしない方がいい。

### 器1. 幻想郷の器量番付を作りたい

相手の器の大きさを見極めるのが何よりの楽しみ。
幻想郷中の者に力を注いで回り、どこで溢れるかで「器量番付」を作ろうとした。
**異変**：器から溢れた者たちが、あちこちで暴れ出す。

### 器2. 返杯してほしかった

注ぐばかりで、誰にも注いでもらったことがない。
注げばいつか返杯してもらえると信じて、手当たり次第に注ぎ続けた。
**異変**：注がれた者たちが酔ったように暴れ出す。誰も返杯してくれないので、本人は注ぐのをやめられない。

### 器3. 酒離れへの逆襲

外の世界で酒を飲む人が減り、潰れた酒蔵から幻想入りした。
幻想郷の人間まで酒離れしていると聞いて、力の味を覚えさせ、酔う楽しさを思い出させようとした。
**異変**：人里の人間たちが力に酔い、仕事そっちのけで大騒ぎする。

### 器4. 喧嘩を肴に飲みたい

「火事と喧嘩は江戸の華」。最高の酒の肴は騒ぎだと思っている。
わざと力を注いで喧嘩を起こし、それを眺めながら一杯やる。
**異変**：幻想郷のあちこちで大喧嘩が起き、本人は高みの見物を決め込む。

### 器5. 神便鬼毒酒の償い

源頼光が酒呑童子を討つときに使った「神便鬼毒酒」を運んだ徳利。
人間がだまし討ちをしたことで、鬼は人間に失望して地上を去った。そのきっかけを作った罪滅ぼしに、鬼たちに力を注いで返そうとした。
**異変**：旧地獄の鬼たちが力を取り戻し、地上へ溢れ出してくる。

### 器6. 祀られない神々にお神酒を

神前にお神酒を供える御神酒徳利。
幻想郷には誰にも祀られない小さな神々が大勢いるのを見て、代わりに力を注いで回った。
**異変**：急に力を得た八百万の神々が荒ぶり、幻想郷中で小さな祟りが頻発する。

### 器7. 器の小さい奴を割ってやりたい

昔、心の狭い持ち主に八つ当たりで投げられて欠けてしまった。
「器の小さい奴は割れてしまえ」と、小さな器の持ち主を狙って注ぎすぎる。
**異変**：心の狭い者から順に暴れ出す。霊夢まで巻き込まれそうになる。

### 器8. 仲直りの盃

仲の悪い者同士を仲直りさせる「手打ちの盃」を取り持つのが役目。
いがみ合う二つの勢力に和解の盃を交わさせたが、双方に注ぎすぎた。
**異変**：和解の宴が、力に酔った両陣営の大乱闘になる。

### 器9. 千年分の注ぎ足しで割れそう

中身を千年も注ぎ足し続けてきたせいで、妖力が濃くなりすぎて自分が割れそうになっている。
割れる前に、とにかく誰かに注ぎ出すしかなかった。
**異変**：注がれた妖精たちが大妖怪並みの力を持って暴れ回る。

### 器10. 酒は百薬の長

「酒は百薬の長」を信じている。
病人や弱った者に力を注げば元気になると思い、人里の病人たちに注いで回った。
**異変**：元気になりすぎた人間たちが、妖怪も顔負けの力で暴れ出す。

### 器11. 継いでくれた人への恩返し

割れたところを、ある人間に金継ぎで直してもらった過去がある。
その恩を返そうと、恩人の子孫の一家に力を注いだ。
**異変**：人里のある一家が並外れた力を持ち、手がつけられなくなる。

### 器12. 酒の神になりたい

ただの付喪神ではなく、本物の酒の神になりたい。
幻想郷中を酔わせれば、酒の神として祀ってもらえると思い込んでいる。
**異変**：幻想郷中が力に酔い、誰も素面でいられない。

### 器13. 酔い覚ましの水と間違えた

酔っ払いに酔い覚ましの水を注いであげたつもりが、中身は千年ものの妖力の原酒だった。
**異変**：注がれた者たちが暴れ出す。本人は慌てて水を注いで回るが、それも原酒なので被害が広がる。

### 器14. 博麗大結界の祝い酒

今年は博麗大結界ができて節目の年。
幻想郷中でお祝いしようと、皆に祝い酒のつもりで力を注いだ。
**異変**：祝いの席が幻想郷中で暴走し、結界そのものが揺らぎ始める。

### 器15. 幻想郷を一つの大きな器にしたい

山に囲まれた幻想郷は、巨大な盃の形をしている。
器として生まれた者の夢は、世界でいちばん大きな器を満たすこと。幻想郷中に力を注ぎ込み、縁まで満たそうとした。
**異変**：幻想郷に妖力が満ちていき、溢れれば博麗大結界の外まで流れ出す。

## パターン4：神輿に担ぎ上げる程度の能力（祭りの神）

| # | 動機 | 起きる異変 | 雰囲気 |
|---|------|------------|--------|
| 神輿1 | ダムに沈んだ村の最後の祭り | 幻想郷中が勝手に祭りを始める | 切ない |
| 神輿2 | 神輿は軽いほうがいい | 妖精が「幻想郷の王」を名乗って大暴れ | 策士・コミカル |
| 神輿3 | 推しを天下一にしたい | 熱狂で力を得た推しが暴走する | コミカル |
| 神輿4 | 喧嘩神輿がしたい | 各勢力がぶつかり合い、幻想郷が合戦状態に | 熱血 |
| 神輿5 | 御神体のオーディション | 担がれては暴走する者が連鎖的に増える | コミカル |
| 神輿6 | 祭りが終わると消えてしまう | 祭りが何日たっても終わらない | 切ない |
| 神輿7 | 景気づけ | 盛り上がりすぎて誰も働かない | コミカル |
| 神輿8 | 本当は祟りを鎮めるためだった | 熱狂で皆が暴走。止めると本当の祟りが目覚める | シリアス・どんでん返し |
| 神輿9 | 神様を元の社に帰してあげたい | 熱狂で博麗大結界が揺らぐ | 切ない |
| 神輿10 | 担ぎ手がほしい | 住人たちが一人の人物を狂信的に崇め出す | 怖い |
| 神輿11 | 消えかけの神に最後の晴れ舞台を | 力を取り戻した古い神が祟り神になりかける | 切ない |
| 神輿12 | ハレとケ | 幻想郷がずっと「ハレの日」のまま、誰も日常に戻れない | 民俗学・知的 |
| 神輿13 | 外の世界を見返したい | 参加しない者まで無理やり祭りに担ぎ出される | 見返し |
| 神輿14 | 人間の英雄を作りたい | 英雄に率いられた人間たちが妖怪退治に乗り出す | 意外性 |
| 神輿15 | 巫女を祭りの主役にしたかった | 担ぎ上げられた別の巫女が張り切りすぎて暴走 | コミカル・自機が当事者 |

### 神輿1. ダムに沈んだ村の最後の祭り

村ごとダムの底に沈み、担ぎ手も帰る社も失った神輿。
最後にもう一度だけ、村の祭りを再現しようとした。
**異変**：幻想郷中が勝手に祭りを始め、誰も止められない。

### 神輿2. 神輿は軽いほうがいい

「担ぐ神輿は軽くて扱いやすいのがいちばん」が信条。
何も考えていない妖精を「幻想郷の王」に祭り上げて、裏から操ろうとした。
**異変**：力を得た妖精が王を名乗り、妖精たちを率いて大暴れする。

### 神輿3. 推しを天下一にしたい

誰にも知られていない小さな妖怪を「推し」と決め、幻想郷一の人気者に担ぎ上げようとした。
**異変**：熱狂的な支持で力を得た推しが暴走し、ファンたちも手がつけられない。
心綺楼（宗教家たちの人気取り）と少し似るので、描き方で差をつけたい。

### 神輿4. 喧嘩神輿がしたい

神輿同士をぶつけ合う「喧嘩神輿」の出身。
幻想郷の各勢力の長をそれぞれ神輿に担ぎ上げて、ぶつけ合わせようとした。
**異変**：各勢力が熱狂に呑まれて衝突し、幻想郷中が合戦状態になる。
これも心綺楼と似るので注意。

### 神輿5. 御神体のオーディション

乗せていた神様に逃げられ、空っぽになった神輿。
新しい御神体を探して、候補者を次々と担ぎ上げては試している。
**異変**：担ぎ上げられては暴走する者が、連鎖的に増えていく。

### 神輿6. 祭りが終わると消えてしまう

祭りの間しか存在できない神。祭りが終われば一年眠る……はずが、外の世界では次の祭りが来なかった。
今度こそ消えたくないので、祭りを終わらせない。
**異変**：幻想郷の祭りが、何日たっても終わらない。

### 神輿7. 景気づけ

最近の幻想郷は不景気で、人里も妖怪もしょぼくれている。
「景気をつけるには祭りがいちばん」と、皆を担ぎ上げて盛り上げようとした。
**異変**：盛り上がりすぎて、誰も働かずに騒ぎ続ける。

### 神輿8. 本当は祟りを鎮めるためだった

祇園祭は、もともと疫病をもたらす怨霊を鎮めるための「御霊会」だった。
幻想郷に強い祟りが目覚めかけていることに気づき、それを鎮めるための大祭を起こそうとした。
**異変**：祭りの熱狂で人も妖怪も暴走する。ただし祭りを止めてしまうと本当の祟りが目を覚ますので、Extraにつなげられる。

### 神輿9. 神様を元の社に帰してあげたい

外の世界の社から、神様を乗せたまま幻想入りしてしまった。
神様を元の社へ送り届けるには、博麗大結界を越えるほどの熱狂が要る。
**異変**：祭りの熱狂で博麗大結界が揺らぎ始める。

### 神輿10. 担ぎ手がほしい

祭りを支える氏子（担ぎ手）がほしい。
ある一人を熱狂的な崇拝の的に担ぎ上げ、その信者たちをそのまま自分の担ぎ手にしようとした。
**異変**：幻想郷の住人たちが、一人の人物を狂信的に崇め出す。

### 神輿11. 消えかけの神に最後の晴れ舞台を

忘れられて消えかけている古い神様を乗せている。
消えてしまう前に、一度だけ盛大な祭りで晴れ舞台に立たせてあげたかった。
**異変**：力を取り戻した古い神が荒ぶり、祟り神になりかける。

### 神輿12. ハレとケ

日常（ケ）の気力が枯れた状態を「ケガレ（褻枯れ）」と呼び、祭り（ハレ）で取り戻すという民俗学の考え方がある。
幻想郷のケが枯れかけていると感じ、ハレで満たそうとした。
**異変**：幻想郷がずっと「ハレの日」のままになり、誰も日常に戻れない。

### 神輿13. 外の世界を見返したい

外の世界の人間に「祭りなんて古い」と捨てられた。
幻想郷で史上最大の祭りを開いて、見返そうとした。
**異変**：祭りがどんどん大きくなり、参加しない者まで無理やり担ぎ出される。

### 神輿14. 人間の英雄を作りたい

妖怪に怯えてばかりの人里の人間たちを見て、勇気を与えたくなった。
ごく普通の人間を「英雄」に担ぎ上げた。
**異変**：英雄に祭り上げられた人間が、人里の人々を率いて妖怪退治に乗り出す。霊夢は人間を止める側に回る。

### 神輿15. 巫女を祭りの主役にしたかった

祭りの主役はやっぱり巫女。博麗の巫女を担ぎ上げようとしたが断られ、代わりに別の巫女（守矢の風祝など）を担ぎ上げた。
**異変**：担ぎ上げられた巫女が張り切りすぎて暴走する。霊夢にとっては商売敵の騒ぎ。
