# オンラインのアカウント・ランキングの準備（Firebase）

アカウントとスコアを、ブラウザや端末が変わっても同じように使えるようにし、
みんなのスコアを1つのランキングで共有するための準備です。
Google の無料サービス **Firebase** を使います（少人数で遊ぶぶんには無料の範囲で足ります）。

準備が終わるまでは、今までどおり「このブラウザだけ」に保存されます。

## 1. Firebase のプロジェクトを作る

1. <https://console.firebase.google.com> を開き、Google アカウントでログインする
2. 「プロジェクトを作成」（または「プロジェクトを追加」）を押す
3. 名前を入れる（例：`hoshifuru`）。Google アナリティクスは使わなくてよい（オフ）
4. 「プロジェクトを作成」を押して、できあがるまで待つ

## 2. ログインの方法を有効にする

1. 左のメニューの「構築」→「Authentication」→「始める」
2. 「ログイン方法」のタブで「メール / パスワード」を選ぶ
3. 一番上の「メール / パスワード」を **有効** にして「保存」（その下の「メールリンク」はオフのまま）

ゲームでは、ユーザー名から作った専用のアドレス（本物のメールアドレスではない）でログインします。
プレイヤーがメールアドレスを入れることはありません。

## 3. データベースを作る

1. 左のメニューの「構築」→「Firestore Database」→「データベースを作成」
2. 場所は `asia-northeast1`（東京）がおすすめ
3. 「本番環境モードで開始」を選んで作成する

## 4. ルールを貼る

1. 「Firestore Database」の「ルール」のタブを開く
2. このリポジトリの `firebase/firestore.rules` の中身を **全部** 貼りつけて（もとの文は消す）、「公開」を押す

このルールで「ランキングはだれでも読める」「記録を書けるのは本人と管理者だけ」になります。

## 5. 設定の値を調べる

1. 左上の歯車（プロジェクトの設定）→「全般」
2. 下の「マイアプリ」で `</>`（ウェブ）を押し、ニックネーム（例：`hoshifuru`）を入れて「アプリを登録」
   （「Firebase Hosting も設定する」はチェックしなくてよい）
3. 表示される `firebaseConfig` の中の **`apiKey`** と **`projectId`** をメモする

## 6. ゲームに設定を入れる

次の3つを Claude に伝えれば、設定してルールも作り直します。

- `apiKey`
- `projectId`
- 管理者にするユーザー名（プレイヤー管理で、ほかの人の記録を消したりリセットしたりできる人。例：自分のユーザー名）

自分で入れるときは：

1. `js/online-config.js` の `apiKey`・`projectId`・`admins` を書く
2. `node tools/firestore-rules.js` を実行して `firebase/firestore.rules` を作り直し、手順 4 のルールを貼り直す
3. `node tools/build-single.js` で1ファイル版を作り直す

設定したら、**管理者のユーザー名はすぐに自分で登録** してください（ほかの人に先に登録されないように）。

`apiKey` は公開してかまわない値です（守りはルールで行います）。

## 7. みんなに遊んでもらう

オンラインのランキングは、ゲームを開いた場所に関係なく共有されます。

- **いちばん簡単**：1ファイル版 `dist/hoshifuru.html` をそのまま渡す。
  ダブルクリックで遊べて、インターネットにつながっていればオンラインのランキングに参加できます
- **URL で配りたいとき**：ふつうの Web ページとして公開する（例：GitHub Pages、Netlify、Firebase Hosting）
- claude.ai の共有ページの中では、外のサービスと通信できないことがあります。
  そのときはタイトル画面などに「オフライン」と出るので、上のどちらかの方法で配ってください

## しくみと注意

- パスワードは Firebase が保管し、ゲームのデータには入りません。ほかのサイトで使っているパスワードは使わないでください
- メールアドレスを使わないので、パスワードを忘れると元に戻せません。
  そのときは管理者が Firebase の「Authentication」でその人を消し、もう一度登録してもらいます（記録は新しく始まります）
- このブラウザだけに保存していたアカウントは、**同じユーザー名とパスワードでオンラインに登録（またはログイン）すると、記録が自動で移ります**
- 通信できないときに遊んだ記録は、このブラウザに取っておき、つながったときに送ります
- スコアはゲームから送られるので、ブラウザを細工すればうそのスコアも送れてしまいます（知り合いどうしで遊ぶ前提のしくみです）
- 無料で使える量の目安（Spark プラン）：読み取り 1日 50,000 回、書き込み 1日 20,000 回。
  ランキングを開いているあいだは15秒ごとに全員分を読み直します（例：50人のランキングを5分見ると約1,000回）

## 確かめかた（開発用）

本物の Firebase がなくても、にせものの Firebase（`tools/fake-firebase.js`）で動きを確かめられます。

```
node tools/test.js オンライン
```
