# 化物屋敷異変 タイトル案

「化物屋敷異変」を描くゲーム本編のタイトル案を30個考えた資料。

- 東方の正式作品と同じ「**東方＋漢字3文字 〜 英語の副題**」の形にした（例：東方紅魔郷 〜 the Embodiment of Scarlet Devil）。
- 漢字3文字は「テーマの2文字＋建物や記録を表す1文字」の組み合わせを基本にした。
- 5つのテーマで6個ずつ考え、最後に「おすすめ3」を選んだ。
- 既存の東方の正式作品のタイトルとは重ならないようにした。ただ、二次創作の作品は数が多いので、決める前に同名の作品がないか一度検索すると安心。

## 最後の1文字の意味

| 字 | 意味 | 正式作品での例 |
|---|---|---|
| 邸・殿・館・楼 | 屋敷・御殿・高い建物 | 地霊殿 |
| 郷 | 里、ふるさと | 紅魔郷 |
| 録・記・抄 | 記録、書き抜き | 風神録、永夜抄 |
| 伝・譚 | 言い伝え、物語 | 紺珠伝 |
| 夢 | 夢 | 妖々夢 |
| 宴・唄・盤 | 宴、歌、盤（方位盤など） | ― |
