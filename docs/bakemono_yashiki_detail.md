# 化物屋敷異変 詳細構成（第2版）

絞り込み版の「B-54 化物屋敷異変」を、全6面＋Extraの弾幕シューティング1本分の構成に広げたもの。第2版では、ご指定どおりに1〜6面の配役と流れを組み直した。

- 各面のボスと自機の会話の案（戦闘前・戦闘後、各面10パターン）は「化物屋敷異変 会話集」、採用した会話は「化物屋敷異変 セリフ決定稿」にまとめた。会話の内容は決定稿を優先する。
- Extraは10案から「EX-2 金神の祟り」を採用した（詳細は「8. Extra」）。
- 【既存】が付いたキャラクターは原作キャラクター。付いていないものはオリジナル。

### 第2版での主な変更点

## 1. 作品の概要

### タイトル案

| 案 | 読み | 英題 |
|---|---|---|
| 東方鳴家録 | とうほう めいかろく | Creaking Hundred-Room Manor |
| 東方百間邸 | とうほう ひゃっけんてい | Haunted Home Sweet Home |
| 東方座敷譚 | とうほう ざしきたん | The Girl Who Wanted a Home |

「鳴家」は、鳥山石燕の画集で家鳴（やなり）に当てられている字。

### あらすじ（プレイヤーが最初に知る内容）

> ある晩から、人里の家という家が軋み始めた。夜通し床が鳴り、柱がうめき、誰も眠れない。
> 翌朝、建てたばかりの家までが、百年経ったように古びていた。柱は黒ずみ、障子は破れ、天井には虫がびっしり。屋根の鬼瓦や古道具は付喪神になって勝手に動き出した。
> さらに夜が明けるたびに、古びた家から部屋が一つずつ消えていく。
> 三日目、たまらず逃げ出した住人たちが博麗神社に押し寄せた。境内は避難者でいっぱい。それなのに賽銭は一銭も増えない。
> 「……これは異変ね。いろんな意味で」

### 真相（ネタバレ）

1. 人里の大店「霧雨店」の奥座敷には、何代にもわたって座敷わらしの「わらべ」が住み着いていた。天井裏には家鳴の「きしみ」が、家の真ん中には何百年も家を支えてきた大黒柱の「ささえ」がいた。
2. 人里で建て替えが流行り、霧雨店も改築された。奥座敷はなくなり、古い大黒柱は取り壊されて捨てられた（捨てられる寸前に、ささえは付喪神になった）。わらべも、きしみも、住む場所を失った。
3. 新しい家々はどこも座敷わらしの気配を受け付けない。わらべは「古いお家がいいなぁ。住む家が欲しいなぁ」とぼやいた。
4. わらべには、人を惹きつけて離さない力がある。きしみもささえも、わらべの幸せのためなら何でもした。
   - きしみは、人里中の家を一晩で百年分古びさせた（座敷わらしが住めるのは、人の暮らしが染みついた古い部屋だけ）。
   - ささえは、古びた家から部屋を一つずつ引き抜き、自分を大黒柱にして継ぎ合わせ、百部屋ある「百間屋敷」を建てた。屋敷は家と家の隙間に隠した。
5. わらべは何も頼んでいない。ぼやいただけで、自分の力にも自覚がない。ただ、やっと見つかったいいお家に喜んで住んでいる。

### 構成の骨組み

| 面 | ボス | 異変との関係 |
|---|---|---|
| 1面 | 鬼瓦 いかめ | 異変の副作用で生まれたばかりの付喪神 |
| 2面 | 家守 ひっつき | 異変の恩恵を受けている（古い家に虫が湧いて食べ放題） |
| 3面 | 滑瓢 ぬらり | 最初に黒幕と疑われる。逃げ込もうとしたせいで、隠れていた百間屋敷が見つかる |
| 4面 | 大黒柱 ささえ | 百間屋敷を建てた張本人で、屋敷の心臓。倒すと屋敷が崩れ始める |
| 5面 | 家鳴 きしみ | 人里の家を古びさせた実行犯。崩れる屋敷から座敷わらしを逃がそうとしている |
| 6面 | 座敷 わらべ | 真犯人。ただし本人に自覚はない |
| Extra | 金神 うしとら | 屋敷を自分の方角に建てられ、崩され、瓦礫まで落とされた方位神。6面直後に瓦礫を吹き飛ばして現れる |

前半（1〜3面）は異変の副作用をたどって屋敷を見つけるまで、4面で屋敷の主を倒すと屋敷が崩れ始め、後半（5〜6面）は崩壊の中での追跡劇になる。

## 2. 異変の時系列

| 時期 | 出来事 |
|---|---|
| 数か月前 | 人里で建て替えが流行る。霧雨店も改築され、奥座敷がなくなり、古い大黒柱は捨てられる |
| 数週間前 | わらべ、きしみ、ささえが宿無しになる。霧雨店の商いが、ほんの少しずつ傾き始める |
| 異変の前夜 | わらべが「住む家が欲しいなぁ」とぼやく |
| 1日目の夜 | きしみと家鳴の群れが、人里中の家を揺すって古びさせる |
| 2日目 | 家が百年分古びる。鬼瓦や古道具が付喪神になり、虫が湧く。夜明けとともに部屋が消え始める |
| 3日目 | 住人が博麗神社へ避難する。空き家に、ぬらりひょんが上がり込み始める |
| 3日目の夜 | 霊夢と魔理沙が動き出す（ゲーム開始） |
| 4日目の夜明け前 | 百間屋敷が崩れ、部屋は元の家へ、家は元の姿へ戻る（ゲームクリア） |
| 同じ夜明け前（Extra） | 屋敷が崩れた直後、瓦礫の山を吹き飛ばして金神が現れる |

## 3. 自機と動機

| 自機 | 動機 |
|---|---|
| 博麗霊夢【既存】 | 避難者で神社が手狭になったのに、賽銭は増えない。とにかく人里に帰ってもらいたい |
| 霧雨魔理沙【既存】 | 「家が古くなる異変なんて面白そうだ」と言って出かける。本当は、実家の霧雨店の噂が気になっている（本人は認めない） |

魔理沙ルートでは、4面以降で「ささえは霧雨店の大黒柱」「わらべは霧雨店の座敷わらし」だと分かり、家を出た魔理沙の過去と重なる。霧雨店が人里の道具屋で、森近霖之助が修業した店だという原作設定を使う。

## 4. ゲームシステム

### 家運システム

座敷わらし（福の神）を題材にした、作品独自のシステム。

| 要素 | 内容 |
|---|---|
| 福アイテム | 敵を倒すと出る小判型のアイテム。取ると家運ゲージが上がる |
| 家運ゲージ | 0〜100％。高いほど得点アイテムの点数が上がる。50％以上でショットに「福弾」が追加される |
| 家運隆盛 | ゲージが100％になると一定時間発動。ショット強化と弾消し |
| 家運が傾く | 被弾するとゲージが半分になる |

### 崩壊ギミック（5面・6面）

4面で大黒柱を倒すと、5面と6面は崩れゆく屋敷の中が舞台になる。

| 要素 | 内容 |
|---|---|
| 落下物 | 梁や瓦が上から落ちてくる。弾ではないが、当たると被弾扱い。撃つと壊せて、福アイテムが出る |
| 床の傾き | 屋敷が傾くと、敵弾も傾いた方向へ流される |
| 崩壊の進行 | 道中が進むほど背景が崩れていき、6面の最後には屋敷が完全に崩れ落ちる |

## 6. 各ステージの詳細

### 1面「一夜で古びた屋根瓦」

**舞台**：夜の人里。百年分古びた家々の屋根の上を進む。

**道中**：

- 雑魚敵は、異変で生まれたばかりの付喪神たち（瓦、雨樋、風見鶏）。どれも生まれたてで動きがぎこちない。
- 屋根の上から、神社へ逃げる避難者の提灯行列が見える。

#### ボス：鬼瓦 いかめ（おにがわら いかめ）

| 項目 | 内容 |
|---|---|
| 二つ名 | 屋根の上の新米鬼 |
| 種族 | 鬼瓦の付喪神（自称・鬼） |
| 能力 | 睨みで魔を払う程度の能力（本人は「鬼の力」だと思っている） |
| 異変との関係 | 異変の副作用で生まれた |

- **設定**：家が一晩で百年分古びたことで、屋根の鬼瓦から付喪神になったばかり。生まれてまだ一日。付喪神だとは分かっているが、厳つい鬼の顔をしているので「鬼でもある」と言い張っている。世間知らずで、自分の力を過信している。人間に会うのは自機が初めて。
- **性格**：「ふっ、人間か。かかって来いよ」と言わんばかりに調子に乗っている。自分のレベルがまったく分かっていない。
- **戦う理由**：生まれて初めて見た人間に、鬼の力を見せつけたい。
- **スペルカード**
  - 瓦符「鬼瓦の睨み」：睨んだ方向へ、扇状に弾を撃つ。
  - 屋符「屋根の上から失礼」：画面の上から、瓦の形の弾が降ってくる。

### 2面「湧き放題の裏長屋」

**舞台**：古びて虫が湧いた人里の裏長屋。家の中を通り抜けながら進む。

**道中**：

- 天井や壁から虫の群れが湧いてくる。虫自体は弱いが、数が多い。
- 家守の仲間のヤモリたちが、壁を這って虫を追いかけている（敵でも味方でもない）。

#### ボス：家守 ひっつき（やもり ひっつき）

| 項目 | 内容 |
|---|---|
| 二つ名 | 壁に貼りつく小さな守り神 |
| 種族 | 家守（ヤモリの妖怪） |
| 能力 | 壁や天井に張り付く程度の能力 |
| 異変との関係 | 異変の恩恵を受けている |

- **設定**：「家を守る」と書いてヤモリ。人の家の壁に張り付き、虫を食べて暮らしている。家が古びて虫が湧き、毎晩ごちそう続き。
- **立場**：自機が「うわっ、虫湧いてる」と嫌がるのが心から理解できない。「どこがそんなに嫌なの？」という立場で、異変を終わらせようとする自機を邪魔する。
- **戦闘後**：「異変が終わる前に、今のうちに腹いっぱい食べておこう」と意気込む。
- **スペルカード**
  - 守符「家守の夜回り」：画面の端から、壁を這うように弾が伸びてくる。
  - 尾符「トカゲの尻尾切り」：撃ち込むと尻尾（弾の発射元）が切れ、独立して撃ってくる。
  - 虫符「湧き放題の天井裏」：天井から虫の群れのような細かい弾がばらばらと降ってくる。

### 3面「主なき家の茶の間」

**舞台**：住人が避難して空き家ばかりになった住宅街から、人里の外れへ。

**道中の流れ**：

1. **前半（空き家）**：古くなった家の茶の間で、ぬらりが家主のような顔でお茶を飲んでいる。自機に気付くと「うちになんか用？」と家主のふりをして対応しようとするが、速攻で見破られて逃げ出す（中ボス戦）。
2. **後半（追跡）**：逃げるぬらりを追いかけ、路地や屋根を抜けて人里の外れへ。ぬらりは「家と家の隙間」にある何かへ逃げ込もうとしている。
3. **ボス戦**：隙間の奥、何もないはずの場所の前で追いつき、ボス戦が始まる。

#### ボス：滑瓢 ぬらり（ぬらりひょん ぬらり）

| 項目 | 内容 |
|---|---|
| 二つ名 | 空き家に居座る総大将 |
| 種族 | ぬらりひょん |
| 能力 | いつの間にか上がり込む程度の能力 |
| 異変との関係 | 無関係。ただし、いかにも黒幕らしいので最初に疑われる |

- **設定**：いつの間にか他人の家に上がり込み、主人のような顔でお茶を飲んで帰っていく妖怪。空き家だらけになった人里で、家から家へ渡り歩いて「主人」を満喫していた。
- **逃げた先**：家と家の隙間から「大きな空き家」の気配を嗅ぎつけ、そこに隠れようとしていた。入ったことはなく、誰が建てたのかも知らない。
- **戦闘後**：屋敷について聞かれても、よく知らない。ただ、どんな家にも上がり込めるぬらりが戸口に手をかけたせいで、隠されていた百間屋敷の入口が開き、屋敷が姿を現す。
- **スペルカード**
  - 瓢符「ぬらりくらりの上がり框」：気付けば弾がもう画面の中にある（前触れなく現れる弾）。
  - 茶符「主人顔の一服」：湯呑み型の弾が、ゆっくり回りながら広がる。
  - 逃符「勝手口からお暇」：ぬらりが画面の端から端へ逃げ回り、逃げた跡に弾が残る。
  - 総大将「百鬼夜行の先頭」：背後に妖怪の行列が現れ、弾の列になって押し寄せる。

### 4面「百間屋敷の長廊下」

**舞台**：家と家の隙間に隠されていた「百間屋敷」。人里の古い家から引き抜いた百の部屋が、廊下と階段で継ぎ合わされている。玄関から奥へ進み、屋敷の真ん中にある「大黒柱の間」を目指す。

**道中**：

- 茶の間、台所、客間、納戸……どこかで見たような部屋が次々に現れる。部屋ごとに元の家の生活感が残っている。
- 廊下は迷路のようにつながっていて、自機は壁や襖を突き破って最短距離で進む（豪快な不法侵入）。
- 中ボスは家鳴の子分たち。天井裏から群れで湧いてくる。

#### ボス：大黒柱 ささえ（だいこくばしら ささえ）

| 項目 | 内容 |
|---|---|
| 二つ名 | 百間屋敷の心臓 |
| 種族 | 大黒柱の付喪神 |
| 能力 | 家を支え、繋ぎ合わせる程度の能力 |
| 外見 | 背が高く、背筋がまっすぐ。黒光りする柱を思わせる着物に、棟札の形の髪飾り |
| 異変との関係 | 百間屋敷を建てた張本人（家鳴と共犯）。屋敷は彼女が支えている |

- **設定**：何百年も霧雨店を支えてきた大黒柱。改築で取り壊され、捨てられる寸前に付喪神になった。家鳴の協力で古びた家々から部屋を集め、自分を大黒柱にして百間屋敷を建てた。屋敷の主として、断りなく上がり込む者を何より嫌う。
- **戦う理由**：壁も襖もぶち抜いて豪快に不法侵入してきた自機に、ぶち切れている。何のために屋敷を建てたのかと聞かれても、最後まで話を濁す。
- **戦闘後**：ささえが倒れたことで、屋敷を保てなくなり崩壊が始まる。ささえは自機に避難を勧めるが、自機は無視して本当の黒幕を探しに奥へ向かう。屋敷を建てた理由は最後まで明かさない（魔理沙ルートでは、誰かをかくまっていることを魔理沙に見抜かれる）。
- **スペルカード**
  - 柱符「大黒柱の屋台骨」：ささえを中心に、柱と梁の形をした弾が格子状に組み上がる。
  - 建符「百間継ぎの建て増し」：部屋の形の弾の囲いが、次々に建て増しされて迫ってくる。
  - 梁符「落ちてこない梁」：頭上に梁の形の弾が並び、ささえが力を緩めると一斉に落ちてくる。
  - 棟符「棟上げの餅撒き」：上棟式の餅撒きのように、丸い弾が四方にばら撒かれる。
  - 家符「家を支える者の意地」：画面全体が軋み、ささえが倒れかけるほど弾幕が激しくなる。

### 5面「崩れゆく百の部屋」

**舞台**：崩れ始めた百間屋敷。廊下が傾き、梁が落ち、部屋が一つずつ崩れていく。

**道中**：

- 崩壊ギミックが本格的に始まる。落ちてくる梁や瓦をかわし、傾いた床で流される弾をさばきながら進む。
- 家鳴の子分たちは、崩れる屋敷から逃げ惑いながらも、自機の足止めをしてくる。
- 中ボスは「落ちてくる大天井」。天井が丸ごと落ちてくるので、撃ち抜いて穴を開けて抜ける。

#### ボス：家鳴 きしみ（やなり きしみ）

| 項目 | 内容 |
|---|---|

### 採用：EX-2「金神の祟り」

**位置づけ**：本編クリア後に遊べるExtraモード。時系列は6面の直後で、エンディングより前にあたる。

**流れ**：

1. **開幕**：6面でわらべを倒し、百間屋敷が崩れ落ちる。部屋が光になって人里へ帰っていき、辺りが静まり返る。
2. **登場**：次の瞬間、瓦礫の山が内側から吹き飛び、金神がぶち切れながら現れる。そのまま会話（戦闘前）になり、戦闘開始。わらべ・きしみ・ささえは、自機の後ろの瓦礫に隠れている。
3. **前半戦（中ボス）**：瓦礫の上で金神と第一戦。
4. **道中**：金神が「ここでは狭い」と方位盤の異界を広げ、自機を引きずり込む。十二支の方位が刻まれた巨大な盤の上を、方角が回転する中で進む。雑魚は八将神（方位を司る八柱の神）の使い。
5. **ボス戦**：方位盤の中心で金神と決着。
6. **戦闘後**：会話のあと、Extraエンディングへ（「7. エンディング」を参照）。

#### Exボス：金神 うしとら（こんじん うしとら）

| 項目 | 内容 |
|---|---|
| 二つ名 | 方位を統べる祟り神 |
| 種族 | 方位神（金神） |
| 能力 | 方角を祟る程度の能力 |
| 外見 | 金色の髪に、十二支の刻まれた方位盤の光輪を背負う。怒ると髪が逆立ち、金色に燃え上がる |
| 異変との関係 | 被害者。ただし怒りの矛先は全員 |

- **設定**：陰陽道の方位神。年や季節ごとに方角を巡り（遊行）、自分のいる方角で家を建てたり引っ越したりする者を祟る。昔の人々は「方違え」で回り道をして金神を避けたものだが、今では誰も気にしない。
- **怒りの理由**
  1. 今季の金神が座していた、人里から見て艮（北東）の方角に、断りもなく百間屋敷が建てられた。
  2. その屋敷が崩れ落ち、百部屋分の瓦礫が丸ごと自分の上に降ってきた。
  3. 屋敷を建てたささえ・きしみも、崩した自機も、誰一人として方角を気にしていない。
- **性格**：決まりごとにうるさく、怒りっぽい。ただし筋を通せば話は聞く。
- **口調**：一人称は「妾（わらわ）」。「〜であるぞ」「〜とは何事か！」と古風だが、怒りが頂点に達すると言葉が荒くなる。
- **決め台詞**：戦闘前の会話の最後、ボス曲が始まる直前に怒鳴り声がふっと止み、方位を統べる神としての静かで荘厳な決め台詞を言う。10案は会話集のExtraを参照。
- **テーマ**：方違えを忘れられ、居場所を失った古い神。古いものが捨てられていく、という本編の主題をExtraでも受け継いでいる。

## 10. 設定メモ

- 第1版の多々良小傘と目目連は、第2版では使っていない。小傘は1面の雑魚付喪神の中に顔を出させる、目目連は4面の部屋の障子に目だけ出す、といった小ネタで残すこともできる。
- わらべの能力は、第1版の「住み着いた家を栄えさせる程度の能力」に「人を惹きつける」を足した。きしみとささえが異変を起こした理由そのものになっている。
- 霧雨店（魔理沙の実家の道具屋）と、森近霖之助がそこで修業したことは原作設定。座敷わらし・家鳴・大黒柱が住んでいたこと、改築したことは今作の創作。
- 金神・方違え・八将神・大将軍の三年塞がり・「金神七殺」は、陰陽道の方位の言い伝えから取っている。「七殺」は金神の祟りで家族七人に災いが及ぶという言い伝えなので、表現の重さは調整してよい。
- 不採用のExtra案に出てくる既存キャラクター（依神姉妹、星熊勇儀、八雲藍、橙、河城にとり、ドレミー・スイート）の能力や肩書きの表記は、使う前に原作で確認すること。
