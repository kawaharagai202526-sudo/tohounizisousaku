# 化物屋敷異変 詳細構成

絞り込み版の「B-54 化物屋敷異変」を、全6面＋Extraの弾幕シューティング1本分の構成に広げたもの。

- 5面犯人型：5面の家鳴が実行犯、6面の座敷わらしが真犯人（本人に自覚はない）。
- 【既存】が付いたキャラクターは原作キャラクター。付いていないものはオリジナル。

---

## 1. 作品の概要

### タイトル案

| 案 | 読み | 英題 |
|---|---|---|
| 東方鳴家録 | とうほう めいかろく | Creaking Hundred-Room Manor |
| 東方百間邸 | とうほう ひゃっけんてい | Haunted Home Sweet Home |
| 東方座敷譚 | とうほう ざしきたん | The Girl Who Wanted a Home |

「鳴家」は、鳥山石燕の画集で家鳴（やなり）に当てられている字。

### あらすじ（プレイヤーが最初に知る内容）

> ある晩から、人里の家という家が軋み始めた。夜通し床が鳴り、柱がうめき、誰も眠れない。
> 翌朝、建てたばかりの家までが、百年経ったように古びていた。柱は黒ずみ、障子は破れ、天井には蜘蛛の巣。家中の古道具は付喪神になって勝手に歩き回っている。
> 三日目、たまらず逃げ出した人里の住人たちが博麗神社に押し寄せた。境内は避難者でいっぱい。それなのに賽銭は一銭も増えない。
> 「……これは異変ね。いろんな意味で」

### 真相（ネタバレ）

- 人里の大店「霧雨店」の奥座敷には、何代にもわたって座敷わらしの「わらべ」が住み着いていた。
- 人里で建て替えが流行り、霧雨店も改築されて奥座敷がなくなった。わらべは出ていくしかなかった。
- 新しい家々はどこも座敷わらしの気配を受け付けず、わらべは行く当てもなくさまよう。そして「古い家がいいなぁ。住む家が欲しいなぁ」とぼやいた。
- 霧雨店の天井裏で長年わらべと暮らしてきた家鳴の頭目「きしみ」がそれを聞いた。きしみは「古い家がないなら、古くすればいい」と考え、人里中の家を一晩で百年分古びさせた。
- さらにきしみは、古びた家を継ぎ接ぎして、人里の外れに"最高の古い家"「百間屋敷」を建てた。わらべは喜んでその奥座敷に住み着いた。
- わらべは何も頼んでいない。ただ、やっと手に入れた家から出ていきたくない。

### 構成の骨組み

1〜4面のボスは全員、異変そのものには関わっていない。家が古びたことの「副作用」で現れたか、得をしている妖怪たち。プレイヤーは副作用をたどって、原因（5面）と、その原因の原因（6面）へ近づいていく。

| 面 | ボス | 異変との関係 |
|---|---|---|
| 1面 | 家守 ひっつき | 古い家に虫が増えて得をしている |
| 2面 | 多々良小傘【既存】 | 古道具が一斉に付喪神になり、その先輩として大はしゃぎ |
| 3面 | 目目連 まなこ | 破れた障子に湧いた目の妖怪。異変の目撃者 |
| 4面 | 滑瓢 ぬらり | 空き家に上がり込んでいるだけ。いかにも怪しいが無関係（ミスリード役） |
| 5面 | 家鳴 きしみ | 実行犯 |
| 6面 | 座敷 わらべ | 真犯人（無自覚） |
| Extra | 三宝 くど | 異変解決後、博麗神社で起きる後日談 |

## 2. 異変の時系列

| 時期 | 出来事 |
|---|---|
| 数か月前 | 人里で建て替えが流行る。霧雨店も改築され、奥座敷がなくなる |
| 数週間前 | わらべが霧雨店を出る。天井裏を失った家鳴たちもついていく。霧雨店の商いが、ほんの少しずつ傾き始める |
| 異変の前夜 | わらべが「住む家が欲しいなぁ」とぼやき、きしみが聞いてしまう |
| 1日目の夜 | 人里中の家で家鳴りが始まる |
| 2日目 | 家が百年分古びる。古道具が一斉に付喪神になり、破れた障子に目目連が湧く |
| 3日目 | 住人が博麗神社へ避難する。人里の外れに百間屋敷が現れる。空き家にぬらりひょんが上がり込み始める |
| 3日目の夜 | 霊夢と魔理沙が動き出す（ゲーム開始） |

## 3. 自機と動機

| 自機 | 動機 |
|---|---|
| 博麗霊夢【既存】 | 避難者で神社が手狭になったのに、賽銭は増えない。とにかく人里に帰ってもらいたい |
| 霧雨魔理沙【既存】 | 「家が古くなる異変なんて面白そうだ」と言って出かける。本当は、実家の霧雨店の噂が気になっている（本人は認めない） |

魔理沙ルートでは、6面で「わらべが霧雨店の座敷わらしだった」と分かり、家を出た魔理沙の過去と重なる。霧雨店が人里の道具屋で、森近霖之助が修業した店だという原作設定を使う。

## 4. ゲームシステム「家運システム」

座敷わらし（福の神）を題材にした、作品独自のシステム。

| 要素 | 内容 |
|---|---|
| 福アイテム | 敵を倒すと出る小判型のアイテム。取ると家運ゲージが上がる |
| 家運ゲージ | 0〜100％。高いほど得点アイテムの点数が上がる。50％以上でショットに「福弾」が追加される |
| 家運隆盛 | ゲージが100％になると一定時間発動。ショット強化と弾消し |
| 家運が傾く | 被弾するとゲージが半分になる |

ボスごとの連動：

- **5面 家鳴戦**：スペルカード中は、家が古びていくのに合わせて家運がじわじわ減る。
- **6面 わらべ戦**：わらべの近く（画面上部）にいるほど家運が上がる。福の神に近づくほど得をするが、そのぶん危ない。
- **Extra 荒神戦**：家運が高いほど荒神の火も強くなる（栄えた家ほど竈の火は盛ん）。家運をあえて下げて戦う選択肢が生まれる。

## 6. 各ステージの詳細

### 1面「軋む夜道」

**舞台**：博麗神社の参道から人里へ向かう夜道。遠くの人里から、家々の軋む音が聞こえてくる。

**道中**：

- 雑魚敵は妖精と、壁や木の幹を這うヤモリ。
- 神社へ逃げる避難者の提灯行列が、自機と逆方向に流れていく（人間には当たり判定なし）。

#### ボス：家守 ひっつき（やもり ひっつき）


| 項目 | 内容 |
|---|---|
| 二つ名 | 壁に貼りつく小さな守り神 |
| 種族 | 家守（ヤモリの妖怪） |
| 能力 | 壁や天井に張り付く程度の能力 |
| 異変との関係 | なし。古い家に虫が増えて得をしている |

- **設定**：「家を守る」と書いてヤモリ。人の家の壁に張り付き、虫を食べて暮らしている。家が古びて虫が増え、毎晩ごちそう続き。異変が終わってほしくないので巫女の邪魔をする。
- **スペルカード**
  - 守符「家守の夜回り」：画面の端から、壁を這うように弾が伸びてくる。
  - 尾符「トカゲの尻尾切り」：撃ち込むと尻尾（弾の発射元）が切れ、独立して撃ってくる。
- **会話の流れ**：霊夢「こんな夜中に壁に張り付いて何してるのよ」→ ひっつき「ごちそうの見張り。最近、人里の家は虫だらけで最高なの」→ 霊夢「最高なのはあんただけよ」

### 2面「一夜で古びた大通り」

**舞台**：夜明け前の人里の大通り。両側の家並みが、スクロールするうちにみるみる古びていく。

**道中**：

- 家々の窓や戸口から、鍋・釜・箒・下駄・行灯の付喪神が次々と飛び出してくる。
- 生まれたての付喪神たちは、行列を作って大通りを練り歩いている。

#### 中ボス：古箪笥 しまいこ（ふるだんす しまいこ）

一晩で付喪神になったばかりの箪笥。引き出しを開け閉めするたびに弾が飛び出す。

#### ボス：多々良小傘（たたら こがさ）【既存】


| 項目 | 内容 |
|---|---|
| 二つ名 | 愉快な忘れ傘 |
| 種族 | 唐傘お化け（付喪神） |
| 能力 | 人間を驚かす程度の能力 |
| 異変との関係 | なし。古道具が付喪神になったのは異変の副作用 |

- **設定**：家が百年分古びて、家中の古道具が一斉に付喪神になった。小傘は「先輩」として新米たちを率いて大はしゃぎ……のはずが、人間は古びた家に怯えるばかりで、誰も自分に驚いてくれない。腹いせに巫女を驚かせようとする。
- **スペルカード**
  - 傘符「お化け屋敷の忘れ傘」：傘を回して、雨粒のような弾を降らせる。
  - 化符「一晩付喪神パレード」：鍋や下駄や行灯の形をした弾が、行列になって画面を横切る。
  - 驚符「見返り家鳴り」：画面の下（背後）から弾が飛んでくる、驚かし弾幕。
- **会話の流れ**：小傘「人間たち、家が軋むたびに悲鳴を上げるのに、私が出ても誰も驚かないの！」→ 霊夢「家のほうが怖いんでしょ」→ 小傘「くやしいー！ せめて巫女だけでも驚かせてやる！」

### 3面「稗田邸の破れ障子」

**舞台**：人里で一番の旧家、稗田邸。もともと古い屋敷がさらに百年古びて、長い縁側に破れ障子の部屋がずらりと並ぶ。

**道中**：

- 障子の穴に次々と目が開き、自機を目で追いかけてから弾を撃つ。
- 屋敷の主・稗田阿求【既存】が会話だけで登場する。幻想郷縁起の「家鳴」の項を見せて、「家を一晩で古くするなら、家に棲む妖怪の仕業では」とヒントをくれる。

#### ボス：目目連 まなこ（もくもくれん まなこ）


| 項目 | 内容 |
|---|---|
| 二つ名 | 障子の穴から覗くもの |
| 種族 | 目目連 |
| 能力 | 障子の穴から覗き見る程度の能力 |
| 異変との関係 | 目撃者。夜中に小鬼の群れが家を揺すって古くしていたのを見ていた |

- **設定**：古びて破れた障子の穴に宿る、無数の目の妖怪。家が古びたことで人里中の障子に目が湧いた。中でも稗田邸の障子に棲みついたのが、まなこ。屋敷の中で起きたことはすべて見ている。
- **戦う理由**：霊夢が「障子を張り替えれば目は消える」と言い出したので、自分の住処である穴を守ろうと立ちはだかる。
- **スペルカード**
  - 目符「目目連の格子窓」：障子の格子に目玉の弾が並び、一斉にこちらを向いて撃ってくる（自機狙い）。
  - 覗符「千の目の見張り番」：画面中に目が開き、自機が動いた方向へ視線（レーザー）を送る。
  - 障符「破れ障子の穴開け」：格子状の弾の壁に、少しずつ穴が開いて通り道ができる。
- **会話の流れ**：まなこ「見てたよ。夜中に小さな鬼がたくさん来て、家を揺すって古くしていくのを」→ 霊夢「なら、その鬼の居場所を教えなさい」→ まなこ「張り替えないって約束するなら、ね」

### 4面「主なき家の茶の間」

**舞台**：住人が神社へ避難して、空き家ばかりになった人里の住宅街。家の中を、茶の間 → 台所 → 縁側と横切っていく。

**道中**：

- 誰もいないはずの茶の間で、ぬらりがいつの間にか先回りして、お茶を飲んでいる（背景演出）。
- 雑魚敵は、空き家を荒らしに来た野良妖怪と付喪神。

#### ボス：滑瓢 ぬらり（ぬらりひょん ぬらり）


| 項目 | 内容 |
|---|---|
| 二つ名 | 空き家に居座る総大将 |
| 種族 | ぬらりひょん |
| 能力 | いつの間にか上がり込む程度の能力 |
| 異変との関係 | なし。いかにも黒幕らしいミスリード役 |

- **設定**：いつの間にか他人の家に上がり込み、主人のような顔でお茶を飲んで帰っていく妖怪。空き家だらけになった人里で、家から家へ渡り歩いて"主人"を満喫している。誰もが真っ先に疑う妖怪だが、今回は本当に何もしていない。
- **スペルカード**
  - 瓢符「ぬらりくらりの上がり框」：弾が、気付けばもう画面の中にある（前触れなく現れる弾）。
  - 茶符「主人顔の一服」：湯呑み型の弾が、ゆっくりと回りながら広がる。
  - 居符「空き家渡り」：画面がいくつもの部屋に区切られ、ぬらりが部屋から部屋へ移りながら撃ってくる。
  - 総大将「百鬼夜行の先頭」：ぬらりの背後に妖怪の行列が現れ、弾の列となって押し寄せる。
- **会話の流れ**：霊夢「やっぱりあんたが黒幕ね」→ ぬらり「わしは空き家にお邪魔しただけよ。家が勝手に古くなっただけさ」→ 撃破後、ぬらり「家を古くするなんて芸当は、家に棲む者の仕業さ。家鳴りの連中を探しな。人里の外れに、えらく大きな家が建っておったぞ」

### 5面「百間屋敷の長廊下」

**舞台**：家鳴が古い家を継ぎ接ぎして建てた巨大屋敷「百間屋敷」。襖が開き続ける長廊下、階段箪笥、天井の低い部屋が延々と続く。

**道中**：

- 廊下が伸び続け、同じ廊下が何度も繰り返される（スクロールのループ演出）。襖を撃ち抜くとループを抜けられる。
- 雑魚敵は家鳴の子分たち（小鬼の群れ）。天井や床下から湧いてくる。

#### 中ボス：座敷 わらべ（顔見せ）

廊下の奥をちらりと横切り、手鞠を一つ転がして消える。手鞠が弾になって跳ね回る。6面の真犯人を先に見せておく演出。

#### ボス：家鳴 きしみ（やなり きしみ）― 実行犯


| 項目 | 内容 |
|---|---|
| 二つ名 | 天井裏の小鬼頭 |
| 種族 | 家鳴（やなり） |
| 能力 | 家を軋ませ、古びさせる程度の能力 |
| 異変との関係 | 実行犯 |

- **設定**：夜中に家を揺すって軋ませる小鬼「家鳴」の群れの頭目。何十年も霧雨店の天井裏に棲み、奥座敷のわらべを姉のように慕ってきた。改築で住処を失い、わらべと一緒に人里をさまよっていた。
- **異変での行動**：わらべの「住む家が欲しいなぁ」というぼやきを聞き、人里中の家を一晩で百年分古びさせた。さらに古びた家を継ぎ接ぎして、「わらべ姉さんのための最高の古い家」として百間屋敷を建てた。
- **戦う理由**：わらべがやっと手に入れた家を、巫女に壊させないため。
- **スペルカード**
  - 鳴符「夜中の家鳴り」：画面全体が揺れ、柱の位置から弾が軋むように不規則に伸びる。
  - 古符「一夜百年の煤払い」：撃たれた弾が時間とともに「古び」て、色と速さが変わる。
  - 継符「継ぎ接ぎ百間廊下」：画面が廊下のように区切られ、襖が開くたびに弾が飛び出す。
  - 鳴符「天井裏の大行進」：子分の家鳴たちが天井（画面の上）から一斉に降ってくる。
  - 家符「わらべ姉さんの新しいお家」：屋敷の間取り図のような弾幕。部屋の壁が弾でできている。
- **会話の流れ**：きしみ「ここはわらべ姉さんのお家だ！ やっと見つけた、姉さんの住める家なんだ！」→ 霊夢「人里の家を全部古くしておいて、よく言うわ」→ きしみ「古い家がないなら、古くすればいいだろ！」

### 6面「奥座敷へ続く襖」

**舞台**：百間屋敷の一番奥にある奥座敷。短い道中で襖を何枚も抜けた先に、金屏風・神棚・囲炉裏のある豪華な座敷がある。化物屋敷の中で、ここだけが明るく暖かく、栄えている。

**道中**：

- 襖が一枚開くごとに、屋敷が古びた様子から栄えた様子へと変わっていく。
- 雑魚は少なめ。福アイテムが大量に出る（家運システムの見せ場）。

#### 中ボス：家鳴 きしみ（再登場）

「姉さんには指一本触れさせない」と最後の足止めをする。

#### ボス：座敷 わらべ（ざしき わらべ）― 真犯人


| 項目 | 内容 |
|---|---|
| 二つ名 | 家を探す小さな福の神 |
| 種族 | 座敷わらし |
| 能力 | 住み着いた家を栄えさせる程度の能力（去った家は傾く） |
| 外見 | おかっぱ頭に赤い着物、手鞠を抱えている |
| 異変との関係 | 真犯人。ただし「住む家が欲しいなぁ」とぼやいただけで、何も頼んでいない |

- **設定**：何代にもわたって霧雨店の奥座敷に住み着き、店を人里一の大店に育ててきた座敷わらし。改築で奥座敷がなくなり、出ていくしかなかった。新しい家々は座敷わらしの気配を受け付けず、ずっと宿無しだった。百間屋敷を用意してくれたきしみに素直に感謝し、奥座敷に住み着いた。化物屋敷のままでも、わらべが住めば家は栄える。
- **戦う理由**：やっと手に入れた家から追い出されたくない。
- **スペルカード**
  - 童符「手鞠唄の数え歌」：数え歌に合わせて、手鞠の弾が一つずつ増えていく。
  - 福符「座敷わらしの足音」：姿の見えない足音。弾の通り道だけが先に見えて、あとから弾が来る。
  - 栄符「家運隆盛」：撃ち込むほど弾幕が豪華になるが、福アイテムも大量に出る。家運システムの見せ場。
  - 鬼符「わらべの隠れ鬼」：わらべが姿を消し、屏風の裏から撃ってくる。どの屏風にいるかを当てる。
  - 宿符「宿無し童子の百夜歩き」：わらべが画面中を歩き回り、足跡が弾になって残る。
  - 傾符「去りゆく家の没落」：わらべが「出ていく」動きに合わせて背景の座敷が傾き、弾が傾いた方向へ流れ落ちる。
  - ラストスペル「座敷童子のいる家」：家運ゲージを最大にすると自機が強化されるが、弾幕も最大の密度になる。
- **会話の流れ（霊夢）**：わらべ「ここは私のお家。やっと見つけたの。出ていけなんて言わないで」→ 霊夢「あんたの家のせいで、人里の家が全部化物屋敷よ」→ わらべ「……知らなかった。でも、もう宿無しは嫌なの」
- **会話の流れ（魔理沙）**：わらべ「その帽子……霧雨のお店で見たことがある」→ 魔理沙「人違いだぜ。私は森の魔法使いだ」→ わらべ「あのお店の子でしょう。あなたが出ていった日のこと、覚えてるよ」

### Extra「博麗神社の台所事情」

**導入**：異変のあと、わらべは博麗神社に住むことになった（霊夢ルートのGood Ending後）。ところがある朝、神社の台所の竈から火柱が上がる。

**舞台**：博麗神社の台所から、竈の中に広がる炎の異界へ。

#### 中ボス：座敷 わらべ

神社の先輩に挨拶しようと竈に入ったら、追い返されかけている。「先輩、すごく怒ってるの！」

#### ボス：三宝 くど（さんぽう くど）


| 項目 | 内容 |
|---|---|
| 二つ名 | 竈に棲む荒ぶる家の神 |
| 種族 | 竈神（三宝荒神） |
| 能力 | 家の火を守り、荒ぶれば家を焼く程度の能力 |
| 外見 | 三つの顔と六本の腕（三面六臂）を、炎の髪飾りと袖で表現 |

- **設定**：博麗神社が建った頃から、台所の竈に棲んできた家の神。誰からも祀られず（霊夢は竈に御札を貼ったこともない）、ひっそりと神社を守ってきた。新入りの座敷わらしが大歓迎されたことに腹を立て、竈から火柱を上げた。
- **スペルカード**
  - 竈符「三宝荒神の火伏せ」：火を封じる御札の形をした弾が、炎の弾を打ち消しながら飛ぶ。
  - 火符「火吹き竹の大風」：火吹き竹の一吹きで、炎の弾が一気に燃え広がる。
  - 炊符「一升炊きの大釜」：大釜の形に弾が煮え立ち、吹きこぼれる。
  - 灰符「竈の灰神楽」：灰が舞い上がって視界を狭め、その中から弾が来る。
  - 三宝「仏・法・僧の三面火」：三つの顔がそれぞれ違う種類の弾幕を撃つ。
  - 荒符「荒神様の御神火」：画面を囲むように炎の壁が迫ってくる。
  - 祀符「御札の貼られていない竈」：何もない場所から火が噴き出す。祀られていない怒りの弾幕。
  - 耐久スペル「荒神の怒り」：一定時間耐えきるスペル。
  - ラストスペル「竈の火は絶やさない」：家運ゲージが高いほど炎が強くなる、家運システムの総決算。

## 9. 設定メモ（原作との整合）

- 5面きしみの能力は、元の案の「家を軋ませる程度の能力」から「家を軋ませ、古びさせる程度の能力」に広げた。
- 霧雨店（魔理沙の実家の道具屋）と、森近霖之助がそこで修業したことは原作設定。座敷わらしが住んでいたこと、改築したことは今作の創作。
- 多々良小傘の二つ名「愉快な忘れ傘」と能力、稗田阿求の能力は原作の表記。使う前に原作で確認すること。
- 「座敷わらしが去った家は傾く」は、座敷わらしの伝承をそのまま使っている。
- 2面を小傘にしたのは既存キャラクターの見せ場として。オリジナルにしたい場合は、中ボスの古箪笥しまいこを2面ボスに繰り上げられる。
