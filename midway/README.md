# ミッドウェー海戦 3D俯瞰デモ

1942年6月4日〜7日のミッドウェー海戦を、約4分20秒の3D俯瞰映像として再現するデモです。

- `index.html` … three.js を CDN から読み込む版（インターネット接続が必要）
- `midway-offline.html` … three.js を同梱したオフライン版。ダブルクリックだけで再生できます

## カメラ

カメラは主要な地域・場面を自動で追いかけます（南雲機動部隊、ミッドウェー島、利根4号機、第8雷撃隊、急降下爆撃隊、飛龍の反撃、ヨークタウンなど）。攻撃隊や艦艇の動きに合わせて追尾し、数百km離れた場面へ移るときは一度高く引いてから寄ります。視聴者がカメラを動かす機能はありません。

## 操作

Space 再生／一時停止、← → 5秒移動、数字キーで章へ移動、L ラベル、H 字幕等を隠す、F 全画面。操作バーで再生速度と画質を選べます。

艦隊の位置・距離は史実をもとに簡略化したものです（艦や航空機は見やすい大きさで表示）。数字には諸説があります。
