# 音声の素材（ゲームはこのフォルダを読まない）

ユーザーがくれた音声の素材を置く。このフォルダの音は、ゲームも1ファイル版（`dist/`）も直接は読まない
（`file://` で開いても動くように、ゲームは外の音声ファイルを読まない。CLAUDE.md の「構成の決まり」）。
ゲームで鳴らすときは JS に埋めこむ：効果音は `node tools/embed-se.js`（`js/sefiles.js`）、曲は `node tools/embed-audio.js 曲ID 音声ファイル`（`js/bgmfiles.js`）。

## a-o/ … BGM の素材 a〜o（2.16.2 のあとにもらった15本の動画の音声）

ユーザーの指定「aからoをbgmとするため記憶する。…まだ実装しない」のあと、2.17.0 で効果音として使うことになった
（ユーザーが場面ごとに音を指定した。どの場面でどの音を鳴らすかは `js/audio.js` の `SE_SAMPLE`、`docs/CONTENT_GUIDE.md` の「効果音」）。
`node tools/embed-se.js` で、使う14個（l 以外）をモノラルの AAC にして `js/sefiles.js` に埋めこんでいる。音を差しかえたら作り直す。

- a〜o は、それぞれの動画の映像に大きく書かれている文字。動画のファイル名の時刻の順と同じ。
  メッセージに付いていた順（a〜f、h、g、j、k、l、m、n、o、i）とはちがったので、映像の文字に合わせた
- 本体の音の前後に入っていた別の音は、すべて消した（ユーザーの指定。下に書いた）。
  切った10本は WAV（16ビット）。切っていない5本（a・e・g・i・o）は、動画から音声だけを取り出した AAC（.m4a。変換していないので音はもとのまま）。付加情報は消した
- どれも 44.1kHz・ステレオだが、左右は同じ音（モノラルと同じ）。長さは 0.7〜4.9 秒の短い音
- 切る前の音は、このフォルダを足したコミット 9df281a にある（例：`git show 9df281a:audio/a-o/b.m4a > b.m4a`。
  h だけは、そのときから最後を切った WAV で、切る前の h はリポジトリにない）
- 埋めこむときに大きさが気になるなら、WAV を .m4a にしてもよい（WAV は 1 秒で約 170KB、.m4a は約 16KB）

### 別の音を消したところ

ユーザーの指定：はじめに「ｈは音がフェードアウトしたのち、最後に別の音声が入り込んでいる。その音声は削除しておくこと」、
そのあと Claude が b・c・n の最後にも別の音があると知らせたところ「別の音は全て消去」。
「全て」なので、Claude が見つけた、はじめに入っていた別の音も消した。
どれも、本体の音が急に始まる（または急に終わる）ところで分かれていて、本体とは音の高さの範囲がちがう音か、
前後のくり返しの切れはし（n）だったもの（もとの動画を切り出したときに入った、前後の音の切れはしと考えた）。

| 文字 | 消した部分（もとの時間） | 切った位置（サンプル） | 消したもの |

- 本体の音を切るところ（はじめ）は、本体が始まる 3ms 前で切り、最初の 2ms で大きくしていった。
  終わりは、別の音が始まる直前で切り、最後の 10ms で小さくしていった（ぷつっと鳴らないように）。無音の中で切ったところはそのまま
- それ以外のところは、もとの音と同じ（16ビットにしたときの丸めだけ）
- 途中で音の高い方の上限が段になって変わるところ（k など）は、音を圧縮したときのもので、別の音ではない
