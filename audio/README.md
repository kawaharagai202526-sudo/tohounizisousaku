# 音声の素材（ゲームはこのフォルダを読まない）

ユーザーがくれた音声のうち、まだゲームに入れていないものを置く。1ファイル版（`dist/`）にも入らない。
ゲームで鳴らすときは `node tools/embed-audio.js 曲ID 音声ファイル` で `js/bgmfiles.js` に埋めこみ、`js/music.js` の `SONGS` に `{ audio: '曲ID' }` を書く
（`file://` で開いても動くように、ゲームは外の音声ファイルを読まない。CLAUDE.md の「構成の決まり」）。

## a-o/ … BGM の素材 a〜o（2.16.2 のあとにもらった15本の動画の音声）

ユーザーの指定「aからoをbgmとするため記憶する。…まだ実装しない」。どこでどう使うかは、ユーザーの指示を待つ。

- a〜o は、それぞれの動画の映像に大きく書かれている文字。動画のファイル名の時刻の順と同じ。
  メッセージに付いていた順（a〜f、h、g、j、k、l、m、n、o、i）とはちがったので、映像の文字に合わせた

メモの「小さい音」「別の音」は、Claude が音の大きさとスペクトログラムで見つけたもの（本体の音より 20dB ほど小さい音など）。
ユーザーの指定は h だけなので、ほかは切っていない。ゲームで鳴らすときは、前後の無音だけ自動で切れる（js/audio.js の `makeLoopBuffer`）。

### h で消したところ

ユーザーの指定「ｈは音がフェードアウトしたのち、最後に別の音声が入り込んでいる。その音声は削除しておくこと」。

もとの h は、ザーッという音に下がっていく音が重なり、0.99〜1.056 秒で高い音が消えていく（−20 → −63dB）。
そのあと 1.0610 秒（46,788 サンプル目）から最後（1.161 秒）まで、高い音の多い別の音が入っていた。
その直前の 1.0603 秒（46,760 サンプル）で切り、最後の 10ms（441 サンプル）を小さくしていった（ぷつっと鳴らないように）。
それより前は、もとの音と同じ（16ビットにしたときの丸めだけ）。
