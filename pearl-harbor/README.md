# 真珠湾攻撃 3D俯瞰デモ

1941年12月7日（日本時間8日）の真珠湾攻撃を、約4分の3D俯瞰映像として再現するデモです。

- `index.html` … three.js を CDN から読み込む版（インターネット接続が必要）
- `pearl-harbor-offline.html` … three.js を同梱したオフライン版。ダブルクリックだけで再生できます

## カメラ

カメラは主要な地域・場面を自動で追いかけます（機動部隊の発艦、攻撃隊の進撃、戦艦列、アリゾナ、ネヴァダの脱出、海軍工廠など）。攻撃隊や艦艇の動きに合わせて追尾し、離れた場面へ移るときは一度高く引いてから寄ります。視聴者がカメラを動かす機能はありません。

## 操作

Space 再生／一時停止、← → 5秒移動、数字キーで章へ移動、L ラベル、H 字幕等を隠す、F 全画面。操作バーで再生速度と画質を選べます。

地形・艦の位置は史実をもとに簡略化したものです（縦方向は誇張、艦や航空機は見やすい大きさで表示）。数字には諸説があります。
